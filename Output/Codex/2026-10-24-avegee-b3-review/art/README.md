# B3 UI decorations — prepared, not integrated

Generated with built-in imagegen. Banner1024×256 and glow512×512, real RGBA alpha, lossless WebP plus PNG. No words are baked in. Original generated images remain in art/raw. The first banner intruded into the text safe area and was superseded by an imagegen edit. The final centered720×128 safe area has maximum alpha1/255: no visible decorative intrusion, with tiny generated alpha noise preserved. Padding crop and resize are the only export processing; no color key, paint or alpha reconstruction. See measurements.json and edge-review.jpg. Glow is intended behind the heading at low CSS opacity; the UI text must remain above it. Runtime use, CSS fallback, contrast at358px and reduced motion still need validation during B3 implementation.
