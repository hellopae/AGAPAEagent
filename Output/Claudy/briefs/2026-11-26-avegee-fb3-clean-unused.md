## ขั้นตอน
1. ทำรายการไฟล์ทั้งหมดในชุด deploy (ใช้ allowlist/workflow จริงของ Pages)
2. หาไฟล์ที่ถูกอ้างอิง — **ต้องครบทั้ง 3 ทาง**:
   a. ชื่อไฟล์ตรงตัวใน `src/` `index.html` `*.json` (manifest, atlas, catalog, `*-assets.js`)
   b. ชื่อที่โค้ดประกอบขึ้นตอนรัน (template string, `A(...)`, `${zone}`, `${k}`, ตัวแปรโซน th/asia/west/cyberhell, เวอร์ชัน `-v1/-v2`, `-profile`, `-idle`, ทิศ L/R, `.webp` แทน `.png`) — ไล่ทุกจุดที่สร้าง path แล้วขยายเป็นชื่อจริงทุกค่าที่เป็นไปได้
   c. รันเกมจริง: `scripts/asset-404-scan.py` + เก็บ URL ที่เบราว์เซอร์โหลดจริงตอนเดินหลายเส้นทาง (4 โซน, ศึก, สอบสวน, คู่มือ, โรงอาหาร, ศาลา, cutscene/อีเวนต์ด้วย fixture ถ้ามี)
3. ไฟล์ที่ไม่อยู่ในทั้ง 3 ทาง = ผู้สมัครลบ · แยกเป็น
   - **ลบได้แน่**: ไม่มีชื่อ/ส่วนของชื่อในโค้ดเลย และมีไฟล์รุ่นใหม่กว่าที่ใช้อยู่ (เช่น `-v1` เมื่อโค้ดใช้ `-v2`) หรือเป็นไฟล์ทดลอง/สำรอง
   - **ไม่แน่ใจ**: มีส่วนชื่อที่อาจถูกประกอบ หรือไม่มีรุ่นแทน → **ไม่ลบ** ใส่ตารางในรายงานให้ Claudy ถามคุณเป้
4. ห้ามลบ: ไฟล์ที่อยู่นอกชุด deploy แต่เป็นต้นฉบับงานศิลป์ (`art-src/`, `docs/`, `output/`) · ภาพที่ใบงาน FB3 กำลังจะวาดทับ (ดู `Output/Claudy/2026-11-26-avegee-feedback/PLAN.md` และ `Output/Codex/runs/art-1126-*.md`) · ไฟล์ placeholder ที่โค้ดใช้อยู่
5. ลบ "ลบได้แน่" ใน commit เดียวหรือแยกตามโฟลเดอร์ · ข้อความ commit อ้าง `FB3-CLEAN`
6. ตรวจหลังลบ: เทสต์เต็มรอบ `node --test tests/*.test.mjs` (เขียนลงไฟล์แล้ว grep `ℹ (tests|pass|fail)`) · `asset-404-scan.py` ไม่มี 404 ใหม่เมื่อเทียบก่อนลบ · ขนาด build ก่อน→หลัง
