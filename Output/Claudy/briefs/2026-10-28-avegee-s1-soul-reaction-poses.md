# S1 — ห้องสอบสวน: วาดท่าวิญญาณใหม่แทน effect เหงื่อ/น้ำตา (28 ต.ค. 2569)

Repo: AVEGEE (worktree ของ run นี้) · ห้าม commit/push/merge เอง · **งานวาดให้ Codex วาดเอง**

## คำขอของคุณเป้
"หน้าสอบสวน เมื่อจี้สอบสวนไปแล้ววิญญาณทำท่าเหงื่อตกและร้องไห้ ยังไม่สวย — วาดท่าทางวิญญาณใหม่ดีกว่าการใส่ effect
ไม่จำเป็นต้องวาดท่าวิญญาณทุกตัว แค่ดูสำนวนว่า วิญญาณไหนโกหกแล้วถูกจับได้ ก็ให้ตกใจ เหงื่อตก
ถ้าวิญญาณไหนทำความผิดเพราะเหตุจำเป็น แล้วความจริงเปิดเผย ก็ให้ร้องไห้"

## ขั้นตอน
1. **หาของเดิม**: effect เหงื่อ/น้ำตาตอนจี้ (`interrogation.js`, `interrogation-ui.js`, `remorse.js`, `soul-portraits.js`, `pot-souls.js`, `art.js`, `asset-preload.js`) — ภาพวิญญาณมาจากไหน (portrait ต่อคดี หรือชุดตามประเภท)
2. **คัดคดี** จาก `cases.js`, `cases-asia.js` และคดีโซน west/cyberhell: แยกเป็น
   - `caught_lie` — ให้การเท็จแล้วหลักฐาน/การจี้หักล้าง
   - `necessity` — ทำผิดเพราะเหตุจำเป็น และความจริงเปิดเผยตอนจี้
   - อื่นๆ — คงแบบเดิม (ไม่ต้องมีท่าใหม่)
   ใส่ตาราง: id คดี / ชื่อ / ประเภท / เหตุผล (อ้างบรรทัดสำนวน) / ใช้ภาพวิญญาณตัวไหน — ถ้าวิญญาณหลายคดีใช้ภาพเดียวกัน ให้วาดครั้งเดียวต่อภาพ
3. **วาด**: ต่อภาพวิญญาณที่ต้องใช้ วาดท่าใหม่ 1 ท่าตามประเภท — `caught_lie`: ตกใจ ตาเบิก เหงื่อตกเป็นส่วนของภาพ · `necessity`: ร้องไห้ ท่าทางเสียใจ
   ต้องเป็นตัวเดียวกับภาพเดิม (หน้า ชุด สี ลายเส้น) ขนาด/กรอบ/จุดยึดเท่าภาพเดิม พื้นโปร่งใส · เก็บต้นฉบับ + prompt ใน `output/coordination/2026-10-28-s1-soul-poses/`
4. **ต่อเข้าเกม**: ตอนจี้แล้วความจริงเปิด (จังหวะเดิมที่ effect ขึ้น) สลับเป็นภาพท่าใหม่ของประเภทนั้น — ถ้าคดีมีท่าใหม่ ให้ **ปิด effect เหงื่อ/น้ำตาแบบซ้อนทับ** · คดีที่ไม่มีท่าใหม่คงแบบเดิม · preload ภาพท่าใหม่พร้อมภาพวิญญาณคดีนั้น
