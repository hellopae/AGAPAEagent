## บริบท
- คุณเป้ 23 ต.ค. 2569: เมืองโซน 2 ตอนนี้ "ดูคล้ายโซน 1 มากไป" → อาคาร เสาไฟ ให้เป็น **จีน / ญี่ปุ่น / เกาหลี** ชัดเจน (หลังคาโค้งกระเบื้องเคลือบ, ชายคางอน, เสาแดงชาด, โคมกระดาษ, โทริอิ/ไพโหลว, ศาลาไม้) · **ตำแหน่งเดียวกับโซน 1** (โค้ดจัดวาง — ใบงานนี้แค่วาดให้ขนาด/จุดยึดเท่าเดิม)
- รายการ sprite โซน 2 ที่ต้องแทน: ตาราง `PLANNED_ART` + `FACADE_SIZES` ใน `src/zone-skin.js` (judgment, houses ×4, lamp, torch-pillar, rock ไม่ต้อง) และ facade สถานี sala/tea/sawan/krajok · ไฟล์ asia ปัจจุบันคือของรอบ M3 (`img/theme-v4/*-asia-v1/v2.webp`, `img/town-district/house-*-asia-v1.webp`, `img/map-v5/st-*-asia*.webp` ถ้ามี) — วัดขนาด/ตำแหน่งจุดฐานจากไฟล์เดิม แล้ววาดใหม่ **ขนาดภาพเท่าเดิม จุดฐาน (โคน/ฐานอาคาร) ตำแหน่งเดิม**
- ต้นไม้ที่คุณเป้วางใหม่มี 2 ชนิดที่ยังไม่มีภาพ: **สีขาว = ซากุระขาวอมชมพู** และ **สีฟ้าอมเขียว = หลิวริมน้ำ** (Claudy ตีความ — ระบุใน README ให้คุณเป้ยืนยัน) · ต้นสีแดง = เมเปิลแดง (ตรวจว่า `town-tree-b-asia-v1` เป็นใบแดงชัดหรือไม่ ถ้าไม่ชัดวาดใหม่)
- สไตล์ต้นแบบ: ภาพพื้นเมืองโซน 2 `img/map-zone2/v1/zone2-terrain-v1-preview.webp` (มุมกล้อง/แสง/ความหนาแน่น) + sprite โซน 1 คู่กัน (ขนาดตัวต่อตัว) · กฎวัฒนธรรม: ห้ามรูปเคารพ/พระพุทธรูป ห้ามตัวอักษรจริง/ลายน้ำ ห้ามธงชาติ
- **ทำงานใน working directory ปัจจุบันของคุณ (git worktree ของ AVEGEE) เท่านั้น** ห้ามสร้าง worktree/branch/clone ห้าม git commit/push

## งาน
1. ตาราง `output/z2-art/inventory.md`: ทุก sprite โซน 2 ที่จะแทน — พาธเดิม, ขนาด, จุดฐาน (วัดจาก alpha), ตัวคู่โซน 1
2. วาดใหม่ทุกชิ้นด้วย imagegen (พื้นโปร่งใส ขอบสะอาด ไม่มีขอบชมพู/ขาว) → ไฟล์เวอร์ชันใหม่ `-v3` ข้างไฟล์เดิม (ห้ามทับไฟล์เดิม) + ต้นไม้ใหม่ `img/theme-v4/town-tree-sakura-asia-v1.webp`, `town-tree-willow-asia-v1.webp` ขนาดเท่า `town-tree-asia-v1`
3. ภาพเทียบ `output/z2-art/qa/`: แผ่นรวมเก่า|ใหม่ทุกชิ้น + ภาพวางทุกชิ้นบนพื้นโซน 2 ที่สเกลจริง (composite ด้วย PIL ตามตำแหน่งใน town-layout ของโซน 1) · ตรวจ alpha ขอบ (ไม่มี halo)
4. README `output/z2-art.md`: ไฟล์ใหม่ทั้งหมด + ขนาด + prompt + ชิ้นที่ยังไม่ดี
