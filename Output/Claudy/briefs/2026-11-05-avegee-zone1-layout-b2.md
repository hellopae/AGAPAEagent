## ขั้นตอน
1. ตัวเล่น animation sprite (เสียบที่จุดที่ B1 เตรียม): tile ของเหลวตามรูปร่างร่อง (mask จาก alpha terrain) + sprite จุด (ฟองลาวา ลาวาตก หมอก ลำแสง) · โหลดเฉพาะรอบกล้อง · หยุดเมื่อ pause/แท็บซ่อน
2. ฟ้า: เมฆ sprite ลอยแนวนอนช้า parallax เทียบพื้น (ฟ้า < ภูเขา < พื้น) · ภูเขา parallax เล็กน้อย
3. DOF แบบ tilt-shift: เบลอตามระยะจากแถบโฟกัสที่ตัวละคร (บน=ไกล, ล่างสุด/ฉากหน้า=ใกล้) + วัตถุชั้น front เบลอแรง · ต้องลื่นบนมือถือ (เบลอชั้นที่ cache ไว้ ไม่ blur ทั้งจอทุกเฟรมถ้าช้า)
4. เงาเมฆบนพื้น (ทับ terrain + วัตถุ ไม่ทับฟ้า) เลื่อนตามทิศลมเดียวกับเมฆ — ตรวจโค้ดเงาเมฆที่ merge ไปแล้ว (`812152d2` และก่อนหน้า) ใช้ซ้ำ
5. อนุภาค: ใบไม้หล่นจากต้นไม้ตามชนิด (เมเปิลแดง/ทอง/เขียว/หิมะฝั่งน้ำแข็ง) จำนวนจำกัด, ฝุ่นในลำแสง
6. bloom อ่อน + vignette + color grading ตามพื้นที่ (ฝั่งลาวาอุ่นแดง / ฝั่งน้ำแข็งเย็นฟ้า) + แสงกระพริบบนพื้นรอบไฟ (ตั้งค่าปิดได้) · ตั้งค่าคุณภาพ ต่ำ/กลาง/สูง (มือถือเริ่มที่กลาง)
7. ทดสอบ fps desktop + มือถือ 390 px (เป้า ≥ 50 fps desktop, ≥ 30 มือถือจำลอง) · เทสต์เต็ม 0 fail · วิดีโอ/ภาพหลักฐานเทียบตัวอย่าง
