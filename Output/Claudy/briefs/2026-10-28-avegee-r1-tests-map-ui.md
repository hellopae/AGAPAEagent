## ส่วน B — UI แผนที่ (ทุกแผนที่ ทุกโซน: เมือง 4 โซน + ชายแดน + ถ้ำ/ดันเจี้ยน)
1. **ลูกศรทางเข้าออก** (exit marker ดู `src/exit-marker.js`, `src/scene.js` ~บรรทัด 548 "ลูกศรชี้ลงเด้ง…+ ป้ายชื่อ + วงแหวนแดง"):
   ย่อลูกศรเหลือ ~50–60% ของขนาดปัจจุบัน (อ่านได้ที่ zoom ต่ำสุดและบนมือถือ 390×844) · **เอาข้อความ/ป้ายชื่อทั้งหมดออก เหลือแค่ลูกศร** · วงแหวนพื้นคงไว้ได้ถ้าไม่มีตัวอักษร
2. **ศัตรูบนแผนที่**: เอาข้อความชื่อ + ระดับ (Lv) ใต้ศัตรูออกทั้งหมด เหลือแค่ตัวละคร (รวมบอสชายแดน/บอสถ้ำ) — งาน B5a เดิมแค่ย่อ ตอนนี้ให้ลบ · ข้อมูลชื่อ/เลเวลยังอยู่ในฉากต่อสู้ตามเดิม
3. **เมนูซ้ายล่าง** (profile / หนังสือคู่มือ / กระเป๋า) ตอนนี้ขึ้นภาษาอังกฤษ → แสดง **ภาษาไทยทั้งหมด** ตอนนี้ยังไม่มีปุ่มสลับภาษา ให้ไล่ดูเมนู/ปุ่มอื่นบน HUD ที่หลุดเป็นภาษาอังกฤษด้วย แก้ที่ค่าเริ่มต้นภาษา/คีย์ i18n ที่หาย ไม่ hardcode ข้อความไทยทับ
