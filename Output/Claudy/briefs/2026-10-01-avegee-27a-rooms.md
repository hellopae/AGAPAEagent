## ขอบเขต
1. ทำ **เทมเพลตห้องเดียว** ขับด้วยข้อมูล (ROOMS) แล้วใช้กับทุกห้อง: การ์ดหัวเรื่องซ้ายบน · ปุ่มพัก/ปิดขวาบน · ปุ่มทองพร้อมคำอธิบายวางตามจุดในแบบ (สัดส่วน 0–1) · HUD ล่างซ้าย · ตัดแผง "ที่นี่คือที่ไหน/เอาไว้ทำอะไร/ไม่ใช้ลงทัณฑ์" และ toast สอนกดออก · ฉากเต็มกรอบแบบในภาพ
2. ข้อความ (ชื่อห้องใช้ชื่อเดิมในเกม; ตัวเลข "รับได้ N ดวงวิญญาณ" ดึงจากความจุจริงในข้อมูล ไม่ฝัง 3):
   | ห้อง (แบบ) | คำอธิบาย | ปุ่ม / คำใต้ปุ่ม |
   |---|---|---|
   | tea `UI4-tea` | ที่พักของยมทูต เพื่อฟื้นฟูกำลังใจ | **นั่งพัก** / เพื่อฟื้นระดับบารมี + แถบบารมี "บารมี 87/100" ใต้ปุ่ม |
   | tarang `UI4-tarang` | สถานที่สำหรับขังดวงวิญญาณ ที่ยังไม่ตัดสินโทษ หรือรอส่งไปประตูสวรรค์ | **จัดการรายชื่อ** / เพื่อจัดรายชื่อดวงวิญญาณในคุก · **ตรวจความเข็ดหลาบ** / เพื่อตรวจรายชื่อดวงวิญญาณที่เข็ดหลาบ → เปิดแผงรายชื่อด้านขวาตามแบบ: หัว "ตรวจรายชื่อกับนิรา - รับทัณฑ์ครบแล้ว N คน" แต่ละแถว "#001 หญิงวัยเกษียณ" + ปุ่มทอง **ให้นิราตรวจ** (ชื่อห้องในเกม = "ตะรางรอวาระ" สะกด ตะ ไม่ใช่ ตา) |
   | dab `UI4-dab` | สถานที่ลงทัณฑ์ดวงวิญญาณที่ทำร้ายผู้อื่น ทั้งทางร่างกายและคำพูด / สำหรับเวรกรรม : ฆ่า/ทำร้าย - วจีทุจริต / รับได้ N ดวงวิญญาณ | **วัดความเร็ว** / เพื่อฝึกความเร็ว |
   | krajok `UI4-krajok` | สถานที่สำหรับรับพลัง ที่จะสามารถส่องดูกรรมของดวงวิญญาณต่าง ๆ | **ส่องดูกรรม** / เพื่อรับพลังที่ช่วยให้ดูกรรมของดวงวิญญาณต่าง ๆ ได้ |
   | sala `UI4-sala` | ที่เก็บสำนวน เอกสารของดวงวิญญาณทุกดวง | **เปิดเอกสาร** (บนม้วนเอกสาร ไม่มีคำใต้ปุ่ม) · **จัดเอกสาร** / เพื่อเพิ่มระดับระเบียบ |
   | sawan `UI4-sawan` | สถานที่สำหรับตรวจกรรมของดวงวิญญาณ ถ้ายังมีกรรมอยู่ จะส่งเข้าประตูสวรรค์ไปเกิดใหม่ แต่ถ้าหมดกรรมแล้ว จะส่งไปสวรรค์ | **ตรวจกรรม** / เพื่อตรวจและลดกรรม |
   | ngiw `UI4-ngiw` | สถานที่ลงทัณฑ์ดวงวิญญาณที่ผิดกาม / สำหรับเวรกรรม : ผิดกาม / รับได้ N ดวงวิญญาณ | **เติมลาวา** / เพื่อเร่งความเร็วการลงทัณฑ์ |
   | lan `UI4-lan` | สถานที่ลงทัณฑ์ดวงวิญญาณที่ไปเบียดเบียนผู้อื่น / สำหรับเวรกรรม : เบียดเบียน / รับได้ N ดวงวิญญาณ | **วัดพละกำลัง** / เพื่อฝึกความอดทน |
   | krata `UI4-krata` | สถานที่ลงทัณฑ์ดวงวิญญาณที่มีความโลภ / สำหรับเวรกรรม : ฉ้อโกง / มัวเมา / รับได้ N ดวงวิญญาณ | **เร่งไฟ** / เพื่อเร่งความเร็วการลงทัณฑ์ |
   | lokan `UI4-lokan` | สถานที่ลงทัณฑ์ดวงวิญญาณที่ไม่รู้จักบุญคุณ / สำหรับเวรกรรม : อกตัญญู / รับได้ N ดวงวิญญาณ | **เพิ่มความเย็น** / เพื่อเร่งความเร็วการลงทัณฑ์ |
   ปุ่มทำงานเหมือนปุ่มเดิมของห้องนั้น (map คีย์ห้องจริงจากโค้ด — ถ้าคีย์ไม่ตรงชื่อไฟล์แบบ ให้จับคู่ตามชื่อห้อง) · ถ้าห้องไหนมีปุ่มในเกมที่แบบไม่มี ให้คงไว้แบบเดียวกันและรายงาน
