## A — ยมทูตโจมตีด้วย cutscene ของตัวเอง (รูป 1, 14)
ตอนนี้กดให้ยมทูตโจมตี ภาพที่ขึ้นเป็นยมน้อยทำท่าโจมตี → เปลี่ยนเป็น:
1. ขึ้น **cutscene ของยมทูตคนนั้น** (แบบเดียวกับ cutscene ท่าของยมน้อย `hero-yama-*-cutscene`) ภาพจาก
   `img/raw/crew-{taan,plerng,dam,kan,guard}-cutscene.jpeg` และ `img/raw/crew-boon-cutecene.jpeg` (ชื่อไฟล์สะกดผิด → ตั้งชื่อใหม่ให้ถูกตอนแปลงเป็น `img/crew-boon-cutscene.*`)
   แปลง/ย่อขนาดแบบเดียวกับ cutscene ที่มีอยู่
2. หลัง cutscene ตัวยมทูต**พุ่งเข้าไปโจมตีศัตรู**แล้วกลับที่ (แบบยมน้อย)
3. **ยกเว้น กานต์ (สะกดจิต) และ บุญ (เติมเลือด)** → มี cutscene แต่ไม่พุ่งเข้าไป (ร่ายจากที่เดิม + เอฟเฟกต์ fx-hypno / fx-heal)
4. โซน 2-4 ถ้ายมทูตโซนนั้นไม่มี cutscene ของตัวเอง ใช้ของโซน 1 ไปก่อน แล้วระบุในรายงานว่าต้อง gen ภาพไหนเพิ่ม

## C — ก่อนสู้พี่ใหญ่: เตรียมศึกเลือกได้ทั้ง 3 อย่าง (รูป 12)
แทนที่ "เลือกเตรียมศึกหนึ่งอย่าง" (แฟ้มหลักฐาน / ยมทูตคุ้มกัน / ลูกไฟ) ด้วย 3 ปุ่มที่กดได้ทุกปุ่ม ไม่บังคับ ตามลำดับที่อยากทำ:
1. **พ่อค้านรก** → เปิดร้านพ่อค้า (ร้านเดิม) ซื้อของแล้วกลับมาหน้านี้
2. **นิรา** → เปิดหน้าจัดทีมยมทูต แล้วกลับมาหน้านี้
3. **กินกล่องยาเติมบารมี** → ใช้กล่องยาจากกระเป๋า (ถ้าไม่มีก็บอก/พาไปซื้อ)
แล้วมีปุ่ม **"เข้าสู้"** แยกชัด · โบนัสแฟ้มหลักฐานเดิม ถ้าผูกกับเนื้อเรื่อง ให้คงไว้แบบอัตโนมัติ (อธิบายในรายงาน) · ใช้กับบอสทุกโซน

## D — ระบบหิว/เหนื่อยของยมทูต (รูป 15)
ตอนนี้มีข้าวปั้นและข้อความ "หิว ทำงานช้า" แต่ผู้เล่นไม่รู้ว่าป้อนยังไง → ทำให้เห็นและป้อนได้ 3 ทาง:
1. **โต๊ะนิรา (จัดทีม)**: การ์ดยมทูตทุกคนมีแถบ **หิว** (และเหนื่อย ถ้าระบบมี) + ปุ่ม "ให้ข้าวปั้น"
2. **หน้าต่างสถานีที่มียมทูตคุม**: ช่อง "ผู้คุมประจำหลังนี้" แสดงแถบหิว + ปุ่ม "ให้ข้าวปั้น"
3. **บนแผนที่**: เดินเข้าใกล้ยมทูตแล้วมีปุ่ม "คุย" → หน้าต่างเล็กบอกสถานะ + ปุ่ม "ให้ข้าวปั้น" (เหมือนคุยกับ NPC อื่นที่มีอยู่)
- ให้ข้าวปั้น = หัก 1 ห่อจากเสบียง/กระเป๋า ความหิวลด · ไม่มีข้าวปั้น → ปุ่มปิด + บอกซื้อได้ที่ไหน
- ผลของความหิวต่องาน (ช้าลงเท่าไหร่) แสดงเป็นข้อความสั้นให้ผู้เล่นเข้าใจ
- ถ้าระบบเสบียงอัตโนมัติเดิมมีอยู่ ให้คงไว้ อธิบายในรายงานว่าสองระบบทำงานร่วมกันยังไง
- ใส่คำอธิบายในหน้า "วิธีเล่น" 2-3 บรรทัด
