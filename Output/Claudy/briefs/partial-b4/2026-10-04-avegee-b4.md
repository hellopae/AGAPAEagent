## progression และกันฟาร์ม

- actor records อยู่ใน `training.actors[rosterId]`; `th:taan` กับ `asia:taan` เป็นคนละ record เช่นเดียวกับ Guard/เพลิง ยมบาทใช้ global:yama ร่วมโซนตามคำตัดสินที่ยกเว้นยมบาท/นิรา
- EXP สะสมขั้นต่ำระดับ 1–5: 0 / 60 / 150 / 270 / 420; คำนวณ level ใหม่จาก EXP ตอนโหลด
- เพดานโซน th/asia/west/cyberhell = 2/3/4/5; EXP เพิ่มไม่เกิน threshold เพดาน
- เล่นสำเร็จและคะแนน 60–79 / 80–94 / 95–100 → EXP 20 / 30 / 40; คะแนนต่ำกว่า 60, ไม่ผ่านเกณฑ์เกม หรือยกเลิก → 0
- 2 ครั้งต่อคนในช่วง tick 0–99, 100–199 ฯลฯ; CD 30 tick เริ่มตอนกดเริ่ม Guard ที่ lan/lokan อ่าน record เดียวกัน
- เปิดหน้าเลือกยังไม่หักครั้ง กดเริ่มจะสร้าง session ที่มี ID/โซน/ผู้ฝึก/station/seed และหักครั้งก่อนเซฟ ถ้าเซฟไม่ได้คืน state แล้วไม่เริ่มเกม
- ผลรับเฉพาะ ID ของ activeSession เท่านั้น จ่ายผลและล้าง session ใน snapshot เดียว ผลซ้ำ/ID ผิดไม่มี EXP
- ปิดกลางรอบไม่คืน quota/CD โหลดเซฟที่มี session ค้างจะล้าง session เป็นผล 0 แต่รักษาครั้ง/CD/sequence เดิม
- หากเซฟผลล้มเหลวจะ rollback การจ่าย EXP; retry ผลเดิมเมื่อเซฟได้จะรับได้ครั้งเดียว

## จุดต่อ B3

ฐานยังไม่มี B3 ไม่เพิ่มพลังตามโซนหรือร้านค้าในใบนี้

B4 ส่งออก `trainingLevel(state, actorId)` และ `trainingDamage(game, actorId, action, base)` จาก `src/training.js` และใช้ใน `battleAct()` จริงแล้ว:

- ยมบาทเฉพาะ `action='atk'`: round(base × (1 + 0.03×(Lv−1))) ก่อน critical และ Rage ตามระบบเดิม; ลูกไฟ/ท่า MP/ไอเท็มไม่ใช้โบนัสนี้
- ทัณฑ์/Guard/เพลิง `action='assist'`: round(base × (1 + 0.06×(Lv−1))) โดย base รวมโบนัส upLv เดิม
- B3 ควรอ่าน level จาก record นี้ผ่าน actor ID แล้วรวมกับ effective stats ของ B3; ย้าย call sites มาใช้แหล่งสูตรเดียวและระวังไม่คูณ training ซ้ำ ปรับ UI ค่าพลังนอกหน้าฝึกผ่านสูตรร่วมของ B3 ต่อไป
