## 1 — แผนที่: ปุ่มล่าง + หน้าต่าง PAUSE
1. **ลบปุ่มลอย "🔍 เริ่มการสอบสวน"** เหนือบัลลังก์ (บังตัวละคร) → ปุ่ม **"เปิดศาล / OPEN COURT"** ล่างกลาง ทำหน้าที่เริ่มการสอบสวนแทน (ถ้าไม่มีวิญญาณรอ ให้ disabled + บอกเหตุผลสั้น ๆ)
2. เพิ่มปุ่ม **"เดินวาระ"** ข้าง ๆ เปิดศาล (สไตล์ปุ่มทองเดียวกัน ขนาดเท่ากัน) = ให้เวลาเดิน (ตรรกะเดิมของ "เดินวาระ") · กดแล้วสลับเป็นสถานะกำลังเดิน · เอาแถบข้อความ "พักอยู่ — กด 'เดินวาระ'…" ออกหรือย่อให้ไม่บัง
3. ปุ่ม ▶/⏸ ขวาบน: **กดแล้วหยุดเกม + เปิดหน้าต่าง PAUSE** ตาม `UI3-pause.jpg`: ไอคอนหยุด + ป้ายทอง "หยุดเกม/PAUSE" · ปุ่มปิดขวาบน · แถวปุ่ม 🏠 กลับหน้าแรก / ▶ เล่นต่อ / ⚙ ตั้งค่า (เปิดหน้าตั้งค่าเดิม) · ปิด/เล่นต่อ = กลับสภาพเวลาก่อนกด
4. ข้อความใหม่ทั้งหมดผ่าน `t()` มีทั้ง TH/EN

## 4 — หน้า Home
- ไอคอน + ข้อความเมนู (เล่นต่อ + บรรทัดรายละเอียด, เริ่มเกมใหม่) **ชิดซ้าย** ในคอลัมน์เดิม (ไอคอนอยู่หน้าข้อความ ติดกัน)

## 5 — หน้าสอบสวนให้ใกล้ `Comment7.jpg` มากขึ้น
ตอนนี้ต่างเยอะ (รายละเอียดใน requests.md ข้อ 5) ต้องเป็น:
1. **เต็มจอ** แบบม็อกอัป (ไม่ใช่หน้าต่างมีกรอบกลางจอ)
2. ซ้ายบน: ปุ่มหยุด + ⚙ ขนาดใหญ่ไอคอนทอง (`img/ui/`) · **ปุ่มปิด `icon_close` อยู่ขวาบนเสมอ** (กฎนี้ใช้กับทุกหน้าต่าง/modal ในเกม — ไล่แก้ทุกจุดที่มีปุ่มปิด)
3. "สำนวน : 025" สีทองตัวใหญ่กลางบนฝั่งซ้าย
4. แท็บขวาบนขนาดใหญ่มีไอคอนจริง: ไต่สวนจี้ได้อีก N ครั้ง · 📖 หนังสือคู่มือ (`icon_book`) · 🔒 ขังไว้ก่อน (`icon lock`) · ⏭ พักคดีนี้ (`icon skip`)
5. กล่อง "สำนวนที่นิราอ่านให้ฟัง" ตัวใหญ่ สีข้อความตามประเภท (ทอง = ข้อกล่าวหา · เขียว = ความดี · ส้ม = ข้อสังเกต) ตามม็อกอัป
6. "เลือกประเด็นที่จะสอบสวน" การ์ดตัวใหญ่ · "บันทึกการสอบสวน" กล่องล่าง
7. ล่างซ้าย: รูปยมบาทน้อย + ชื่อ + แถบบารมี **ไม่มีกล่องพื้นหลัง**
8. แถบเตือน "ออกหมายไม่ได้ — ยังไม่ได้เลือก…" → ย้ายเป็นข้อความเล็กใต้ปุ่มออกหมายในวงคำสั่ง หรือ tooltip (ไม่เป็นแถบบนสุด)
9. ตัวอักษรทั้งหน้าใหญ่ขึ้นให้อ่านง่ายที่ 1440 · มือถือ 390×844 แผงขวาเลื่อนได้

## 6 — แถบ "ควรรู้" → กระดิ่ง
- แถบยาว "บทที่ N — … N/16 · เข้าใจแล้ว" กลางจอ → เปลี่ยนเป็น **ไอคอนกระดิ่ง** (`icon_bell`) มุมจอ (ใกล้ HUD ขวาบน หรือจุดที่ไม่บัง) **เด้ง/สั่น + จุดแดงตัวเลข** เมื่อมีข้อความใหม่
- กดกระดิ่ง → หน้าต่างอ่านข้อความ (หัวข้อ เนื้อหา ลำดับ N/16 ปุ่มถัดไป/ก่อนหน้า ปุ่มปิดขวาบน) · อ่านแล้วจุดแดงหาย · ข้อความเก่ากลับมาอ่านได้
