## ขอบเขต run นี้ = นำร่อง 4 ชิ้น + สำรวจทั้งแผนที่
คุณเป้ต้องดูรอบนำร่องก่อน ถ้าผ่านจึงวาดอีก 16 ชิ้นในรอบถัดไป

### ⚠️ ห้ามหยุดที่ภาพร่าง — ทำครบใน run เดียว (~30 นาที) ImageGen ≤ ~12 ครั้ง ถ้าไม่ทันทำตามลำดับแล้วรายงานว่าค้างข้อไหน

1. **ประกอบ master 1×** (v5 + repairs) → `master-1x.jpg` และ walkmask overlay `walkmask-overlay-1x.jpg`
2. **สำรวจวัตถุทั้งแผนที่** → `objects-inventory.json`: ทุกวัตถุที่วาดติดพื้นและ **ทับ/ชิดพื้นที่เดินได้** (walkmask ขยาย ~24 หน่วย) หรือ **สูงยื่นขึ้นบังพื้นที่เดิน** (ต้นไม้ ทรงพุ่ม ราวสะพาน เสา ตะเกียง รั้ว เสาบันได ดอกไม้กอสูง หิน)
   ฟิลด์: `id, kind, bboxWorld[x,y,w,h], footWorld[x,y], chunk, action` โดย `action` = `extract-redraw` (วาดชิ้นแยกใหม่) | `replace:<ไฟล์ภาพใหม่ของคุณเป้>` | `keep-baked` (ไกล เดินไม่ถึง — ต้นไม้ป่าบนหน้าผาไกลไม่ต้องแยก) + `inventory-overlay.jpg` กรอบสีตาม action
   **สะพาน:** พื้นสะพาน/ขั้นบันได **อยู่ในพื้นต่อไป** (ยามาเดินบน) — แยกเฉพาะราว/เสา/ซุ้ม และแบ่ง **ส่วนหลัง** (อยู่หลังตัวละคร) กับ **ส่วนหน้า** (บังตัวละคร) เป็นคนละภาพ
3. **ตารางจับคู่อาคาร/สถานีใหม่ → ที่ตั้งเดิม** `station-mapping.md`: ภาพใหม่ไฟล์ไหน → `TOWN_STATION_SITES` id / บ้านพัก / แท่นตัดสิน / เสาไฟ · ระบุขนาดในเกมที่เสนอ (เทียบขนาดอาคารเดิมที่ตำแหน่งนั้น) · ข้อที่ไม่แน่ใจเขียน "รอคุณเป้" (ป่าดาบ `dab`, ต้นงิ้ว `ngiw`, โรงอาหาร `canteen` ในชุดใหม่ไม่มีชัดเจน)
4. **วาดพื้น 2× นำร่อง 4 ชิ้น:** `r2-c2, r2-c3, r3-c2, r3-c3` (ลานหลัก บันไดกลาง สะพานข้ามแม่น้ำ ท่าเรือ) → ชิ้นละ 2048×2048 px ตารางเดียวกับเดิม (r/c เดิม พิกัดโลกเดิม)
   - ใส่ภาพ chunk เดิม (+ ขอบเพื่อนบ้าน ~128 px) เป็นภาพตั้งต้น · สั่ง "องค์ประกอบเหมือนเดิมทุกจุด รายละเอียดคมขึ้น สไตล์ painterly เดียวกับภาพอาคารใหม่ของคุณเป้" · **ลบวัตถุที่ action ≠ keep-baked แล้วเติมพื้นข้างใต้ให้ต่อเนื่อง** (พื้นหิน/ดิน/หญ้า ไม่ใช่บล็อกสี่เหลี่ยม)
   - ของเหลว (แม่น้ำม่วง ลาวา น้ำฟ้า) และหมอกขาว **คงไว้เป็นชั้นฐานนิ่ง** (ชั้น animation ทำใบงานแยก)
   - **จัดตำแหน่งผลลัพธ์กลับให้ตรงต้นฉบับ** (register ด้วยสคริปต์) แล้วเบลนด์รอยต่อในช่วงขอบซ้อน
5. **วาดวัตถุแยกในพื้นที่นำร่อง** (action = extract-redraw): RGBA ความละเอียด ≥ 2.56 px/หน่วย มี foot · ราวสะพานแยกหน้า/หลัง → `sprites/<id>.webp` + `sprites.json` (`id, src, rectWorld, footWorld, layer: back|sort|front`)
6. **ตรวจ:**
   - `structure-check.jpg` + ตัวเลข: เส้นขอบพื้นที่เดิน (ขอบลาน/บันได/หน้าผา/ตลิ่ง) ของภาพใหม่ย่อลง 1× เทียบต้นฉบับ ต่างไม่เกิน **4 px (1×)** — walkmask เดิมต้องใช้ได้ทันที
   - `seam-check.jpg` รอยต่อระหว่าง 4 ชิ้น และกับชิ้นเดิมรอบนอก
   - `compare-game-zoom.jpg`: crop มุมเดียวกัน (ลานหลัก + บันไดกลาง + สะพาน) ที่ความละเอียดเท่าจอเกม (≈ 2.8 device px/หน่วย) **เก่า | ใหม่** เคียงกัน + ประกอบ sprite แยกกลับลงไปแล้ว
   - `style-compare.jpg` เทียบกับภาพอาคารใหม่ของคุณเป้ 2–3 ชิ้น
7. `index.html` พรีวิว (เลื่อน/ซูมได้, สลับ เก่า/ใหม่, เปิด-ปิด sprite แยก) · README ภาษาไทย (จำนวน ImageGen, วิธี register/เบลนด์, ข้อไม่แน่ใจ, สถานะ วาดแล้ว/ตรวจภาพแล้ว/ยังไม่ประกอบในเกม) · `generation-prompts.json`
