## ขั้นตอน
1. **สำรวจ + สเปกอาร์ต (ส่งก่อน)** — ทำรายการทุกท่าที่ผู้เล่นเห็นในศึก (โจมตีปกติแต่ละอาวุธ/ชุด, พลังยม, ท่ายมทูตแต่ละคน, ท่าศัตรู/บอส, ไอเท็ม) → จับคู่กับ "สูตรเอฟเฟกต์" อย่างน้อย:
   ฟัน (แนวนอน/เฉียง/กากบาท/หลายครั้ง), ลูกไฟ (เล็ก/กลาง/ใหญ่ระเบิดเต็มจอ ตามความแรง), น้ำแข็ง (ผลึกพุ่งจากพื้น+แตก), ลม (พายุหมุน/ใบมีดลม), สะกดจิต (วงเวทม่วงหมุน+เกลียว), หอก (แทงพุ่งเป็นเส้นแสง+เจาะ), กระบอง (ฟาดพื้นคลื่นกระแทก+เศษหิน), เติมเลือด (ต่อยอด heal-fx)
   แล้วเขียน **สเปกภาพ texture** ที่ต้องให้ Codex วาด (ชิ้นส่วน ไม่ใช่ทั้งแอนิเมชัน: แสงวาบ, เส้นฟัน, เปลวไฟ, ผลึก, เกลียวลม, วงเวท, ประกาย, คลื่นกระแทก, เศษหิน ฯลฯ — ชื่อไฟล์ `img/fx/*.webp`, ขนาด, พื้นโปร่ง/พื้นดำสำหรับ blend `screen`/`lighter`, สี) ลงไฟล์ `/Users/agapae/Documents/Work PAE/Claude/AGAPAE Agent/Output/Toby/2026-10-16-avegee-m2-art-spec.md`
   **เสร็จข้อนี้แล้ว commit ไฟล์สเปกในตัวเอง ไม่ต้องรอ** (Claudy จะส่ง Codex วาด) แล้วทำต่อ
2. **เอนจินเอฟเฟกต์** `src/battle-fx.js` (+ CSS/canvas overlay บนสนาม): สูตรแต่ละท่า = ไทม์ไลน์ของชั้น (texture/particle/แสงวาบ/ตัวเลข) + เรียกกล้อง M1 (focus/shake/dim) ตามสัญญา API
   - ระหว่างรอภาพ Codex ใช้ texture ที่วาดด้วยโค้ด (gradient/รูปทรง) ให้ดูดีพอ แล้วสลับเป็นไฟล์จริงด้วย key เดียว
   - ความแรงต่างกัน: ระดับเล็ก/กลาง/ใหญ่ตามดาเมจหรือเลเวลพลัง (ลูกไฟอย่างน้อย 3 ระดับ)
   - ตัวเลขดาเมจใหญ่ขึ้นแบบวิดีโอ (ลอย+เด้ง) + ป้าย "อ่อนแอ!"/"คริติคอล" ถ้าเกมมีสถานะนั้น (ไม่เพิ่มกติกาใหม่)
   - เติมเลือด: ต่อยอด heal-fx ให้ใหญ่และสวยขึ้น (วงแสงรอบทีม + ประกาย) ไม่ทิ้งของเดิม
   - performance: ใช้ canvas ชั้นเดียว + pool อนุภาค, `globalCompositeOperation` ได้ แต่ห้าม `ctx.filter`/`shadowBlur` ต่อเฟรม · ≤ ~300 อนุภาคพร้อมกัน · fps ใกล้ 60 ที่ DPR2
   - ใช้ได้ทั้งฉากต่อสู้ทุกโซน + ฉากสอบสวน (สะกดจิต/ส่องกระจก ถ้ามี)
3. Playwright: วิดีโอ/ภาพเฟรมทุกสูตร (บนพื้นหลังต่อสู้จริง) · fps · เทสต์ใหม่ (map ท่า→สูตร ครบทุกท่า, ไม่มี filter) · `node --test tests/*.test.mjs` ไม่มีแดงเพิ่มจากฐาน · cache-bust `-m2` · commit ใน branch (Dale รีวิว)
