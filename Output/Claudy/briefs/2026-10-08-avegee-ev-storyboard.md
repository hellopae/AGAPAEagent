## C. ลำดับ event (ภาพมีเลขวงกลม = ลำดับ)

### โซน 1 (th)
1. **Map-Zone1-4 — คดีที่ 5**: ปรับสำนวนคดีที่ 5 = วิญญาณพระที่จำวัดอย่างเดียว ไม่เคยทำบาป (มีอยู่แล้ว เช่น `k:'monk'` ใน `src/cases.js`) ให้เป็น **เทวดาปลอมตัวมา** · หลังตัดสินแล้ว → cutscene เฉลย `deva-intro-th-v1` · ตัดสินถูก = ได้รับคำชม แล้วเข้าสู้ทดสอบ · ตัดสินผิด = โดนว่าตักเตือน แล้วเข้าสู้ต่อ · ชนะ = ได้ item **กระจกวิเศษ** (ได้ครั้งแรกจากทางนี้) — event เดิม `devaTest`
2. **Map-Zone1-2 — หลังคดีที่ 8**: หน้าต่างแจ้งเตือนมีปีศาจฝ่าชายแดน → yama เดินลงไปชายแดน เดินเข้าใกล้ Boss → cutscene `frontier-th-intro-v1` → สู้ 2 wave + บอสชายแดนโซน 1 — event เดิม `frontierBreach`

### โซน 2 (asia)
1. **Map-Zone2-1 — หลังคดีที่ 3**: วิญญาณแหกคุกออกมาเผาอาคาร ทำลายไป 1 หลัง (อาคารบนกลาง ~1200,230 = ตะราง) **ใส่ effect ไฟ** + หน้าต่างแจ้งเตือน — event เดิม `asiaPrisonFire`
2. **Map-Zone2-2**: พอจัดการวิญญาณไป 2 ตน → ภาพตัดมาที่ฉากแผนที่ เทวดา **ค่อยๆ บินลงมา** (จากบนลงมาที่ ~1330,400 ข้างอาคารที่ไหม้) ช่วยสู้ → cutscene `deva-intro-asia-v1` → เทวดาจัดการวิญญาณที่เหลือ 1 ตนให้ → เทวดา **ยืนรอบนแผนที่** ว่าเราดูแลโซนนี้ได้ไหม · เดินเข้าไปคุยเพื่อทดสอบฝีมือ · ชนะ = **พลังพัดสายลม** — event เดิม `devaArrives`/`asiaDevaTest` (ปัจจุบัน `afterFirstKill` → ต้องเปลี่ยนเป็นหลังตนที่ 2)
3. **Map-Zone2-3 — หลังคดีที่ 6**: หน้าต่างแจ้งเตือนปีศาจฝ่าชายแดน → yama เดินลงชายแดน เจอปีศาจและบอสชายแดนโซน 2 ยืนอยู่ → เดินใกล้ → cutscene `frontier-asia-intro-v1` → สู้ 3 wave + บอสชายแดนโซน 2 — event เดิม `asiaRageBreach`

### โซน 3 (west)
1. **Map-Zone3-1 — มาถึงโซน 3**: บนแผนที่มีแค่ **Taan กับพ่อค้านรก** ยืนอยู่ (ฝั่งซ้าย ~250–380,500) กำลังถูกปีศาจ 3 ตัวรุมตี (โครงกระดูก 2 + มนุษย์หมาป่า 1) · เราต้องเดินเข้าไปช่วย (จากบันไดข้ามสะพานไปซ้าย) → เดินใกล้ → ตัดเข้าฉากต่อสู้ (ฝั่งเรามี yama + Taan) · ชนะแล้วถึงสร้างสถานที่ได้ — **แทน** event เดิม `westHypnotized` (วิญญาณถูกสะกดจิต)
2. **Map-Zone3-2 — หลังคดีที่ 3**: อยู่ๆ วิญญาณก็หยุดนิ่งไปหมด ไม่ขยับ (มี "!!!" เหนือหัว) + หน้าต่างแจ้งเตือน มีปีศาจทรงพลังบุกมาที่ชายแดน ทำให้วิญญาณในดินแดนนี้โดนผลกระทบกันหมด
3. **Map-Zone3-3**: yama เดินเข้าใกล้ → cutscene `frontier-west-intro-v1` → ปีศาจที่ชายแดน 3 wave + Boss แวมไพร · ชนะ = item **พลังสะกดจิต** (turn ถัดไปศัตรูโจมตีตัวเอง) — event เดิม `westVampireBreach`
4. **Map-Zone3-4 — หลังคดีที่ 7**: เทวดาวิ่งเข้ามาจากประตูชายแดน (เดินขึ้นบันไดจากล่างมาหน้าบัลลังก์) จะมาปราบแวมไพร → cutscene `deva-intro-west-v1` พร้อมบทพูด:
   - วาคิวรี: "ไม่ต้องห่วงเจ้าตัวเล็ก ข้ามาช่วยเจ้าแล้ว"
   - yama: "......."
   - วาคิวรี: "อ้าว! ปีศาจแวมไพร หายไปไหนแล้ว.."
   - yama: "!!-"-"
   - วาคิวรี: "..... เจ้าตัวเล็ก ฝีมือไม่ธรรมดานิ"
   → เทวดาเดินไปยืนรอตรงลานขวาของบัลลังก์ (~1380,460) ว่าเราดูแลโซนนี้ได้ไหม · เดินเข้าไปคุยเพื่อทดสอบฝีมือ · ชนะ = **หอกวาคิวรี** — event เดิม `westDevaTest`

### โซน 4 (cyberhell)
1. **Map-Zone4-1 — มาถึงโซน 4**: Taan และพ่อค้านรกไม่อยู่ โดนเทวดาจับขังในคุก (อาคารคุกบนกลาง ~1200,470 มีอยู่แล้ว) **มี effect สายฟ้าจับอยู่** · cutscene `deva-intro-cyberhell-v1` พร้อมบทพูด:
   - ลูเมน (เทวดาโซน 4): "นายเองสินะ ที่กล้าจะมาคุมดินแดนนี้ ที่นี่ไม่ง่ายเหมือนที่อื่นๆหรอกนะ"
   - yama: "นายเป็นใคร"
   - ลูเมน: "ข้าคือตัวแทน ที่เบื้องบนส่งมา เพื่อมาดูว่าเจ้าคู่ควรจะปกครองดินแดนนี้หรือไม่??"
   → ต้องสู้กับเทวดาให้ชนะก่อน 2 คนนั้นถึงจะถูกปล่อยออกมา · ชนะ = item **reset cooldown ของยมทูต** — event เดิม `cyberRescue` (เทวดายืนหน้าบัลลังก์ ~1050,470)
2. **Map-Zone4-2 — หลังคดีที่ 5**: ปีศาจฝ่าชายแดน 4 wave · Boss ชายแดน: โทรจัน-9 อาชาบุกระบบ · yama เดินเข้าใกล้ → cutscene `frontier-cyberhell-intro-v1` · ชนะได้ **หัวใจสำรอง** — event เดิม `cyberBreach`
3. **Map-Zone4-3 — หลังคดีที่ 10**: บอสโซน 4 อาร์คอน-ศูนย์ จอมข้อมูลผู้ตรวจการ พากองทัพลูกน้อง **วาร์ปหายตัวมาปรากฏที่ด้านหน้า yama** (บนแผนที่ฝั่งขวา) → cutscene `story-cyberhell-01-v2` → หน้าต่าง เตรียมเข้าฉากต่อสู้
4. **Map-Zone4-4**: หลังจากสู้กับลูกน้อง 4 wave → cutscene `story-cyberhell-reinforcements-01` ยมทูตจากโซนต่างๆ ตามมาช่วย → ตัดมาที่แผนที่ ให้มีตัวละครต่างๆ (กำลังเสริม) ยืนบนแผนที่ อยู่หลัง yama อีกฝ่ายหนึ่ง (ฝั่งซ้าย) → cutscene `story-cyberhell-reinforcements-02`
5. **Map-Zone4-5**: ถัดไป cutscene `story-cyberhell-02-v3` boss โซน 4 ควบคุมหัวหน้าโซน 1 2 3 4 อยู่ → ตัดมาที่แผนที่ มีตัวละครยืนบนแผนที่ด้วย: yama, Boss โซน 4 และหัวหน้าทั้ง 4 โซนที่โดนควบคุม (ฝั่งขวา) · หน้าต่างให้เตรียมตัวสู้: ไปหาพ่อค้านรกซื้อของก่อน หรือเดินไปหานิราจัดทีมยมทูตก่อน หรือไปนอนพักที่ศาลาน้ำชาก่อนได้
6. **Map-Zone4-6**: เมื่อชนะหัวหน้าทั้ง 4 คน → cutscene `story-cyberhell-03-v4` → ตัดมาที่แผนที่ yama ยืนเผชิญหน้ากับ Boss โซน 4 · หน้าต่างเตรียมตัวสู้ (ข้อความเดียวกับข้อ 5) · เมื่อชนะ → cutscene ฉากจบ `story-ending-01-v4` และ `story-ending-02-v3`
