## ลำดับที่เสนอให้รวมเข้าคิวหลัก

1. จบงานขนาดยามาที่กำลังทำ และงาน UI/ข้อความ/พฤติกรรมชายแดนเดิมก่อน
2. เมื่อถึงคิวภาพแผนที่ จัดพื้น ต้นไม้ ราก ขอบทางเดิน และ collision ให้ตรงกันก่อน เพื่อไม่ทำเงาซ้ำหลังย้ายวัตถุ
3. รวม L1–L2 ด้านล่างกับงานชายแดน 1–2 ข้อ 3.png/4.png เป็นพื้นที่นำร่อง หากพื้นที่นั้นยังไม่พร้อม ใช้พื้นที่ที่เปิดเดินได้จริงและผังนิ่งแล้วหนึ่งแห่ง บันทึกเหตุผล
4. หลังนำร่องผ่าน ขยายระบบเดียวกันไปโซน 2 ระหว่างแก้พื้นญี่ปุ่น/จีนและเปลี่ยนไผ่รอบนรกน้ำแข็ง จากนั้นพื้นที่ที่พร้อมอื่น ๆ ตามคิวรายละเอียดภาพเมื่อซูม
5. L3 VFX ทำหลังแสงเงาหลักผ่าน ไม่ให้การสมัครหรือข้อจำกัด export ของ Shado ขวางงานแผนที่
6. โซน 4 และชายแดน 2–3/3–4 เตรียมภาพและข้อมูลเงาได้ แต่ยังไม่เปิดเดินหรืออ้างตรวจเดินครบจนได้รับ mask จากคุณเป้

## L1 — เงาอาคารและต้นไม้บนพื้น

- [ ] กำหนดแสงหลักให้สอดคล้องกับภาพเดิมของแต่ละฉาก เงาจากอาคารและต้นไม้ต้องยึดจุดฐานและทิศทางเดียวกัน ไม่เป็นเพียงวงรีใต้ตัว
- [ ] แยกเงาสัมผัสพื้นกับเงาทอด; เงาพุ่มไม้มีรูปทรง/ช่องใบไม้ตามความเหมาะสม โดยไม่ทึบจนอ่านทางไม่ได้
- [ ] แยกข้อมูลเงาออกจาก collision/mask เดิน และตรวจเงาหลังซูม กล้องเลื่อน และการบังวัตถุ

## L2 — ตัวละครรับเงาจากฉาก

- [ ] เมื่อตัวละครเดินเข้าใต้เงาอาคารหรือต้นไม้ เงาต้องปรากฏบนภาพตัวละครและสอดคล้องกับเงาที่พื้น ออกสู่แดดแล้วกลับตามปกติ
- [ ] เป้าหมายคือเงาพาดบางส่วนของตัวได้ ไม่เพียงตรวจจุดเท้าแล้วลดความสว่างทั้งตัว ใช้ข้อมูลความสูง/รูปทรงบังแสงเท่าที่จำเป็นกับกล้องมุมคงที่
- [ ] ตรวจยามาและตัวละครร่วมฉาก โดยไม่ย้อม UI/ชื่อ/เอฟเฟกต์เรืองแสงตามไปทั้งหมด และไม่เปลี่ยนขนาดหรือจุดเท้าที่ยอมรับจากงานยามา
- [ ] ใช้เกม 2D เดิมเป็นฐานก่อน ประเมินต้นแบบ 3D เดิมได้หากมีประโยชน์ แต่ยังไม่มีคำสั่งให้ย้ายทั้งเกมหรือเปลี่ยนเอนจิน

## L3 — บรรยากาศและ Shado Game Studio

- [ ] หลังเงาถูกต้อง จึงปรับโทนแสง ความฟุ้ง หมอก/ฝุ่น/ประกายเฉพาะพื้นที่ ให้ใกล้อารมณ์ภาพอ้างอิง โดยคงทางเดินและตัวละครอ่านง่าย
- [ ] ประเมินเอฟเฟกต์จาก https://studio.playshado.com กับฉากจริงหนึ่งชนิดก่อน เช่น ไฟพร้อมควัน/ประกาย ส่งออกแล้วจึงวัด loop ความโปร่งใส ขนาดไฟล์ และต้นทุนวาด
- [ ] ผลทดลองในแชตนี้: เปิดตัวอย่างไฟ 3 layers และฉาก sample 2.5D isometric ได้; เมนู Effect sprite sheet ระบุ PNG + frame JSON แต่เมื่อกดส่งออกขึ้น Plus/Whitelist จึงยังไม่มีไฟล์ที่นำเข้าอเวจี และยังไม่ได้พิสูจน์เงารับบนตัวละครใน Studio
- [ ] ไม่ถือข้อความโฆษณา “เปิดได้ทุกไฟล์” หรือ VFX จำนวนมากเป็นหลักฐานเข้ากับเกมเดิม ไม่ผูกงานเงากับการเชื่อม AI/MCP; การเชื่อมต่อยังไม่ได้ดำเนินการ
- [ ] ใช้ตัวเลือกฟรีที่ส่งออกได้จริงหรือเอฟเฟกต์เดิมต่อได้หากติดข้อจำกัด บันทึกเงื่อนไขก่อนผูก pipeline กับบริการ ห้ามซื้อแพ็กเกจ/ยอมรับข้อตกลงสมัครบริการแทนผู้ใช้โดยอาศัยใบงานนี้

## เกณฑ์ตรวจรับ

- ฉากทดลองมีบ้านหนึ่งหลัง ต้นไม้หนึ่งต้น พื้น และตัวละครเดินเข้า–ออกเงา เห็นภาพเปรียบเทียบก่อน/หลังใน renderer จริง
- ตรวจแดด เงาบางส่วน และเงาเต็มตัว การเดินสองทิศทาง ซูม/กล้องเลื่อน การบังลำดับวัตถุ รวมถึงไม่ซ้อนเงาดำสองรอบบนภาพที่มีเงาวาดติดมา
- เส้นทางและเซฟเดิมทำงานเหมือนเดิม; ตรวจประสิทธิภาพบน viewport/เครื่องเป้าหมายและ reduced motion ตามระบบเดิม บันทึกผลจริง ไม่ตั้งตัวเลข FPS ที่ยังไม่ได้วัด
- รันการตรวจที่เหมาะกับการเปลี่ยน renderer และ regression ที่เกี่ยวข้อง เก็บภาพและข้อจำกัด ส่งผ่านกระบวนการ release เดิม ไม่อ้างว่างานจบจากการเปิด sample หรือจาก tests อย่างเดียว
