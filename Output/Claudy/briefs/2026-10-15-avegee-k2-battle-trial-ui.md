## งาน
1. **เมนูเอียง (ทั้งต่อสู้และสอบสวน)** ตามภาพตัวอย่าง:
   - ปุ่มแต่ละอันเป็นทรงสี่เหลี่ยมด้านขนาน เอียงเล็กน้อย (skew ราว −8° ถึง −12°) ตัวหนังสือในปุ่ม**ไม่เอียง** (skew กลับที่ข้อความ)
   - ปุ่มเรียงลงแบบขั้นบันได แต่ละปุ่มเลื่อนขวาเล็กน้อย (~6–10px ที่ 1678 กว้าง) เหมือนในตัวอย่าง
   - ปุ่มที่เลือก = ทอง, ที่เหลือ = แดงเลือดหมูขอบทอง (ตามเดิม) ใช้ token สีเดิมในไฟล์ css
2. **เมนูย่อย (flyout) แบบตัวอย่าง** — โผล่ทางขวาของปุ่มที่เลือก ทับขอบปุ่มเล็กน้อย เรียงขั้นบันไดเอียงเหมือนกัน:
   - สอบสวน "ที่ไหน/ใครคุม/ความแรง": แถบเตี้ย (~40px) มีภาพ thumbnail เต็มพื้นหลังแถบ + ชื่อทับบนภาพ — **แทนกล่องสูงเรียงแนวตั้งที่มีอยู่ตอนนี้** ถ้ารายการเกินพื้นที่ ให้เลื่อนได้ในตัว flyout
   - ต่อสู้ "พลัง/ไอเท็ม": แถบเดียวกัน มีไอคอนพลัง + ชื่อ + ค่า MP ทางขวา (ตามภาพ Battle9)
3. **ปุ่มกดไม่ค่อยติด** — หาสาเหตุจริงก่อนแก้ แล้วเขียนในรายงาน ตรวจอย่างน้อย:
   DOM ถูก render ใหม่ระหว่าง pointerdown→click (ปุ่มเดิมหายไป), ชั้น scrim/flyout ที่ซ่อนอยู่แต่ยังรับคลิก (opacity 0 แต่ไม่มี `pointer-events:none`),
   transition ที่ทำให้ปุ่มขยับตอนกด, พื้นที่คลิกหลัง skew, busy-guard ที่ล็อกค้าง
   ใช้ `pointerdown`/`click` ให้ทำงานครั้งเดียวและกดติดทุกครั้ง · เพิ่มเทสต์ที่จับสาเหตุนั้นได้
4. **ตำแหน่งตัวละครต่อสู้**: ทีมเราอยู่ชิดกันขึ้น (ระยะห่างระหว่างตัว ~60–65% ของเดิม) และกลุ่มขยับเข้าหาศัตรูเล็กน้อย — ดู Battle9: ทีมอยู่ราว 20–38% ของความกว้าง ศัตรู ~73%
   คงลำดับยืน (formation) และการก้าวออกมาของตัวที่ถึงเทิร์นไว้
5. **รูป profile ด้านล่างใหญ่ขึ้น** ตาม Battle9: การ์ดทีมเราสูงราว 120px ที่ 1678 กว้าง (ใหญ่ขึ้น ~2.5 เท่าจากตอนนี้) ชื่อใต้รูป แถบ HP เขียว + แถบ MP/พลัง
   การ์ดศัตรูขวาล่างใหญ่ขึ้นตามสัดส่วน · หน้าสอบสวน: รูปยมฯ ซ้ายล่าง ~115px + ชื่อ + แถบ ตาม Comment8
6. คงพฤติกรรมเดิมทั้งหมด: เลือกพลังแล้วคลิกศัตรู = ใช้ทันที, busy guard, cooldown, คิวเทิร์น, กติกาสอบสวน/warrant
