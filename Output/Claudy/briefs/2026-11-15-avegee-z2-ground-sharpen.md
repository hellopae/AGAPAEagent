## ขั้นตอน
1. ทุกบริเวณ fallback (16 จุด) ให้วาดรายละเอียดใหม่ที่ความละเอียด 2× native
   - ให้คมเท่ากับ native รอบข้าง โดยวัด sharpness เทียบกับวงแหวนรอบ ๆ
   - ใช้โครงสร้างจาก v2 core เดิม ตำแหน่งขอบผา บันได ราว สะพาน และน้ำต้องไม่ขยับ
   - ใช้ ImageGen แบบ image-to-image หรือ inpaint ได้ ขอแค่สี พุ่มไม้ ใบไม้แดง และหินกลืนกับ native รอบข้าง
2. บันไดเฉียง lava-bank: คืนขั้นบันไดตามจังหวะของ v2 บนพื้น native
3. ต่อรอยด้วยวงแหวน feather แบบเดิม แล้วส่งชุดใหม่เป็น `v8/`
   - 20 chunk ขนาด 2048 px, webp q90, fullPx 9830×6554, grid เดียวกับ v7
   - ลงทะเบียนพิกเซลตรงกับ v7 ทุกจุดนอกบริเวณที่แก้
4. ส่งหลักฐานที่ `docs/art-reviews/2026-11-15-z2-ground-sharpen/`
   - ภาพเทียบก่อนและหลังทุกบริเวณ
   - sharpness ก่อนและหลังเทียบวงแหวน
   - structure check (≤4 px) ของบริเวณที่แก้
   - `overview.jpg`
   - คำสั่งติดตั้ง `python3 scripts/install-ground.py <pack>/v8 --zone 2 --name v8 --activate` (เขียนไว้ใน README อย่ารันเอง)

## เกณฑ์รับงาน
1. ทั้ง 16 บริเวณมี sharpness ไม่ต่ำกว่า 85% ของวงแหวนรอบข้าง และไม่เห็นรอยต่อที่ซูมเกม

4. นอกบริเวณที่แก้ พิกเซลเหมือน v7
