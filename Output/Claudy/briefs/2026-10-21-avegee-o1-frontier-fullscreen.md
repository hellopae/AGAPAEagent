## งาน
1. **เต็มจอ**: หน้าแผนที่นอกชายแดน (เส้นทางระหว่างโซน + ด่านชายแดน ถ้าใช้ view เดียวกัน) ภาพแผนที่เต็ม viewport ทุกขนาด (1440×900, 1280×720, มือถือ 390×844 แนวตั้ง/แนวนอน)
   - **ลบแถบสีด้านล่าง (footer)** และแถบ header ออก · ภาพไม่มีกรอบ/ขอบสี
   - ต้องยังมีทางกลับเมือง: ใช้ปุ่มไอคอนเล็กลอยโปร่งที่มุมบนซ้าย (← อย่างเดียว ขนาดแตะได้ ≥ 44px) — ถ้าระบบมีทางกลับอื่นอยู่แล้ว (เดินกลับประตูเมือง) ให้รายงาน · ปุ่ม overview ย้ายเป็นไอคอนลอยเล็ก หรือตัดออกถ้าไม่จำเป็น — **รายงานว่าเลือกอะไรเพราะอะไร**
   - minimap/ความคืบหน้าที่อยู่ใน footer: ถ้าเป็นข้อมูลจำเป็น ทำเป็นชั้นลอยโปร่งเล็กมุมจอ ไม่ใช่แถบ
2. **เข้าโซนอัตโนมัติ**: เดินถึงประตูโซน (ระยะเดียวกับที่ปุ่มเคย enabled) → เข้าโซน/เล่นคัตซีนประตูทันที **ไม่มีปุ่มกดเข้าประตู**
   - มี latch กันเข้าซ้ำ (แบบ S1: ต้องเดินออกจากระยะก่อนถึงจะ trigger ใหม่) · ไม่ trigger ระหว่างต่อสู้/คัตซีน/โหลด
   - คัตซีนมอบเงิน/ชุด (บอส 1–3) ยังเล่นครั้งเดียวตามเดิม — ห้ามทำให้ของซ้ำ
3. **บอสนำทางหายหลังเปิดโซน**: เมื่อ guide พาถึงโซนใหม่และบอกลาแล้ว (farewell=true)
   - บอสตัวนั้น **ไม่ปรากฏอีก** บนเส้นทาง, ที่ด่านชายแดน (`CHALLENGE_STAND.*`), และในเมือง — รวมจุดคลิกที่มองไม่เห็น
   - เดินเส้นทางเดิมซ้ำ (ไปกลับระหว่างโซนที่เปิดแล้ว) ทีมบนแผนที่และในศึก = **ยามา + นิรา เท่านั้น**
   - ถ้าเห็นว่าทีมด่านชายแดน (ยมทูต/guard) ต้องเปลี่ยนด้วยหรือไม่ชัด → ไม่เปลี่ยน แต่ใส่ในรายงานเป็นคำถามให้คุณเป้
   - เซฟเก่าที่ farewell แล้ว: โหลดแล้วบอสต้องไม่โผล่ · ห้าม reset เงิน/ชุด
4. **หลักฐาน**: Playwright (chromium ติดตั้งแล้ว) ผ่าน local server — ภาพไว้ที่ `/tmp/o1/` (ไม่ commit):
   - เส้นทาง th→asia ก่อน/หลัง ที่ 1440×900 และ 390×844 (เต็มจอ ไม่มีแถบ)
   - เดินเข้าประตูแล้วเข้าโซนเองโดยไม่กดปุ่ม (ภาพก่อน–หลัง หรือ log ลำดับ state)
   - เดินซ้ำหลัง farewell: บนแผนที่มีแค่ยามา+นิรา, ศึกมีแค่สองคน, ด่านชายแดนไม่มีบอสแล้ว
   - console ไม่มี error
5. เทสต์ใหม่ครอบข้อ 2–3 (auto-enter + latch, guide หายหลัง farewell, ทีม repeat = 2 คน, โหลดเซฟ) · แก้เกณฑ์เทสต์เก่าที่คาดปุ่มเข้าประตู/footer ให้ตรงคำสั่งใหม่ (ระบุในรายงานว่าแก้ข้อไหนเพราะอะไร) · `node --test tests/*.test.mjs` 0 แดง
6. cache-bust suffix `-o1` เฉพาะไฟล์ที่แก้ (รักษา suffix เดิม) · commit ใน branch ข้อความขึ้นต้น `O1:` · push branch ได้ · **ห้าม push main** (Dale merge)
