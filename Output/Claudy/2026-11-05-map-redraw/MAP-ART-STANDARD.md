## ชั้นภาพ (ล่าง → บน) — ทุกชั้นแยกไฟล์ พิกัดร่วมเดียวกัน
1. **Sky** — ใช้ท้องฟ้าโซน 1 เดิมได้ (ปรับโทนตามโซน)
2. **Mountains / ฉากไกล** — RGBA โปร่งใสบน-ล่าง วางเหนือ Sky ได้ ขยับ/เบลอแยกได้ (parallax/DOF)
3. **ของเหลว** (น้ำ/ลาวา/น้ำตก) — วาดเป็นผืนต่อเนื่อง **ไม่มีหิน ต้นไม้ อาคารปนในชั้นนี้** + loop 12 เฟรม × 3 ลูป ไหลตามทิศจริง
4. **Terrain** — พื้นภูมิประเทศต่อเนื่องผืนเดียว RGBA (ร่องน้ำ/ลาวา = alpha จริง ไม่ใช้สีขาว/ดำแทน) รวมบันได สะพาน ตลิ่ง
   **ไม่มีอาคาร ต้นไม้ พุ่ม เสาไฟ ราวสูง** ติดในพื้น · รายละเอียดที่วาดแยกส่วนต้องล็อก silhouette/alpha จากภาพฐานร่วม (ไม่เอาภาพต่างคนต่างวาดมาต่อขอบตรง ๆ)
5. **Objects** — อาคาร ประตู ต้นไม้ พุ่ม หิน เสาไฟ รั้ว ราว/เสาสะพาน ปากถ้ำ: **RGBA แยกชิ้นละไฟล์** ตัดขอบโปร่งใส
   มี `foot` (จุดฐานกลางล่างที่แตะพื้น) สำหรับเรียงหน้า–หลังกับตัวละคร · ราว/เสาที่ตัวละครต้องเดินผ่านหลัง/หน้า แยกเป็นชิ้นหน้า (front) กับหลัง (back)
6. เมฆ/เงาเมฆ — ใช้ของเดิมโซน 1 ได้

## ขนาดและไฟล์
- Terrain atlas กว้าง **≥ 2300 px** (ไม่ต่ำกว่าโซน 1) อัตราส่วนตามผัง · แบ่ง tile 512 px: PNG + WebP lossless gutter 2 px
- `tile-review.json` ยืนยันต่อ tile กลับเป็น atlas ได้ตรงทุกพิกเซล · `manifest.json` (world, tiles, layers, liquids, layerOrder)
- `layout.json` — วัตถุทุกชิ้น: `id, sprite, x, y, w, h, flipX, foot:[x,y], layer(back|mid|front), category` (พิกัด atlas)
- `composite-preview.jpg` (กว้าง 1600) ประกอบทุกชั้น · `terrain-alpha-preview.png` · `index.html` พรีวิวโหลดเฉพาะรอบกล้อง + ซูม 2 ระดับ + เปิด/ปิดชั้น + เล่น/หยุดน้ำ (ต้นแบบ terrain-seamless)
- `README.md` ภาษาไทยสั้น · `generation-prompts.json` (prompt เต็ม/ครั้ง) · ต่อท้าย ledger จำนวนครั้ง ImageGen
- **ขนาด output ต่อ run ≤ 80 MB** — เก็บเฉพาะไฟล์สุดท้ายที่ใช้ ลบภาพทดลองที่ไม่ใช้ก่อนจบ (wrapper จะ `git add -A` ทุกอย่างที่เหลือ)
