**ปัญหาไม่ใช่ "ยังไม่ได้ทำ SEO" แต่คือ AI มองไม่เห็นเว็บนี้เลย**

ผลงานทั้ง 26 ชิ้นและเว็บโปรเจกต์ 7 ตัวถูกสร้างด้วย JavaScript ตอน runtime
(`renderPort()` / `renderWeb()` ยัดเข้า DOM ด้วย innerHTML) HTML ที่ส่งออกไปมีแต่ `<div>` ว่าง

Googlebot render JS ได้ จึงเห็น (รอบสอง) แต่ **GPTBot / ClaudeBot / PerplexityBot ไม่ execute JS**
— Vercel วัด traffic บอทจริงพบว่าดึงไฟล์ JS มาแต่ไม่รัน แปลว่า ChatGPT/Claude/Perplexity
ไม่เคยเห็นผลงานของ AGAPAE เลยสักชิ้น ทั้งที่ 2RichMap / Invest AI / TANAPAT คือของที่ดีที่สุด

เทียบคู่แข่งไทย 4 ราย (pagdesign, roundandnine, designbydinsor, graphicdesignthailand)
มี robots.txt + sitemap + meta description + OG + JSON-LD **ครบทุกราย** — AGAPAE ได้ 0/5

## แผนลงมือ

### เฟส 0 — เก็บ baseline ก่อนแตะอะไร (30 นาที)

ถาม AI 5 ตัว (ChatGPT, Claude, Gemini, Perplexity, AI Overviews) ว่า
*"AGAPAE Design คือใคร"* / *"รับออกแบบ packaging พร้อมพิมพ์ ที่ไหนดี"*
บันทึกคำตอบดิบไว้ ไม่งั้นทำไปแล้ววัดไม่ได้ว่าดีขึ้นจริงไหม

ทำ Search Console + Bing Webmaster ให้เรียบร้อยด้วย (ตอนนี้ยังไม่มี)

### เฟส 1 — ของด่วน รวมราว 3 ชั่วโมง

เรียงตามคุ้มค่าต่อเวลา ทำได้ทันทีโดยไม่ต้องแตะโครงสร้าง:

1. **ลบไฟล์เทมเพลตเก่าที่ยัง live** — `inc/sendEmail.php`, `styles.html` และไฟล์ที่ไม่ถูกอ้างถึง
   (~110 ไฟล์ 64 MB) · ตัวแรกรั่วอีเมลให้บอทเก็บ **ทำก่อนเพื่อน** — 10 นาที
2. **แก้ "0 Years / 0 Projects"** ให้ HTML มีเลขจริงตั้งแต่แรก แล้วให้ JS นับขึ้นทับ — 5 นาที
3. **เติม `<head>`** — meta description, canonical, OG + Twitter card, favicon,
   theme-color (แชร์ LINE ตอนนี้ได้กล่องเปล่า) — 30 นาที
4. **ใส่ `defer` ให้ Chart.js** — ใช้แค่ตอนกดปุ่ม Radar Chart คน 95% ไม่กด — 5 นาที
5. **แก้ hero poster ซ้ำ** — `index.html:534` ใช้ poster มือถือกับทุกจอ โหลดเปล่า 111 KB
   ช่วง LCP บนคอม — 10 นาที
6. **robots.txt + sitemap.xml** — เปิด AI crawler ทุกตัว โดยเฉพาะ `OAI-SearchBot`
   (บล็อก = ไม่โผล่ใน ChatGPT search) — 20 นาที
7. **JSON-LD** `ProfessionalService` + `WebSite` + `ItemList` (เว็บ 7 ตัว) + `VideoObject`
   (งาน motion 2 ชิ้น) · เหตุผลคือ **ชื่อแบรนด์ชนกัน** — ค้น "AGAPAE Design" เจอ
   Agape Design Studio / Agape Design Co. / Agape Designs LLC ปนกันหมด ต้องใช้ `sameAs`
   แยกตัวตน (ไม่ใช่ทำเพื่ออันดับ) — 45 นาที
   *Dale ร่าง JSON-LD ตัวเต็มไว้แล้วในรายงาน ใช้ข้อมูลจริงจาก index.html ล้วน
   ฟิลด์ที่เว็บยังไม่มี (ที่อยู่ เบอร์โทร ชื่อจริง) ทำ TODO ไว้ ไม่แต่งขึ้นเอง*
8. **llms.txt** — 10 นาที (ดูหมายเหตุด้านล่าง)

### เฟส 2 — แก้รากปัญหา (1–2 วัน)

**2.1 เอาเนื้อหาออกจาก JavaScript** (4–6 ชม.)
เขียนผลงานเป็น HTML จริงไว้ในหน้าตั้งแต่แรก แล้วให้ JS มาเสริม (progressive enhancement)
หรือทำ build step เล็กๆ ที่ pre-render `PORT_ITEMS`/`WEB_ITEMS` ลง HTML ตอน deploy
— ข้อนี้คือ 80% ของผลลัพธ์ทั้งหมด

**2.2 แตกหน้าย่อย** (3–5 วัน)
ตอนนี้มี URL เดียว Google จึงมีของให้จัดอันดับแค่หน้าเดียว ควรมีอย่างน้อย:
หน้ารายบริการ (ออกแบบ packaging / สิ่งพิมพ์องค์กร / ภาพประกอบ / animation),
หน้า About ที่เล่าเรื่องโรงพิมพ์ 40 ปี, หน้า FAQ จริง

**2.3 ใส่ชื่อผลงานจริง** (2–3 ชม. — งานของเป้ ไม่ใช่งานโค้ด)
ตอนนี้ alt/title ของผลงาน 24 ชิ้น gen ด้วย loop ได้ "Art Work 3" / "Printing Work 1"
(`index.html:816-820`) ซึ่งไร้ค่าทั้งกับ Google และ AI

**2.4 เก็บงาน performance** — CLS ที่ portfolio grid (masonry + lazy image ไม่มี
width/height, `index.html:911,916`), hero-title `opacity:0` + delay หน่วง LCP ~1.2 วิ
โดยไม่เกี่ยวกับความเร็วเน็ต (`index.html:118`), hero video 2.4 MB โหลดทันที

### เฟส 3 — เนื้อหาที่ลอกไม่ได้

จาก Idea Card ของ Minnie 8 ใบ เรียงตามคุ้มค่า:

1. **ตารางเทียบกระดาษ** — ถ่ายกระดาษจริงทุกชนิดพิมพ์งานเดียวกัน (1 สัปดาห์)
   ใช้ทดสอบสมมติฐานทั้งชุดว่า "เนื้อหาจากของจริงติดอันดับไหม" ก่อนลงแรงหนัก
2. **พจนานุกรมศัพท์งานพิมพ์** 60–100 คำ พร้อมรูปของจริง (2–3 สัปดาห์)
   คำนิยามสั้นๆ คือรูปแบบที่ LLM หยิบไปอ้างง่ายที่สุด
3. **คลังไดคัทฟรี** 20–30 แบบที่ผ่านการพิมพ์จริง (1–2 สัปดาห์) — แม่เหล็ก backlink
4. **เครื่องมือฟรี** คำนวณตัดกระดาษ (1–2 วัน) แล้วค่อยต่อด้วยเช็กไฟล์ก่อนส่งพิมพ์
5. Case study เปิดหลังบ้าน · บันทึก AI ในโรงพิมพ์ · ซีรีส์ animation อธิบายงานพิมพ์
   — เก็บไว้หลังรู้ว่าหมวดไหนมีคนสนใจจริง

**อย่าไล่คำตรงๆ** — "รับออกแบบกราฟิก" / "รับวาดภาพประกอบ" ถูก marketplace ยึดหมด
(Fastwork โฆษณา "เริ่มต้น ฿500") เว็บเดี่ยวชนะยาก และต่อให้ชนะก็ได้ลูกค้าผิดกลุ่ม

**ช่องที่มีจริงคือคำผสม "ออกแบบ + พิมพ์"** เช่น "ออกแบบ packaging พร้อมพิมพ์",
"ออกแบบสิ่งพิมพ์หน่วยงานราชการ", "ภาพประกอบไทยร่วมสมัย" — freelance ตอบไม่ได้
โรงพิมพ์ทั่วไปออกแบบไม่สวย AGAPAE ทำได้ทั้งคู่

**ไม่มีตัวเลข search volume จริง** ในรอบนี้ (ไม่มี Keyword Planner/Ahrefs)
ที่สรุปมาจากการดูองค์ประกอบ SERP ล้วน — อย่าเอาไปอ้างเป็นตัวเลข

## สิ่งที่ตัดสินใจว่า "ไม่ทำ" และเหตุผล

- **hreflang** — เว็บมี URL เดียว ใส่ไปไม่มีผล เสี่ยงเป็น signal ขยะ
  ใช้ `lang="en"` รายบล็อก + `inLanguage:["th","en"]` ใน JSON-LD แทน
- **FAQPage schema ตอนนี้** — เว็บยังไม่มีเนื้อหา FAQ จริง ใส่ markup ลอยๆ ผิดนโยบาย
  Google โดนลดอันดับได้ · ต้องเขียน section FAQ จริงก่อน (แล้วค่อยใส่ — AI ชอบหยิบมาก)
- **ไล่คำค้นหลักที่ marketplace ยึด** — ดูหัวข้อคีย์เวิร์ดด้านบน

**llms.txt — ทำได้แต่อย่าคาดหวัง**
Reese หาหลักฐานแล้วพบว่า Google เขียนในเอกสารทางการว่าไม่จำเป็นต้องสร้างไฟล์พวกนี้
และไม่มี AI เจ้าไหนประกาศว่าใช้จริง (Mueller เทียบกับ keywords meta tag)
Dale จัดไว้ในชุด quick win เพราะต้นทุนแค่ 10 นาที — **ข้อสรุปของ Claudy: ใส่ก็ได้
เพราะถูกมาก แต่อย่านับเป็นทางออก** ตัวที่ได้ผลจริงคือเฟส 2.1
