## หลักที่ใช้เขียน
- คุยเป็น **บรรยากาศล้วน** (คำตอบคุณเป้ ข้อ D8) — ไม่มีบทไหนใบ้คดี บอกว่าใครผิด บอกผลสำนึก ให้ของ หรือบอกคำตอบการตัดสิน
- ตัวแปรใช้เฉพาะที่ Vera §4.4 ระบุ: `{name} {me} {title} {zone} {soul} {station} {sentence} {sentenceN} {progress} {queueRank} {queueLen} {wait} {back} {hunger} {morale} {food} {i} {p} {my} {na}`
- วิญญาณ คนงาน ถ้อยคำท้ายใบ ใช้ `{i}{p}{my}{na}` เสมอ ไม่เขียน "ผม/ครับ/ดิฉัน/ค่ะ" ตรง ๆ
- **คำถามในบทวิญญาณ/คนงานลงท้ายด้วย `{na}` ไม่ใช้ `{p}`** เพราะ `{p}` ของผู้หญิงคือ "ค่ะ" ซึ่งใช้ลงท้ายคำถามไม่ได้ ("ใช่ไหมค่ะ" ผิด · "ใช่ไหมนะคะ" ถูก)
- ยมทูตเขียนด้วยสรรพนามประจำตัว: ทัณฑ์ = "ข้า" ห้วนสมัยเก่า · เพลิง กานต์ บุญ ดำ = "ผม/ครับ" · นิรา = "ดิฉัน/ค่ะ/คะ" · ยักษ์ = "ข้า" · พ่อค้า = "ข้า" ไม่ลงท้ายครับ/ค่ะ (ตรงกับ `line` เดิมในเกม)
- ไม่กล่าวหาตัวละครจริง ไม่อ้างหลักศาสนา คัมภีร์ หรือคำสอนเฉพาะ — คำอย่าง สวรรค์ เกิดใหม่ กรรม ชดใช้ ใช้ในฐานะศัพท์ของเกมที่มีอยู่แล้ว ไม่ได้อ้างข้อเท็จจริงทางศาสนา → **ไม่มีบรรทัด `// CHECK`**
- ความยาว: ตั้งใจให้ทุกบทสั้นกว่า 60 ตัวอักษรไทย (นับรวมสระและวรรณยุกต์) โดยเผื่อที่ให้ตัวแปรที่ขยายตอนรัน

## สถานะที่ตัดสินเอง (สเปกกำหนดไว้แล้ว ไม่ได้เพิ่มสถานะใหม่)
ยมทูตใช้ 7 สถานะตาม Vera §7: `idle` ว่าง · `supervise` คุมวิญญาณ · `build` สร้าง/ซ่อม · `escort` นำส่ง · `hungry` หิว · `tired` ล้า/พักฟื้น · `first` ครั้งแรก

| key | เงื่อนไขที่โค้ดควรเลือกใช้ |
|---|---|
| `crew.*.first` | `g.talk.seen[actorId]` ยังไม่มี (บทเดียว ใช้ครั้งแรกแล้วไม่วนซ้ำ) |
| `crew.*.hungry` | `c.hunger` ต่ำ (ใช้ `{hunger}` ได้ แต่ชุดนี้ไม่ได้ใช้ เพราะบทอ่านได้โดยไม่ต้องมีตัวเลข) |
| `crew.*.tired` | ล้า/พักฟื้น หรือกำลังใจต่ำ (`{morale}` ใช้ในบางบท) |
| `crew.*.supervise` | `slot.soul` มีอยู่ → ใช้ `{soul} {station} {sentence} {progress}` ได้ |
| `crew.*.build` / `escort` | `c.buildK` / `c.escort` |
| `nira.*` | `queueEmpty` คิว 0 · `queueLong` คิวเกินปกติ · `karmaHigh` กรรมท่านอยู่ชั้น warn/bad · `orderLow` ระเบียบชั้น "เริ่มรวน" ลงไป |
| `queueSoul.waitShort/waitLong` | `soul.waited` ≤ 40 / > 40 |
| `queueSoul.returned` | `soul.back` มีค่า |
| `queueSoul.overflow` | คิวเกิน `BAL.queueMax` |
| `diagnosisClosing.*` | ตามตารางสถานะแบนเนอร์ Vera §2.5: `tarangPending` = ตะรางยังไม่ตรวจ · `ked` = ตรวจแล้ว repentant · `notKed` = ตรวจแล้ว !repentant · `heaven` = gate checked karmaLeft 0 · `reborn` = karmaLeft > 0 · `pure` = `soul.pure` |
| `cellSoul.<สถานี>.early/mid/late` | แนะนำแบ่ง `progress` ต่ำกว่า 34 / 34–66 / มากกว่า 66 (Toby ปรับได้) |
| `worker.waiting` | `w.reason` = รอค่าจ้าง หรือ รอเสบียง |
| `worker.zone.<โซน>` | `w.homeZone` · โค้ดสุ่มแทรกเป็นบทคั่นได้ |

ข้อควรระวังตอนต่อโค้ด: ตัวแปร `{station}` ในบทคนงานใช้เฉพาะ `supervise` และ `buildRepair` (เป็นงานที่มีสถานีเสมอ) ส่วนบทอื่นไม่มี `{station}` · ในบทที่มี `{progress}` ให้ใส่เป็นตัวเลขล้วน เพราะบทเติมเครื่องหมาย `%` ไว้เองแล้ว

## สิ่งที่ตัดสินเองนอกสเปก
1. **คำถามลงท้ายด้วย `{na}` ไม่ใช้ `{p}`** ในบทวิญญาณ/คนงาน เพราะ `{p}` ของผู้หญิงและเด็กหญิงคือ "ค่ะ" ซึ่งใช้ลงท้ายคำถามไม่ได้ (ผลคือ "ใช่ไหมนะคะ/นะครับ" แทน "ใช่ไหมค่ะ") — เป็นข้อควรรู้ของคนที่เพิ่มบทต่อ ไม่ต้องแก้โค้ด
2. **คนงานใช้ `{i}{p}` ไม่ใช้ "ข้า" ตามตัวอย่าง §4.5** เพราะ §7 และหัว `data.js` กำหนดให้วิญญาณ/คนงานใช้โทเค็นเสมอ (ตัวอย่างโทนในสเปกเป็นเพียงตัวอย่าง) · คนงานไม่มีฟิลด์เพศ `voice()` จะตกเป็นชาย "ผม/ครับ" ตามค่าเริ่มต้น
3. **สรรพนามยมทูต**: ทัณฑ์ใช้ "ข้า" (ตาม `says` เดิมและตัวอย่าง Vera "อย่ามาเร่งข้า" · `line` เดิมของทัณฑ์ใช้ "ผม" ซึ่งไม่เข้ากับ `says` ของเขาเอง) · เพลิง กานต์ บุญ ดำ ใช้ "ผม/ครับ" ตาม `line` เดิม · ยักษ์และพ่อค้าใช้ "ข้า" ไม่ลงท้ายครับ/ค่ะ ตามบทเดิมที่ไม่มีหางเสียง
