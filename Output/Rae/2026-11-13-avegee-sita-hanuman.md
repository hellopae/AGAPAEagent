## 0. กติกาน้ำเสียงที่ใช้ทั้งชุด (Toby ยึดตามนี้ตอนเสียบ)

| ตัวละคร | สรรพนาม / ท่วงทำนอง |
|---|---|
| นางสีดา | "หม่อมฉัน ... เจ้าค่ะ" สงบ นิ่ง สุภาพ ไม่ร้องไห้ฟูมฟาย ไม่ขอร้องเพราะสถานะของตน ขอเพียงให้ตัดสินจากความจริง |
| หนุมาน | "ข้า" องอาจ ภักดี พูดตรง ไม่ตลก ไม่ยียวน เรียกพระรามว่า "พระราม" / "พระรามเจ้า" เรียกนางสีดาว่า "พระนาง" |
| ยมบาทน้อย | "ผม ... ครับ" ต่อหนุมานและนางสีดาให้เรียก "ท่านหนุมาน" / "พระนาง" (ให้ตรงกับสรรพนามที่ใช้ในซีรีส์สัญญาณ cyber-signal) |
| นิรา | "ดิฉัน ... ค่ะ" เรียกผู้เล่นว่า "ท่านคะ" ใช้ศัพท์ทะเบียน/เลขกำกับ เสียงนิ่ง ละเอียด |
| บรรยาย | "บรรยาย:" นำหน้า ตามแบบ SIGNAL_STORIES |

หมายเหตุชื่อ: ในโค้ดบทพูดใช้ "ยมบาทน้อย" เป็นชื่อผู้พูด ส่วนข้อความ UI/ท่าไม้ตายใช้ "ยามา" (เช่น ABILITY_REWARDS) ใบนี้ใช้ "ยมบาทน้อย" ในบทพูด และ "ยามา" ในหน้าต่างแจ้งเตือน ให้ตรงกับของเดิม

หลักที่ล็อกไว้: บัญชีผิด ไม่ใช่นางสีดาผิด · ไม่แตะเรื่องลุยไฟ ไม่แตะเรื่องถูกเนรเทศ ไม่แตะเรื่องความบริสุทธิ์ทางกาย · พระรามไม่ปรากฏตัว มีแต่คำบัญชาที่หนุมานถือมา · ไม่มีใครล้อเลียนหรือพูดหยาบ

## 2. หน้าต่างแจ้งเตือน (ข้อความสั้น พร้อมวางใน toast/modal)

**N1 · คดีเข้าคิว (ก่อนเริ่มคดี)**
- หัวข้อ: วิญญาณนามสูงมาถึงแล้ว
- ข้อความ: วิญญาณนางสีดามาถึงคิวพิจารณา ตามบัญชีระบุว่าต้องรับโทษ แต่รายละเอียดในแฟ้มมีข้อน่าสงสัย โปรดไต่สวนอย่างรอบคอบ
- ปุ่ม: เริ่มไต่สวน

**N2 · หนุมานลงมา (หลังตัดสิน)**
- หัวข้อ: หนุมานลงมาแล้ว
- ข้อความ: ทหารเอกของพระรามลงมารับพระนางกลับ เขาไม่ใช่ศัตรู แต่ต้องการเห็นว่าท่านปกป้องพระนางได้จริง
- ปุ่ม: รับมือ

**N3 · ชนะ**
- หัวข้อ: หนุมานยอมรับ
- ข้อความ: ท่านผ่านการทดสอบของหนุมาน พระนางยังปลอดภัย
- ปุ่ม: ต่อ

**N4 · แพ้ (ให้ลองใหม่)**
- หัวข้อ: หนุมานรอท่านอยู่
- ข้อความ: หนุมานหยุดมือไว้ก่อน ท่านตั้งหลักแล้วลองอีกครั้งได้
- ปุ่ม: สู้อีกครั้ง

**N5 · พบรหัสแปลกปลอม (หลังฉากนิรา)**
- หัวข้อ: พบรหัสผู้แก้ที่ไม่มีในทะเบียน
- ข้อความ: นิราพบว่าแฟ้มของนางสีดาถูกแก้จากด้านนอก รหัสผู้แก้คือ [PHANTOM-404] เพิ่มบันทึกลงสมุดแล้ว
- ปุ่ม: ดูบันทึก

**N6 · บันทึกในสมุด (journal)**
- PHANTOM-404: แฟ้มนางสีดาถูกแก้โดยผู้ไม่อยู่ในทะเบียนสาขาใด วิญญาณยังไม่ถึงกำหนดแต่ถูกเรียกลงมา นิราจะตรวจแฟ้มเก่าย้อนหลังต่อ

**N7 · แบนเนอร์เริ่มสู้ (battle banner)**
- ศึกปกป้องพระนาง · ท่านหนุมาน

## 3. สำนวนคดี: นางสีดา (รูปแบบเดียวกับ QUEST_CASES)

โครงนี้เป็นร่าง Toby ปรับ `quest`, `sp` (สถานี) และรหัสบาป `s` ให้เข้ากับระบบ · ข้อกล่าวหาเป็นของปลอมจึงไม่ผูกศีล (ดูหมายเหตุใต้บล็อก)

```js
{
  k:'sitaledger', quest:'sqSita', zone:'th', sex:'f', sp:/*Toby เลือก*/0, kind:'innocent',
  name:'นางสีดา', who:'ชายาแห่งพระราม ผู้ถูกเรียกลงมาตามบัญชี',
  face:'ใครเห็นก็ก้มศีรษะให้โดยไม่ต้องบอก สงบ นิ่ง ไม่แสดงความหวั่นไหวแม้ถูกเรียกลงมายังที่นี่',
  seen:[
    { t:'ตามบัญชี ระบุว่าเป็นผู้ก่อเหตุให้เกิดศึกกรุงลงกา มีผู้ล้มตายนับไม่ถ้วน กำหนดรับโทษเก้าวาระ', w:0, forged:true },
  ],
  hidden:[],
  merits:[
    { t:'ยึดมั่นในสัจจะตลอดเวลาที่ถูกกักตัว ไม่ยอมอ่อนข้อต่อการบังคับ', v:2, fake:false },
    { t:'ยังเมตตาต่อผู้ที่เฝ้าคุมตน แม้ในวันที่ตนเองทุกข์ที่สุด', v:1, fake:false },
    { t:'ไม่เคยเอ่ยโทษผู้ใดว่าเป็นต้นเหตุของสิ่งที่ตนต้องเผชิญ', v:1, fake:false },
  ],
  line:'"หม่อมฉันมาตามที่บัญชีเรียกเจ้าค่ะ ขอท่านโปรดอ่านให้จบก่อนตัดสิน"',
  claims:[ /* ดูข้อ 3.1 */ ],
  secret:'ส่องกระจกแล้ว ไม่พบเรื่องใดซ่อนอยู่ในใจพระนางเลย พบเพียงรอยหมึกบนช่อง "ผู้กระทำ" ที่ไม่ใช่ลายมือของสำนักคัดกรรม',
  reward:'ยมบาทน้อยมองพระนางเดินกลับขึ้นไปพร้อมหนุมาน แล้วนิราก็ปิดแฟ้มเล่มนั้นลงช้า ๆ ด้วยสองมือ',
  fail:'ยมบาทน้อยยืนนิ่งอยู่หน้าแท่น แฟ้มบนโต๊ะยังเปิดค้างอยู่ที่หน้าเดิม',
}
```

หมายเหตุสำหรับ Toby
- `seen[0]` เป็นข้อกล่าวหาที่ถูกแก้ ไม่ใช่บาปจริง จึงให้น้ำหนัก w:0 และไม่ใส่รหัส `s` ถ้าระบบบังคับให้มี `s` ให้ใช้ค่าที่ไม่ลดคะแนนผู้ถูกพิจารณา อย่าให้ผู้เล่นได้คะแนน "พิพากษาถูก" จากการเอาโทษนางสีดา
- `forged:true` เป็นฟิลด์ที่เสนอเพิ่ม (ไว้ให้ UI ขึ้นป้าย "ข้อมูลน่าสงสัย") ถ้าไม่ต้องการเพิ่มฟิลด์ ตัดทิ้งได้ ข้อความไม่เสีย

### 3.1 ข้อสอบสวน 4 ข้อ (ทั้งหมดเป็น solid · ข้อ 3 คือข้อเปิดความจริง)

| ข้อ | ผู้ตัดสินถาม | claims[].t (คำตอบของพระนาง) | reveal (เมื่อกดไต่ถาม) |
|---|---|---|---|
| 1 | พระนางทราบไหมครับว่าบัญชีเขียนข้อหาอะไรไว้ | "หม่อมฉันทราบเพียงว่าถูกเรียก จึงมาตามที่เรียกเจ้าค่ะ ข้อหาที่ท่านอ่านให้ฟัง หม่อมฉันเพิ่งได้ยินเป็นครั้งแรก" | (ไม่มี) |
| 2 | ในช่วงศึกกรุงลงกา พระนางอยู่ที่ใดครับ | "หม่อมฉันอยู่ในสวนขวัญตลอดเวลา ไม่ได้ยกทัพ ไม่ได้ออกคำสั่งสิ่งใดเจ้าค่ะ ใครจะเรียกว่าเป็นต้นเหตุก็เรียกได้ แต่ไม่ใช่ความจริง" | (ไม่มี) |
| 3 **(เปิดความจริง)** | ผมขอดูแฟ้มต้นฉบับพร้อมกันกับพระนาง ช่อง "ผู้กระทำ" กับ "ผู้ถูกกระทำ" ในหน้านี้ พระนางเห็นอะไรครับ | "ถ้าหม่อมฉันอ่านไม่ผิด ชื่อของหม่อมฉันอยู่ในช่องที่ควรเป็นชื่อของผู้ลักพาเจ้าค่ะ" | ยมบาทน้อยส่องแฟ้มใกล้ ๆ หมึกตรงสองช่องนั้นเป็นสีเดียวกับตราประทับของสำนักคัดกรรม แต่ไม่มีเลขรับรองกำกับแม้แต่บรรทัดเดียว และสองช่องถูกสลับที่กัน |
| 4 | พระนางต้องการสิ่งใดจากศาลนี้ครับ | "หม่อมฉันไม่ขอให้ใครยกโทษเพราะหม่อมฉันเป็นใคร ขอเพียงให้ตัดสินจากความจริง หากความจริงว่าหม่อมฉันต้องรับ หม่อมฉันก็รับเจ้าค่ะ" | (ไม่มี) |

### 3.2 ตัวเลือกตัดสิน (choices / responses)

ทุกตัวเลือกไม่มีการลงโทษนางสีดาจริง เจตนาคือให้ผู้เล่นรู้สึกว่า "ตัดสินอย่างรอบคอบ" ไม่ใช่ "ตัดสินถูก/ผิด" และไม่ทำให้พระนางเสียเกียรติ

| # | choices | responses |
|---|---|---|
| A | ระงับโทษไว้ก่อน เพราะบัญชีไม่ชอบมาพากล | ยมบาทน้อย: "ผมขอระงับโทษไว้ก่อนครับ บัญชีที่มีรอยแก้ไม่มีเลขรับรอง ผมไม่ตัดสินจากบัญชีที่ผมเชื่อไม่ได้" / นางสีดา: "ขอบพระคุณเจ้าค่ะ หม่อมฉันจะรอ" |
| B | ให้พระนางพักที่ศาลาระหว่างรอตรวจบัญชี | ยมบาทน้อย: "ขอเชิญพระนางพักที่ศาลาก่อนครับ ระหว่างที่นิราตรวจต้นฉบับ" / นางสีดา: "หม่อมฉันขอบพระคุณเจ้าค่ะ" |
| C | ประทับตราตามบัญชี แล้วค่อยขอทบทวน (ตัวเลือกหลอก) | บรรยาย: ตราลงโทษถูกกดลงบนกระดาษ แต่รอยหมึกซึมหายไปเอง ตรวนที่เตรียมไว้ไม่ยอมล็อก ยมบาทน้อย: "...มันไม่ติด" / นางสีดา: "ท่านไม่ต้องกังวลเจ้าค่ะ หม่อมฉันไม่ได้ถือสา" (ผลเหมือน A/B เพียงแต่ไม่ได้ "คะแนนความรอบคอบ" ถ้าระบบมี) |

ตัวเลือก C ไม่มีการทำโทษจริงกับนางสีดา ระบบ/ตรวนปฏิเสธเอง เพื่อไม่ให้ภาพพระนางถูกลงโทษปรากฏในเกม

## 8. ข้อที่ควรให้ chris-culture ตรวจตอนรอบ ship

1. **ข้อกล่าวหาปลอม "ต้นเหตุแห่งศึกกรุงลงกา"** (seen[0]) อ่อนไหวที่สุดในชุดนี้ เพราะเป็นการเอานางสีดามาอยู่ในช่องผู้ถูกกล่าวหา แม้เฉลยว่าบัญชีผิดทันที · ข้อหาสำรองที่ปลอดภัยกว่า: "ผิดวาระ ค้างโทษจากภพก่อน เก้าวาระ" (ไม่ผูกกับเนื้อเรื่องรามเกียรติ์ เสียงเฉลยในข้อ 3 ต้องปรับตามเล็กน้อย) ส่งให้ Rae ปรับได้ภายใน 1 รอบ
2. **สรรพนาม/คำราชาศัพท์**: "หม่อมฉัน ... เจ้าค่ะ" ของนางสีดา, "พระนาง" ที่หนุมานและผู้บรรยายใช้, "พระรามเจ้า", "พระบัญชา" ถูกระดับหรือไม่ · ควรเรียกนางสีดาว่า "พระแม่" หรือไม่ (เลือก "พระนาง" ไว้ก่อน เพื่อไม่เสี่ยงปนกับการใช้ "พระแม่" ในบริบทเทวี)
3. **"สวนขวัญ"** เป็นชื่อสถานที่กักนางสีดาในรามเกียรติ์ฉบับไทย (ต่างจาก "อโศกวัน" ในฉบับอินเดีย) ขอยืนยันชื่อ และชื่อ "กรุงลงกา"
4. **คำอธิบายบุญ 3 ข้อของนางสีดา** (merits) เขียนเป็นคุณธรรมทั่วไปที่สอดคล้องกับเรื่อง ไม่ได้อ้างเหตุการณ์เฉพาะ ขอให้ตรวจว่าไม่ขัดกับฉบับรามเกียรติ์ที่ใช้เป็นหลัก
5. **บุคลิกหนุมาน**: ในรามเกียรติ์หนุมานมีมุมคะนอง ขี้เล่น แต่ใบนี้เขียนให้สุภาพ ภักดี ไม่ล้อเล่น (เพื่อความเคารพ) ขอตรวจว่าถ้าเข้มและเคร่งเกินไป จะผิดลักษณะที่คนไทยรู้จักหรือไม่ · วิธีที่หนุมาน "ทดสอบ" ด้วยการสู้เป็นแนวเดียวกับเทวดาทดสอบในคดีขอทาน ถ้ารู้สึกว่าการให้ผู้เล่นสู้กับหนุมานเป็นการไม่เหมาะสม ให้พิจารณาใช้ "ประลองฝีมือ/ทดสอบ" แทนคำว่าสู้ใน UI (ใบนี้ใช้ "ทดสอบ" ในบทแล้ว แต่ปุ่ม UI ยังไม่ได้ล็อก)
6. **ไม่ให้พระรามปรากฏ/พูด** ในเกม มีแต่คำบัญชาที่หนุมานถือมา · ขอให้ยืนยันว่าแนวนี้ยอมรับได้
7. **ตัวเลือก C (ประทับตราตามบัญชีแล้วตราไม่ติด)** ผู้เล่นมีทางเลือก "เกือบลงโทษ" นางสีดา แม้ไม่มีผลจริง ขอตรวจว่ายังรับได้หรือควรตัดตัวเลือกนี้ทิ้ง (ตัดได้โดยไม่กระทบเนื้อเรื่อง)
8. **การเลี่ยงที่ตั้งใจ**: ไม่แตะเรื่องลุยไฟ, การถูกเนรเทศ, ข้อสงสัยเรื่องความบริสุทธิ์ทางกาย, ตอนจบของนางสีดาในฉบับต่าง ๆ · ขอให้ chris-culture ยืนยันว่าไม่มีส่วนใดในชุดนี้ไปเข้าเรื่องเหล่านั้นโดยไม่ตั้งใจ

## 9. หมายเหตุอื่น
- ไม่ได้ตั้ง "รางวัล" (reward ที่เป็นไอเท็ม/คะแนน) เพราะสเปกไม่ได้กำหนด ถ้าต้องมี ให้ Toby/คุณเป้เลือก แล้วส่ง Rae เขียนชื่อ/คำอธิบาย
- ตัวเลือกและการพิพากษาข้อ 3.2 ไม่ควรทำให้ผู้เล่นได้คะแนนด้านลบจากการ "ปล่อยผู้บริสุทธิ์" ให้ Toby ตรวจกับระบบคะแนนบาป/บุญ
- ภาษาเรียบร้อยแล้ว ไม่มีคำหยาบ ไม่มีมุก ไม่มี emoji (ถ้าต้องการไอคอนกระจกนำหน้าข้อความ secret ให้ Toby ใส่ตามของเดิม)
