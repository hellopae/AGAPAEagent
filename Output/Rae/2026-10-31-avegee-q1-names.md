## 2. อรุณเดช (C39) = ขอทานในวัด · แก้ `deva.th.warning`

ตัดคำว่า "จำวัด" (ศัพท์พระ ใช้กับขอทานไม่ได้) เปลี่ยนเป็นคำของขอทานเอง และเก็บสิ่งที่เขาทำในคดี คือแบ่งอาหารให้ผู้หิว

| คีย์ | ข้อความเดิม | ข้อความใหม่ |
|---|---|---|
| `deva.th.warning` (TH, `i18n.js:1062`) | ข้าเพียงจำวัด มิได้ทำบาป โปรดพิจารณาให้รอบคอบกว่านี้ ขอให้ข้าทดสอบฝีมือท่านสักครู่ | ข้าเป็นเพียงขอทานในวัด แบ่งอาหารที่ได้มาให้ผู้หิวโหย มิได้ทำบาป โปรดพิจารณาให้รอบคอบกว่านี้ ขอให้ข้าทดสอบฝีมือท่านสักครู่ |
| `deva.th.warning` (EN, `i18n.js:1088`) | I only rested and committed no sin. Please judge more carefully. Allow me to test your skill. | I am only a beggar in the temple, sharing what I am given with the hungry. I committed no sin. Please judge more carefully. Allow me to test your skill. |

บทเทวดาโซน 1 ที่เกี่ยวข้องอีกบท `deva.th.praise` ไม่มีคำว่าจำวัด ไม่ต้องแก้ · การ์ดคู่มือ C39 ไม่มีคำนี้ ไม่ต้องแก้

## 3. เอียร์ลิน (C41) = ชื่อ · วาลคีรี = ตำแหน่ง

**การ์ดคู่มือ** คีย์ `C41 เอียร์ลิน (west)`

| ข้อความเดิม | ข้อความใหม่ |
|---|---|
| เอียร์ลินเป็นเทวดาถือหอกประจำปัจฉิม ลงมาปราบแวมไพร์ แต่ท่านปราบไปก่อนแล้ว จึงขอทดสอบฝีมือท่านแทน ไม่ใช่เพราะไม่เชื่อ แต่เพราะอยากเห็นด้วยตาว่าผู้ที่ชนะวาลดริกเป็นอย่างไร ผู้ที่ผ่านจะได้หอกวาลคีรีไปใช้เอง | เอียร์ลินเป็นเทวดาตำแหน่งวาลคีรี ผู้ถือหอกประจำปัจฉิม ลงมาปราบแวมไพร์ แต่ท่านปราบไปก่อนแล้ว จึงขอทดสอบฝีมือท่านแทน ไม่ใช่เพราะไม่เชื่อ แต่เพราะอยากเห็นด้วยตาว่าผู้ที่ชนะวาลดริกเป็นอย่างไร ผู้ที่ผ่านจะได้หอกวาลคีรีไปใช้เอง |

**ต้องสะกดใหม่ที่ `deva.west.arrival` (TH, `i18n.js:1063-1067`)** ป้ายผู้พูดสะกดผิด "วาคิวรี" 3 จุด เปลี่ยนเป็น "วาลคีรี" ป้ายผู้พูดคงเป็นตำแหน่งเหมือนเดิม (ตรงกับ EN ที่ใช้ `Valkyrie:`) ไม่ใส่ชื่อ เอียร์ลิน ในบท

```
วาลคีรี: ไม่ต้องห่วงเจ้าตัวเล็ก ข้ามาช่วยเจ้าแล้ว
yama: .......
วาลคีรี: อ้าว! ปีศาจแวมไพร หายไปไหนแล้ว..
yama: !!-"-"
วาลคีรี: ..... เจ้าตัวเล็ก ฝีมือไม่ธรรมดานิ
```

ให้ Toby ค้นสะกดผิดที่เหลือในโค้ดทั้ง repo: `วาคิวรี` (รู้แล้วว่ามี `data.js:1951` "หอกวาคิวรี" ตาม A10) แล้วแก้เป็น `วาลคีรี` ให้ครบ · ถ้ามีโค้ดจับคู่ป้ายผู้พูดกับภาพ/ชื่อด้วยสตริง ต้องแก้ตามด้วย

ข้อสังเกตนอกขอบเขต ไม่ได้แก้: บรรทัดที่ 3 ของบท เขียน "แวมไพร" (น่าจะขาด ์ เป็น "แวมไพร์")

## 4. ข้อความญาติ 14 ประโยค แยกจากข้อความหลัก

**วิธีใช้:** ข้อความการ์ด = ข้อความหลัก (ตาราง 4ข) + เว้นวรรค + ประโยคญาติ (ตาราง 4ก) ตามสถานะ "เจอแล้ว/ยังไม่เจอ" · "เจอ" = ตามเงื่อนไขธง `met:` ของ W3 §3 (เคยคุยหรือเคยจ้างตัวละครนั้น) ไม่คิดเงื่อนไขใหม่

**กติกาแบบยังไม่เจอ:** ไม่บอกชื่อญาติ ไม่บอกโซน ใช้ "แดนไกล" แทน · ตัดคำบรรยายหน้าตา (ผมสีเทา เขี้ยวคู่เดียวกัน) ออกจากแถวที่ทำให้เดาตัวได้ · ยังบอกชนิดความสัมพันธ์ได้ (พ่อ ลูก แฝด พี่ น้อง ตา หลาน ลูกพี่ลูกน้อง ลุง) เพราะไม่ทำให้เดาตัวได้ เนื่องจากไม่รู้ชื่อและไม่รู้โซน

ทางเลือก (ไม่บังคับ): แบบเจอแล้วของแถว 13-14 ใส่ชื่อได้ เช่น "เขามีหลานคนหนึ่งเฝ้าประตูนรกเครือข่าย (ไฟร์วอลล์)" และ "เขาเป็นหลานของกุมภัณฑ์ ยักษ์ทวารบาลแห่งสุวรรณภูมิ" · ตามใบงานให้ใช้ประโยคเดิม จึงไม่ได้เปลี่ยนในตาราง

### 4ข. ข้อความหลักที่ตัดประโยคญาติออกแล้ว (14 การ์ด)

| คีย์ (title) | ข้อความหลัก |
|---|---|
| `C04 ทัณฑ์ (th) — ...` | ทัณฑ์คุมกระทะทองแดงมาตั้งแต่รุ่นปู่ของท่าน ก่อนมาอยู่ที่นี่เขาเป็นพัศดีและช่างตีเหล็กที่เชื่อว่าทัณฑ์ยิ่งหนักยิ่งสอนคน จนวันที่เห็นผู้ต้องขังที่ตนสั่งสอนออกไปเกลียดโลกกว่าเดิม เขาจึงเตือนทุกคนว่าอย่าใส่แรงเกิน เพราะมันไม่จำ มันแค่เกลียด |
| `ซิสอ็อป` | ซิสอ็อปคุมทัณฑ์ประจำนรกเครือข่าย เคยเป็นผู้ดูแลระบบที่แบนถาวรได้ในคลิกเดียว และกดไปหลายพันบัญชีโดยไม่เคยตามดูว่าเจ้าของไปทางไหนต่อ ตอนนี้เขาเฝ้าดูผลของทุกคำสั่งจนจบ |
| `C05 เพลิง (th) — ...` | เพลิงเคยเป็นนักพ่นไฟตามงานวัด จนคืนหนึ่งไฟของเขาลามไปทั้งแถวห้องแถว ไม่มีใครตายแต่หลายครอบครัวเสียบ้าน เขาจึงมารับเวรเร่งไฟด้วยหลักเดียวคือตามหมายเท่านั้น ไม่เกินและไม่ขาด แล้วบ่นว่าคดีไม่มันพอไปเรื่อย ๆ |
| `เทอร์โบ` | เทอร์โบคุมไฟประจำนรกเครือข่าย เคยเป็นสตรีมเมอร์ที่ดันเครื่องเกินพิกัดจนห้องเซิร์ฟเวอร์ของชุมชนเล็ก ๆ ไหม้ในคืนเดียว วันนี้เขาเร่งเต็มสปีดเท่าที่หมายอนุญาตและไม่เกินแม้แต่หนึ่งเปอร์เซ็นต์ |
| `C06 กานต์ (th) — ...` | กานต์เคยเป็นผู้ช่วยเสมียนศาลที่ขึ้นชื่อว่าจับโกหกแม่น เขาเคยปักใจว่าพยานปากหนึ่งเล่าเรียงลำดับเป๊ะเกินไปจึงต้องแต่งเรื่อง ทั้งที่เธอแค่ซ้อมมาเพราะกลัวพูดผิด หลังจากนั้นเขาไม่ตัดสินจากความรู้สึกอีก และขอเวลาอ่านบรรทัดสุดท้ายทุกครั้ง |
| `ไซเฟอร์` | ไซเฟอร์อ่านสำนวนประจำนรกเครือข่าย เคยเป็นนักวิเคราะห์ความปลอดภัยที่รู้ทันตัวเลขปลอมก่อนใคร และเคยส่งรายงานเตือนที่ไม่มีใครเปิดอ่าน เขาจึงเปิดอ่านทุกสำนวนถึงบรรทัดสุดท้ายเสมอ |
| `C07 บุญ (th) — ...` | บุญเคยเป็นผู้ช่วยจัดงานศพประจำวัด คนที่เสียงเบาที่สุดในงานและไม่เคยปฏิเสธใคร จนวันที่เพื่อนขอยืมเงินกองทุนค่าโลงของหมู่บ้านไปเล่นพนัน เขาก็ให้ยืมเพราะใจอ่อน เขาจึงรู้ว่าวาระที่เกินมาไม่หายไปไหน วันนี้เขาดูแลกำลังใจทั้งโซนและจุดธูปให้ทุกดวงที่เพิ่งจากไป |
| `เมกุมิ` | เมกุมิดูแลกำลังใจชาวบูรพา เคยเป็นผู้ช่วยดูแลผู้ป่วยในวัดบนเขา ใจดีจนไม่เคยปฏิเสธใครสักคน และเรียนรู้ว่าความใจดีที่ไม่มีขอบเขต บางครั้งทำให้คนอื่นเจ็บแทนตน |
| `บัฟเฟอร์` | บัฟเฟอร์ดูแลกำลังใจชาวนรกเครือข่าย เคยเป็นผู้ดูแลกลุ่มพูดคุยออนไลน์ที่รับเรื่องเศร้าของคนแปลกหน้าทุกคืนจนไม่เหลือที่ให้ตัวเอง ตอนนี้บัฟเฟอร์เรียนรู้ที่จะพักก่อนรับเรื่องต่อไป |
| `C08 ดำ (th) — ...` | ดำเคยขนข้าวสารกะดึกให้ค่ายพักพิงผู้ประสบภัยน้ำท่วม วันที่แม่เสียเงินกับแชร์จนหนี้ตกมาที่เขา เขาแอบหักข้าวสารไปขายทีละกระสอบ และคนในค่ายต้องอดไปหลายวัน วันนี้เขาถือเสบียงทุกห่อด้วยมือที่ระวังกว่าใคร และขอแค่ได้หลับสนิทสักคืน |
| `นัวร์` | นัวร์ขนเสบียงประจำปัจฉิม เคยเป็นคนงานท่าเรือกะกลางคืนที่หักขนมปังของโรงทานฤดูหนาวไปขายครั้งหนึ่ง ตอนนี้เขาไม่ยอมให้ลังไหนขาดแม้แต่ก้อนเดียว |
| `ดาร์กเน็ต` | ดาร์กเน็ตขนเสบียงประจำนรกเครือข่าย เคยเป็นช่างเทคนิคกะดึกที่ขายพื้นที่สำรองของคลังข้อมูลการกุศลเพื่อใช้หนี้ จนข้อมูลของหลายครอบครัวหายไปชั่วคืน เขาจึงนับพื้นที่สำรองทุกกิกะไบต์ก่อนปล่อยของ |
| `ยักษ์ทวารบาล (Guard)` th | (ใช้ข้อความหลักในตารางข้อ 1 ที่เติมชื่อกุมภัณฑ์แล้ว) |
