# เตรียมไฟล์อาร์ตเวิร์กให้พร้อมพิมพ์ — CMYK, 300 dpi, ระยะตัดตก และฟอนต์

งานพิมพ์ที่ออกมาไม่ตรงใจ ส่วนใหญ่ตัดสินกันตั้งแต่ตอนเซฟไฟล์ ไม่ใช่ตอนขึ้นแท่นพิมพ์ สี่เรื่องต่อไปนี้คือสิ่งที่เราตรวจเป็นอันดับแรกทุกครั้งที่รับไฟล์ ถ้าไฟล์ของคุณผ่านครบสี่ข้อ งานจะเดินหน้าได้เลยโดยไม่ต้องส่งกลับไปแก้

## 1. โหมดสีต้องเป็น CMYK

จอคอมพิวเตอร์แสดงสีด้วยแสงในระบบ RGB ส่วนเครื่องพิมพ์สร้างสีด้วยหมึกสี่สี CMYK ขอบเขตสีของสองระบบไม่เท่ากัน สีสดจัดจ้านบนจอ อย่างฟ้าจัด เขียวนีออน หรือม่วง จึงมักหม่นลงเมื่อพิมพ์ออกมา

ตั้งโหมดสีเป็น CMYK ตั้งแต่เริ่มไฟล์ อย่ารอแปลงตอนท้าย ใน Illustrator ดูที่ File > Document Color Mode ส่วน InDesign ไม่มีโหมดสีระดับเอกสาร ให้กำหนดสีใน Swatches เป็น CMYK และเลือกแปลงสีเป็น CMYK ตอน Export PDF อีกชั้นหนึ่ง ใน Photoshop ดูที่ Image > Mode

## 2. ความละเอียด 300 dpi ที่ขนาดจริง

คำว่า "ที่ขนาดจริง" สำคัญมาก ภาพ 300 dpi ที่ขนาด 5 เซนติเมตร เมื่อถูกยืดเป็น 20 เซนติเมตรบนหน้ากระดาษ ความละเอียดจริงจะเหลือแค่หนึ่งในสี่ ภาพที่ดึงมาจากเว็บไซต์หรือโซเชียลมักถูกบันทึกไว้ที่ความละเอียดต่ำเพื่อให้โหลดเร็ว จึงไม่พอสำหรับงานพิมพ์เกือบทุกกรณี

เช็กก่อนวางภาพทุกครั้งที่ Image > Image Size ใน Photoshop ถ้าไม่ถึง ให้หาไฟล์ต้นฉบับที่ใหญ่กว่า หรือเปลี่ยนไปใช้ภาพเวกเตอร์ซึ่งขยายได้ไม่จำกัด

## 3. ระยะตัดตกและขอบปลอดภัย

เครื่องตัดกระดาษมีการเหลื่อมเล็กน้อยเสมอ ถ้าพื้นสีหรือภาพชิดขอบงานพอดี ตัดออกมาจะเห็นเส้นขาวที่ขอบ ระยะตัดตก (bleed) คือการยืดพื้นหลังเกินขอบจริงออกไปอีกด้านละ 3 มิลลิเมตร เพื่อกันความคลาดเคลื่อนนี้

อีกด้านหนึ่งที่คนมักลืมคือขอบปลอดภัย ข้อความ โลโก้ และเลขหน้า ควรถอยเข้ามาจากขอบตัดอย่างน้อย 3–5 มิลลิเมตร ไม่อย่างนั้นต่อให้ไม่โดนตัด ก็จะดูอึดอัดเหมือนวางชิดขอบเกินไป

## 4. ฟอนต์ต้องเดินทางไปกับไฟล์

ไฟล์ที่ส่งมาไม่ได้พาฟอนต์ไปด้วยโดยอัตโนมัติ เมื่อเปิดบนเครื่องที่ไม่มีฟอนต์ตัวเดียวกัน ระบบจะสลับไปใช้ฟอนต์อื่นและเลย์เอาต์พังทั้งหน้า เรื่องนี้สำคัญเป็นพิเศษกับฟอนต์ไทย เพราะตำแหน่งสระและวรรณยุกต์อาจเพี้ยนโดยที่ตายังไม่ทันสังเกต

ทางแก้มีสองทาง ทางแรกคือแปลงตัวอักษรเป็นเส้นเวกเตอร์ ใน Illustrator ใช้ Type > Create Outlines ปลอดภัยที่สุดแต่แก้ข้อความไม่ได้อีก ควรเก็บไฟล์ต้นฉบับแยกไว้เสมอ ทางที่สองคือ Export เป็น PDF มาตรฐาน PDF/X-1a หรือ PDF/X-4 ซึ่งฝังฟอนต์ให้อัตโนมัติอยู่แล้ว

## เช็กลิสต์ก่อนกดส่งไฟล์

- โหมดสีเป็น CMYK ทั้งไฟล์ รวมถึงภาพที่วางเข้าไป
- ภาพทุกภาพ 300 dpi ที่ขนาดใช้งานจริง
- ตั้งระยะตัดตก 3 มม. และยืดพื้นหลังให้เต็ม
- ข้อความถอยจากขอบตัดอย่างน้อย 3–5 มม.
- Outline ฟอนต์ หรือบันทึกเป็น PDF/X
- เปิดไฟล์ PDF ที่จะส่งขึ้นมาดูอีกรอบก่อนส่ง

## สรุป

ไล่เช็กหกข้อนี้ใช้เวลาไม่กี่นาที แต่ช่วยตัดรอบแก้ไขที่กินเวลาเป็นวันออกไปได้ทั้งรอบ ถ้าไม่แน่ใจจุดไหน ส่งไฟล์มาคุยกับเราก่อนได้ ดีกว่ารู้ตอนงานออกจากแท่นพิมพ์แล้ว
