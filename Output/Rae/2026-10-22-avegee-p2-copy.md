## 5. บุญปลอมคดี 15 (แม่ชีถือศีลสงบ) แทนข้อ "ทำวัตรเช้า-เย็น"

ตำแหน่ง: `src/cases.js` คดี `k:'novice'` ในอาร์เรย์ `merits` แทนรายการที่ 2 (บรรทัด ~435–436) ทั้งก้อน ไม่แตะหลักศาสนา ไม่มีคำว่าบาป/นรก รูปแบบ `fake:true` ตามคดีอื่น (ใช้ `v:1` เหมือนบุญปลอมคดี 1, 2, 5, 11, 12, 13) เขียนเข้ากับเรื่องหนีหมายจับมาบวช ใช้ชื่อใหม่ ไม่มีใครรู้ตัวตนเดิม

บล็อก `merits` ฉบับสมบูรณ์พร้อมวาง:

```js
    merits:[
      { t:'สอนเด็กในหมู่บ้านใกล้สำนักให้อ่านหนังสือฟรีทุกเย็น', v:1, fake:false },
      { t:'ส่งเงินช่วยบ้านพักคนชราแห่งหนึ่งทุกเดือนโดยไม่ออกนาม', v:1, fake:true,
        note:'เรื่องแต่งขึ้นเพื่อให้ดูเป็นคนใจบุญ ไม่เคยมีการโอนเงินจริงสักครั้ง จึงไม่นับเป็นบุญ' },
    ],
```

คำอ้างที่ให้ผู้เล่นจี้เจอ (`kind:'boast'` ตามรูปแบบคดีอื่นที่มีบุญปลอม) แทรกต่อจากข้อ `deny` และก่อนข้อ `solid` แรกใน `claims`:

```js
      { kind:'boast', t:'ท่านดูบุญของดิฉันด้วยนะคะ — ดิฉันส่งเงินช่วยบ้านพักคนชราแห่งหนึ่งทุกเดือนโดยไม่ออกนาม',
        merit:'ส่งเงินช่วยบ้านพักคนชราแห่งหนึ่งทุกเดือนโดยไม่ออกนาม',
        reveal:'ท่านขอให้บอกชื่อบ้านพักสักแห่ง เธอเงียบไปครู่หนึ่งแล้วตอบว่า "ทำบุญไม่ออกนามค่ะ" — ข้ออ้างเดียวกับที่เธอใช้ปิดเรื่องชื่อเดิมของตัวเอง' },
```

## จุดที่ควรรู้ / ต้องตัดสินใจ (Rae ไม่ได้แก้ไฟล์ใดนอก Output)

1. **ข้อความเดิมในบทที่ 3 ของคู่มือขัดกับโค้ดปัจจุบัน** (`sentencing-guide.js` บทที่ 3 ย่อหน้า 2) เขียนว่า "ทัณฑ์เหมาะเริ่มต้น… เพลิงทำงานแรงแต่มีโอกาสเพิ่มกรรมของเราเอง" แต่ `roles.plerng.cost` ระบุ "ไม่มีการสุ่มบวกโทษหรือกรรม" เสนอแทนย่อหน้านั้นด้วย (Toby ยืนยันก่อนว่าไม่มีกลไกสุ่มกรรมเหลืออยู่):
   `<p>ทัณฑ์ บุญ เพลิง ดำ และกานต์ มีผลดีกับต้นทุนต่างกัน ดูหน้า "สีของวิญญาณ กับการเลือกผู้คุม" และ "ผลของทีมดูแลคดี" ก่อนเลือก นิราอ่านสำนวน จึงเลือกไปลงทัณฑ์ไม่ได้ ดูค่าสถานะปัจจุบันของคนที่ว่างหลังฝึกประกอบด้วย</p>`
2. **สีชนกัน (สำคัญ)** สีที่ชื่อวิญญาณ (ม่วง/แดง/เขียว) ใช้แดงและเขียวซ้ำกับสีตัวเลขในสำนวน (`sentence-colors.js`: แดง = 5, เขียว = 2) ผู้เล่นอาจอ่านสีแดงที่ชื่อว่า "กรรมหนัก 5" ข้อความหน้า 1 และหน้า "จำไว้" เขียนกันความสับสนไว้แล้ว แนะนำให้ Vera เว้นตำแหน่งให้ชื่อวิญญาณห่างจากแถวสำนวน และให้ Toby ใส่ไอคอนนำหน้าเสมอ เพราะผู้เล่นตาบอดสีอาศัยไอคอนกับป้าย `aria-label` ("ลักษณะ: ปิดบังความจริง")
   เพิ่มประโยคท้ายใน `sentenceColorGuide` ได้ (ไม่บังคับ): "สีที่ชื่อวิญญาณคนละเรื่องกับสีเหล่านี้ บอกพฤติกรรม ดูหน้า สีของวิญญาณ"
3. **`firstTrialLesson` เดิม** ข้อ 3 ("เลือกยมทูตที่ว่าง ดูระเบียบ ปัญญา และเมตตา") ยังใช้ได้ เพิ่มท้ายข้อได้ถ้าต้องการ: " และดูสีของวิญญาณเพื่อเลือกผู้คุม" (ไม่บังคับ)
4. **เกณฑ์ "สัญญาณ" ของสี** เขียนตาม `spiritTrait` ปัจจุบัน (ม่วง = มีเรื่องซ่อน, แดง = ปฏิเสธ/ต่อต้าน, เขียว = นอกนั้น และม่วงมาก่อน) ถ้า Toby เปลี่ยนเกณฑ์ตอนกำหนดสีครั้งเดียวตอนเข้าศาล ต้องบอก Rae ปรับบรรทัด "สัญญาณ" ทั้ง 3 ข้อ
5. **สถานะปิดปุ่มกานต์ (ข้อ 3)** `kanClueWhy` ในโค้ดเกมมีข้อความของมันเองอยู่แล้ว (ผมไม่ได้เปิด `game.js`) ถ้ามีข้อความตรงกันให้ใช้ของเดิม เอาชุดนี้เฉพาะที่ยังไม่มี และให้ตรวจว่า "กำลังใจ" เป็นของกานต์หรือของผู้เล่น
6. **กล่อง "ผลของทีมดูแลคดี" เดิมมีของสดที่ย้ายเป็นข้อความคงที่ไม่ได้** คือบรรทัด "อสูรผู้ช่วยในโซน N คน · มีงานแล้ว · ว่าง" และรายชื่อผู้คุมแบบมีปุ่ม "เลือก …" (`keeperRoleHtml` โหมด `choose`) ซึ่งเป็น UI เลือกผู้คุมจริง ผมแปลงเฉพาะส่วนอธิบาย ถ้าย้ายออกจากหน้าสอบสวนหมด ต้องมีทางเลือกผู้คุมที่อื่น (Vera/Toby ตัดสิน) ส่วน "รายงานผลงานทีม" (`teamReportsHtml`) ไม่ได้อยู่ในใบงาน ไม่แตะ
7. **ตรวจ:** ข้อความทั้งหมดเป็นกติกาเกม ไม่อ้างหลักศาสนา ข้อ 5 ไม่มีคำเกี่ยวกับการทำวัตรหรือการได้บุญตามหลักศาสนา ตัวเลขทุกค่าในข้อ 1, 3, 4 ให้ Reese เทียบกับตารางด้านบนได้ตรง ๆ
