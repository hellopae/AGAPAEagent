## 2. ข้อค้นพบนอกงานข้อความ (Claudy ตัดสินแล้ว)

**(A) ลูกไฟจาก "0 ดาว" เข้าไม่ถึงในโค้ด — ตัดสินแล้ว: โค้ดคงเดิม ข้อความตามพฤติกรรมจริง** Reese ยืนยัน (CHECK 1) และแก้ข้อสันนิษฐาน: ส่งประตูสวรรค์ผิด `judge` คืน score 0 (game.js 1117) = `bad` = แดง ไม่ใช่ลูกไฟ ลูกไฟจากคำตัดสินเหลือ 2 ทางเท่านั้น: cruel (เกินกรรม ≥ 2 ระดับ และ score ≥ 50) กับเตือนแดงครั้งที่ 2 ข้อความทุกจุดด้านล่างตรงนี้แล้ว (ไม่มีข้อความไหนบอกว่า 0 ดาวหรือส่งสวรรค์ผิดโดนลูกไฟ) · บันทึกเดิมของผม `game.js` applyVerdict 1239-1241:

```
if (tag !== 'bad' && r.stars === 0) this.fireball('คำตัดสินนี้ไม่มีดาวสักดวง');
else if (tag !== 'bad' && r.boss === 'cruel') this.fireball('เกินกรรมไปสองวาระ');
else if (tag !== 'bad' && r.stars <= 1) { this.hp -= 10; ... }
```

`tag === 'bad'` คือ score < 50 และดาว 0–1 เกิดเฉพาะ score < 42 (`starsOf`) ดังนั้นสองเงื่อนไขที่พูดถึง "0 ดาว" กับ "1 ดาว" ไม่มีวันเป็นจริง (ดาว 2 ที่ score 42–49 ก็เป็น `bad` เช่นกัน) เหลือที่เข้าถึงได้แค่ "เกินกรรม ≥ 2 ระดับ และ score ≥ 50" (`cruel`) กับสายแดนติดกัน (ครั้งที่ 2 ลูกไฟเตือน ครั้งที่ 3 พ่อลงมา) `BAL.hpBad`/`hpTerrible` ก็ไม่ถูกใช้
ข้อความทุกจุด (D1 U5 U8) **ตรงพฤติกรรมจริง** และใส่เงื่อนไข "คะแนนรวม ≥ 50" ครบ (D1 U5 U8) ต่ำกว่า 50 = แดง

**(B) "ท่านลงทัณฑ์เอง" เอาออกแล้วจริง (Reese ยืนยัน CHECK 2)** — `assignBlock` ปฏิเสธ `c.self` (game.js 1035) กิ่ง `c.self` ใน `step()` เหลือไว้ให้เซฟเก่า · เว้นวรรคในห้องสถานีมีผลเฉพาะ: กระทะ = มินิเกมเร่งไฟ · หอทะเบียน = จัดเอกสาร · ป่าดาบ/ดงต้นงิ้ว = ฝึกดาบ · ศาลาน้ำชา = นั่ง/นอน ไม่มีกรรมจากการเร่งทัณฑ์เอง U2 และ U7 ใหม่แก้ตามโค้ดแล้ว ไม่มีทางสำรองเว้นวรรค
