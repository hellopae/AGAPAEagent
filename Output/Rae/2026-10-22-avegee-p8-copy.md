## 2. ข้อค้นพบนอกงานข้อความ (ส่ง Claudy ตัดสิน)

**(A) ลูกไฟจาก "0 ดาว" เข้าไม่ถึงในโค้ด** — `game.js` applyVerdict 1239-1241:

```
if (tag !== 'bad' && r.stars === 0) this.fireball('คำตัดสินนี้ไม่มีดาวสักดวง');
else if (tag !== 'bad' && r.boss === 'cruel') this.fireball('เกินกรรมไปสองวาระ');
else if (tag !== 'bad' && r.stars <= 1) { this.hp -= 10; ... }
```

`tag === 'bad'` คือ score < 50 และดาว 0–1 เกิดเฉพาะ score < 42 (`starsOf`) ดังนั้นสองเงื่อนไขที่พูดถึง "0 ดาว" กับ "1 ดาว" ไม่มีวันเป็นจริง (ดาว 2 ที่ score 42–49 ก็เป็น `bad` เช่นกัน) เหลือที่เข้าถึงได้แค่ "เกินกรรม ≥ 2 ระดับ และ score ≥ 50" (`cruel`) กับสายแดนติดกัน (ครั้งที่ 2 ลูกไฟเตือน ครั้งที่ 3 พ่อลงมา) `BAL.hpBad`/`hpTerrible` ก็ไม่ถูกใช้
ข้อความทุกจุดที่ผมเขียนใหม่ (D1 U5 U8) **ตรงพฤติกรรมจริงตอนนี้** ไม่พูดถึง 0 ดาว ถ้าคุณเป้ตั้งใจให้ 0 ดาวโดนลูกไฟ นี่คือบั๊กโค้ด (น่าจะมาจากการย้ายเงื่อนไขแดงเข้า DAD ใน P3) ต้องแก้โค้ด แล้วค่อยกลับไปใช้ข้อความเดิม

**(B) "ท่านลงทัณฑ์เอง" ดูเหมือนถูกเอาออกแล้ว** — `assignBlock` ปฏิเสธ `c.self` (game.js 1035) คอมเมนต์ `createGame` บอก "self เก็บไว้เพื่ออ่านเซฟเก่า แต่ไม่เปิดให้ลงทัณฑ์เอง" `SELF` ใน data.js ก็ระบุว่า "สำหรับคดีค้างในเซฟเก่าเท่านั้น" แต่ openHelp ข้อ 2 ยังบอกว่า "สถานีจะเดินเฉพาะตอนท่านยืนอยู่ตรงนั้น" และข้อ 13 บอกว่า "เร่งทัณฑ์เอง … ลงมือเองก็เป็นกรรมของท่าน" ผมไม่พบโค้ดเพิ่มกรรมจากการเร่งทัณฑ์เอง (ค้นใน judge/applyVerdict/step/usePower/battleAct) U2 และ U7 เสนอแก้ตามโค้ด แต่ U7 ต้องให้ Reese ยืนยันว่าปุ่มเว้นวรรคที่สถานียังทำอะไรอยู่ไหม (CHECK 2)
