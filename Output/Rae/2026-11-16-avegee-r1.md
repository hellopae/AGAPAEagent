## B. คดีนายพล (F18) · `src/cases.js` บรรทัด 71 และ 77–79

**ข้อเสนอ: เปลี่ยนเป็นข้อความใหม่ ไม่ตัด** เหตุผล: ข้อบรรเทาปลอมเป็นกลไกหลักของคดีกลุ่ม `twist` (ผู้เล่นต้องจับด้วย `reveal`) คดีนายพลมีข้อบรรเทาข้อเดียว ถ้าตัดจะไม่มีทั้งข้ออ้าง `boast` และ `reveal` ให้ฝึก และคดีจะต่างจากคดีนักการเมือง/ดาราที่อยู่ข้างเคียง

ข้อความเดิมผิดตรงที่ "ไม่ขึ้นเงินเดือนตัวเอง" ไม่ใช่คุณธรรมที่ผู้เล่นทั่วไปจะรับว่าบรรเทาโทษได้ (คุณเป้ชี้ถูก) ข้อความใหม่ต้องฟังเป็นข้อดีจริงในตอนแรก แล้วค่อยพังตอนไต่ถาม

```js
// merits (แทนบรรทัด 71)
{ t:'สร้างโรงพยาบาลให้ประชาชนรักษาฟรีทั้งจังหวัด', v:1, fake:true },

// claims[1] (แทนบรรทัด 77–79)
{ kind:'boast', t:'ท่านดูเถอะครับ — ผมสร้างโรงพยาบาลให้ชาวบ้านรักษาฟรีทั้งจังหวัด',
  merit:'สร้างโรงพยาบาลให้ประชาชนรักษาฟรีทั้งจังหวัด',
  reveal:'ท่านถามว่าชาวบ้านคนแรกที่ได้รักษาฟรีคือใคร เขานิ่งไป — โรงพยาบาลนั้นรับเฉพาะครอบครัวทหารกับผู้มีบัตรจากค่าย ชาวบ้านทั่วไปถูกส่งกลับที่ประตู' },
```
- `merits[].t` = "สร้างโรงพยาบาลให้ประชาชนรักษาฟรีทั้งจังหวัด"
- `claims[1].t` = "ท่านดูเถอะครับ — ผมสร้างโรงพยาบาลให้ชาวบ้านรักษาฟรีทั้งจังหวัด"
- `claims[1].merit` ต้องเหมือน `merits[].t` ทุกตัวอักษร (ระบบจับคู่ด้วยข้อความ)
- `claims[1].reveal` = ข้อความข้างบน
- รูปแบบตรงกับคดีนักการเมือง (กองทุน "ไม่เคยจ่ายเลยสักบาท") และดารา ("ไม่เคยไปเลยสักครั้ง") แต่ต่างเหตุผล: ของจริงมี แต่ไม่ได้ให้ประชาชน
- ถ้าคุณเป้ไม่ชอบเรื่องโรงพยาบาล ตัวสำรอง: "บริจาคเงินเดือนหนึ่งปีให้กองทุนทหารผ่านศึก" / reveal "ท่านถามว่าเงินเดือนนั้นมาจากไหน เขานิ่งไป — เงินที่บริจาคเป็นเงินกลับคืนจากงบกลาโหมที่เขาเบิกไปก่อนหน้านั้นหลายเท่า"
- ค่า `v:1` คงเดิม ถ้าต้องการปรับให้เทียบกับคดีอื่น Toby/คุณเป้ปรับได้

| `weapon.effect.burn` (พารามิเตอร์ `chance hp turns cap` · เทสต์ต้องการ `/2 รอบ/` เมื่อ `turns:2`) | ติดไฟ {chance}% ลุกไหม้ {hp} ต่อเทิร์นของศัตรู นาน {turns} รอบ (ไม่เกิน {cap}) | {chance}% to set the foe alight, burning {hp} per foe turn for {turns} rounds (max {cap}). |
| การ์ดไอเท็มผนึกน้ำแข็ง (ตรวจคีย์) | ศัตรูที่ถูกผนึกจะหยุดนิ่งตลอดหนึ่งรอบเต็ม | A sealed foe stands frozen for one full round. |
| การ์ดพลังในเรื่อง `story.js` (ตรวจคีย์) | ใช้ประโยคเดียวกับโปรไฟล์พลัง (ผนึก/สะกดจิตข้างบน) เพื่อไม่ให้ข้อความสองที่ต่างกัน | same as the profile lines above |
| ข้อความหน้าอาวุธ "นาน N รอบ" | คงรูป "นาน {n} รอบ" ที่ Toby เขียนไว้แล้ว ถูกต้องตามนิยามด้านบน | keep "for {n} rounds" |

หมายเหตุ
- `cap` ใน `weapon.effect.burn` ผมไม่เห็นว่าหมายถึงอะไรในโค้ด (เพดานความเสียหาย หรือเพดานการซ้อน) จึงเขียนว่า "(ไม่เกิน {cap})" กลาง ๆ ให้ Toby ปรับคำให้ตรงความหมายจริง
- ป้ายสถานะบนตัวศัตรู "แช่แข็ง N เทิร์น" ยังบอกเทิร์นที่เหลือจริง คำอธิบายพูดเป็น "รอบ" ผู้เล่นอาจสงสัยว่าทำไมสองที่ใช้คนละหน่วย แนะนำให้ป้ายเขียน "แช่แข็ง · เหลือ N เทิร์น" เพื่อให้ "เหลือ" บอกว่าเป็นตัวนับที่เหลืออยู่ ไม่ใช่ระยะเวลาของพลัง
- ผมไม่ได้เห็นข้อความเดิมใน `data.js` `story.js` `i18n.js` ที่มีคำว่า "รอบ" (ค้นไม่ได้) จึงไม่รับรองว่าตารางนี้ครบทุกที่ Toby ค้นคำว่า "รอบ" ใน 3 ไฟล์นี้แล้วจับคู่ตามหน้าที่ ถ้าเจอข้อความที่ไม่อยู่ในตาราง ส่งกลับมาให้ผมเกลา

## ให้ Reese ตรวจ (เฉพาะจุดอ้างตำนาน/ข้อเท็จจริงใหม่)
1. **หนุมานก้มศีรษะประนมมือขอโทษ (A6)** และนางสีดาเป็นผู้สั่งให้หยุด: ในรามเกียรติ์หนุมานเป็นทหารเอกที่ภักดีต่อพระรามและให้ความเคารพนางสีดาสูง ตรวจว่าการให้ "พระนาง" เป็นผู้ห้ามและหนุมาน "น้อมรับ" สอดคล้องกับลักษณะที่คนไทยรู้จัก (ไม่ใช่ลักษณะยียวนล้วน) และคำว่า "พระรามเจ้า" "พระบัญชา" "พระนาง" ที่ใช้ยังถูกระดับ
2. **ขี้ผึ้งอุดหูกันเสียงกล่อม (z3 หัวข้อ 6.0 และคดีญาติ 5)**: ผมนำมาจากเรื่องโอดิสซีอุสที่ให้ลูกเรืออุดหูด้วยขี้ผึ้งตอนผ่านเกาะไซเรน ตรวจว่าการใช้เป็นเกร็ดเกมไม่ขัดตัวบท (ผมไม่ได้อ้างว่าเป็นตำนานของยักษ์ทวารบาล)
3. **เซอร์เบอรัสยืนเฝ้าประตู (z3 1.8)**: เซอร์เบอรัสเป็นผู้เฝ้าประตูโลกใต้ดินตามตำนานกรีก ผมใช้ตามนั้น ไม่เพิ่มเรื่องใหม่
4. **วาลดริก (z3 2.11)**: เรื่องคำปฏิญาณ 200 ปี สาวใช้ผู้ยื่นผ้าห่ม และหมอกที่ "เร่งคำสั่งสุดท้าย" เป็นเรื่องแต่งของเกมทั้งหมด ไม่ได้อ้างตำนานแวมไพร์จริง ตรวจเพียงว่าไม่ชนกับเกร็ดแวมไพร์ที่คนทั่วไปคุ้น (กัดคอ แสงอาทิตย์) ซึ่งผมเลี่ยงไว้
5. **สะกดชื่อ "วาลคิรี"** ตามคำตัดสินคุณเป้ (Reese เคยแจ้งว่าพจนานุกรมใช้ "วาลคีรี") รับตามคุณเป้ ไม่ต้องตรวจซ้ำ

## ต้องให้คุณเป้ตัดสิน
1. **ลงโทษนางสีดาได้จริงไหม** ผมให้เลือกลงโทษได้ตามที่คุณเป้ขอ แต่เขียนให้หนุมานลงมาก่อนหมายถึงมือผู้คุม ไม่มีภาพนางสีดารับโทษ (A4) ถ้าอยากให้เห็นฉากรับโทษสั้น ๆ ก่อนหนุมานมา บอกได้ (ผมไม่แนะนำเพราะอ่อนไหวกับรามเกียรติ์)
2. **คะแนน**: ลงโทษ/ไม่ลงโทษ/พักคดี ให้ผลคะแนนเท่ากันหมดหรือไม่ (ผมแนะนำเท่ากัน เพื่อไม่ชี้ทางเฉลย) หรืออยากให้ "พักคดี" ได้บันทึก "รอบคอบ"
3. **ข้อหา "บัญชีผิดปกติ"** ไม่ผูกรหัสบาป จึงไม่มีคะแนนบาปเมื่อผู้เล่นลงโทษ ยืนยันหรือไม่
4. **ข้อบรรเทาคดีนายพล**: ใช้ "โรงพยาบาลรักษาฟรี" หรือ "บริจาคเงินเดือนหนึ่งปี" (ตัวสำรอง) หรือ "ตัดข้อบรรเทาออก" (ไม่แนะนำ ดูเหตุผลส่วน B)
5. **ข้อความขอบเขตใน z3** (ดูหัวข้อ 13 ท้ายไฟล์ z3): ระดับทัณฑ์วาลดริก "หนัก 4/5" ป้ายระดับตามเกม · ของรางวัลขี้ผึ้งอุดหู 3 ก้อนจากศึกทดสอบยักษ์ทวารบาล (หรือเปลี่ยนเป็นเงิน) · ระยะเวลาที่ซิบิลหายไปรับโทษ
6. **"รอบหน้า" ในบรรทัดเตือนท่า (D1)**: ถ้าศัตรูมี 3 เทิร์นต่อรอบ "รอบหน้า" ที่เกมหมายถึง = เทิร์นถัดไปของศัตรู หรือรอบเต็มถัดไป ผมเขียนตามบอสท่าอื่น (EN "next turn") ให้ Toby ยืนยันว่าตรงกับกลไก ถ้าไม่ตรงจะเปลี่ยนเป็น "เทิร์นถัดไป" ทั้ง 4 ท่า
