## ปัญหาหลักที่พบและวิธีแก้ (ใช้ทั้งชุด)
1. จดหมายและบทเปิดไม่บอกว่า "ใครเป็นอะไรกับใคร" แก้โดยใส่ตำแหน่งและความสัมพันธ์ในประโยคแรกของผู้พูด เช่น "ผมเป็นลูกชายของทัณฑ์ ผู้คุมทัณฑ์ที่สุวรรณภูมิ"
2. บรรทัดผลจบภารกิจใช้ "เขา" ลอย ๆ แก้เป็นชื่อหรือบทบาท เช่น "ซาโตริเขียนบันทึกแทนผู้ต้องหา"
3. คำบอกบทของผู้เขียน (dev note) หลุดมาเป็นข้อความที่ผู้เล่นเห็น เช่น "(NPC ใกล้แท่นตลอดสำนวน ไม่พูดจนกว่าตัดสินเสร็จ)" "(ผู้เล่นเลือกผู้คุมและความแรงตามปกติ)" "(ต่อ)" แก้เป็นประโยคบรรยายปกติ
4. kin: บรรทัดตอบของญาติ (branch) ถูกแสดงตอนกลับไปหาคนส่งเรื่อง แต่ขึ้นต้นด้วย "ทัณฑ์:" เหมือนทัณฑ์อยู่ตรงนั้น แก้เป็นคำเล่าต่อ เช่น "ทัณฑ์ฟังจนจบเล่มแล้วพูดว่า "..."" (ยังคงรูป `**[tag]** → ข้อความ`)
5. ลด "..." ที่ไม่จำเป็น และตัดมุก "ล้อเล่น/ไม่ใช่ล้อเล่น" ที่สลับไปมาจนงง เหลือไว้เฉพาะเพลิง/เทอร์โบ (เป็นนิสัยแฝดที่ cross-zone line และ kinPlerng อ้างถึง)

## ที่ไม่แน่ใจ / ต้องให้ Claudy ตัดสิน
1. **ไม่มี Bash/grep ในรอบนี้** — อ่านได้เฉพาะไฟล์ที่ระบุ จึงไม่ได้ค้นหาเทสต์ที่อ้างข้อความตรง ๆ และไม่ได้รันเทสต์ ฝาก Claudy รัน และสตริงที่เปลี่ยนแล้วเสี่ยงชนเทสต์มากสุดคือ
   - `side-quests.js:46` "ผมไม่ได้โทษท่านครับ ... บอกเฉย ๆ" (ส่วนต้น "ผมไม่ได้โทษท่านครับ" ยังอยู่)
   - `side-quests.js:48` "เรื่องนี้เขายังไม่ได้อนุญาตให้ใครรู้"
   - ข้อความ choices ของ sqGuard (2 ข้อความ) เปลี่ยน · ของภารกิจอื่นและ kin ทั้งหมดไม่เปลี่ยน
   - ที่ขึ้นต้นเดิม "ทัณฑ์ (ต่อ):" "กานต์ (เขียนตอบหนึ่งบรรทัด):" และ branch ที่ขึ้นต้น "ทัณฑ์:" "กานต์:" "บุญ:" "ดำ:" "บัฟเฟอร์:" "เพลิง:" ถูกเปลี่ยนเป็นประโยคเล่าต่อ
2. **ข้อความ UI ที่อยู่นอกไฟล์ที่ระบุ ไม่ได้แก้** เพราะหาตำแหน่งไม่ได้โดยไม่มี grep: "✓ ปิดภารกิจแล้ว · รางวัลรับไปแล้วครั้งเดียว" (ในภาพตัวอย่าง น่าจะอยู่ใน `ui.js`) — เกี่ยวกับระบบรางวัลของ Toby จึงน่าจะเป็นจุดที่ต้องแก้ตอนทำรางวัลอยู่แล้ว · ข้อความเป้าหมายใน `quest-journal.js` ขั้นสุดท้าย "ส่งคำตอบให้X และรับรางวัลเพื่อปิดภารกิจ" ก็ไม่ได้แตะ เพราะมีคำว่ารางวัล
3. **ไม่ได้แก้** `quest-cases.js` (เนื้อคดีวิญญาณ, `reward`/`fail` ของ campelder) และ `CROSS_ZONE_LINES` / `MERCHANT_STORIES` / `CHARACTER_HISTORY` / `KIN_HISTORY` เพราะไม่ใช่บทพูดภารกิจข้างตามขอบเขต · เป็นข้อสังเกตว่า `MERCHANT_STORIES.asia` ใช้ชื่อ "ยามา" ส่วนที่เหลือใช้ "ยมบาทน้อย" (ไม่ขัดกฎ แต่ไม่สม่ำเสมอ)
4. **ช่องว่างที่ยังเหลือ: array ที่เป็น `[]`** — sqNira/sqKan/sqDam/sqMerchant/sqGuard ขั้น 3 และ sqBoon ขั้น 4 เป็น array ว่าง ผมไม่ใส่ข้อความเพราะไม่รู้ว่า UI ใน `ui.js` ถือว่า "ไม่มีบท" เป็นเงื่อนไขอะไรหรือเปล่า (ขั้น 3 ของ sqTaan, sqPlerng, sqBoon มีข้อความอยู่แล้วและผมเกลาให้) ถ้าต้องการบรรทัดบรรยายตรงนั้นด้วย บอกได้
5. **kinGuard ขั้น 2 ไม่มีบทพูดก่อนเลือก** เป็นโครงเดิม (ทุกบรรทัดของ dialogue[2] เป็น branch) ผู้เล่นจึงเห็นแค่ปุ่มตัวเลือกที่ยักษ์ประตูนรกเครือข่าย ผมเลยทำให้ตัวเลือกบอกบริบทเอง ถ้าจะเพิ่มบรรทัดบรรยายต้องยอมเพิ่มสมาชิกใน array
6. **ข้อสันนิษฐานที่ต้องให้คุณเป้/Reese ยืนยัน** (เป็นการอนุมานจากเนื้อเรื่องเดิม ไม่ใช่เรื่องใหม่)
   - sqPlerng: เหตุผลที่อ็อกเนียนฝากเพลิง ผมเขียนว่า "เขาเป็นผู้คุมไฟเหมือนผม" (ตำแหน่งเดียวกัน) เพราะเนื้อเรื่องเดิมไม่บอกว่าสองคนรู้จักกันอย่างไร
   - sqNira: เติมว่า "คนที่ควรถูกเรียกลงมา...ได้ขึ้นสวรรค์ไปแล้ว" ตีความจากขั้น 2 เดิม ("ขอเรียกเขากลับจากประตูสวรรค์") — ถ้าเรื่องสลับเลขตั้งใจให้เป็นอีกแบบ ต้องแก้ประโยคนี้
   - sqBoon: เก็บวลี "วาระที่เกินมา" ของบุญไว้ตามเดิมเพราะไม่แน่ใจความหมายตามประวัติตัวละคร ("ยืมเงินกองทุนค่าโลง") — ประโยคนี้ยังกำกวมอยู่เล็กน้อย
   - sqGuard ขั้น 5 "อีกฝั่งหนึ่งของประตูก็มีคนเฝ้าอยู่ด้วย" เก็บตามเดิม ไม่แน่ใจว่าหมายถึงใคร (ยมบาทน้อยหรือนิรา)
   - ผมตัด "ครับ" ออกจากโกคุกับยักษ์ทวารบาลในประโยคที่ใช้ "ข้า" เพราะไม่เข้ากัน แต่คงไว้ที่ซาโตริ ซึ่งสุภาพแบบนักอ่าน ถ้าอยากให้คงไว้ทุกตัวให้บอก
7. ขั้นสุดท้ายของ sqPlerng ถ้าเปลี่ยน choice 0/1 ผู้เล่นจะเห็นบรรทัดผลของอ็อกเนียนก่อน แล้วค่อยเห็นบทเพลิง (ลำดับจาก `questDialogue` ไม่เปลี่ยน)
