### 2.1 อัปโหลดเกมแบบภาพรวม (SteamPipe) — ไม่ลงรายละเอียดแพ็ก Tauri/Electron

แหล่ง: [Uploading](https://partner.steamgames.com/doc/sdk/uploading), [Depots](https://partner.steamgames.com/doc/store/application/depots), [Branches](https://partner.steamgames.com/doc/store/application/branches), [Builds](https://partner.steamgames.com/doc/store/application/builds), [Platforms](https://partner.steamgames.com/doc/store/application/platforms), [Testing](https://partner.steamgames.com/doc/store/testing) (ตรวจ 9 พ.ย. 2569)

- **Steam ต้องการไฟล์แบบไหน:** ✅ โปรแกรมที่ติดตั้งแล้วรันได้บน OS ที่ติ๊กในหน้าร้าน (หน้ารีวิว: "must start up properly on all supported operating systems") · ไม่พบเอกสารที่พูดถึงเกม HTML/เว็บโดยตรง จึงต้องแพ็กเป็นโปรแกรม (Toby ทำ) · ไม่พบว่าบังคับใส่ Steamworks API ในเกม 🔴 (ไม่ได้ตรวจหัวข้อนี้)
- **ระบบปฏิบัติการที่รองรับตามเอกสาร:** Windows 7 ขึ้นไป · macOS: เอกสารระบุ Intel Mac / OS X 10.11 ขึ้นไป และ "ตั้งแต่ 14 ต.ค. 2019 แอป macOS ใหม่ต้อง 64-bit และ notarized โดย Apple" (ติ๊ก "macOS > 64 Bit Binaries Included"), ห้ามเปิด entitlement `com.apple.security.app-sandbox` · Linux/SteamOS เป็นทางเลือก · **เอกสารไม่ระบุ Apple Silicon** 🔴 (หน้านี้ข้อมูลเก่า ปี 2019 เป็นส่วนมาก) · ไม่บังคับให้รองรับทุก OS: เลือกติ๊กเอง
- **Depot:** กลุ่มไฟล์ที่ส่งถึงผู้เล่นเป็นชุดเดียว · รองรับหลาย OS = แยก depot ต่อ OS (ไฟล์ร่วมใส่ depot "all OS") · ต้องเพิ่ม depot เข้า package (เช่น Developer Comp) ไม่งั้น Mac/Linux build อาจติดตั้งไม่มีไฟล์
- **ContentBuilder / steamcmd:** อยู่ในโฟลเดอร์ `tools/ContentBuilder` ของ SDK (`builder` Windows, `builder_osx`, `builder_linux`, `content`, `output`, `scripts`) · เขียนสคริปต์ VDF 2 ชนิด: `app_build_<AppID>.vdf` (AppID, Desc, ContentRoot, BuildOutput, Preview, SetLive, Depots) และ `depot_build_<DepotID>.vdf` (FileMapping, FileExclusion) · ตัวอย่างเริ่มต้น `simple_app_build.vdf` · คำสั่งตัวอย่าง Windows: `steamcmd.exe +login <account> <password> +run_app_build ..\scripts\simple_app_build.vdf +quit` · Preview build เขียน log อย่างเดียว ไม่อัปโหลด
- **Branch:** build ใหม่อัปขึ้น branch; `default` = เวอร์ชันที่ลูกค้าได้ ก่อนปล่อยคือเวอร์ชันที่ผู้ทดสอบโหลด · **SetLive อัตโนมัติใช้กับ default ไม่ได้** ต้องกด "Set Build Live Now" ในหน้า App Admin เอง · branch ตั้งรหัสผ่านได้ (สำหรับ beta)
- **บัญชีอัปโหลด:** ต้องมีสิทธิ์ "Edit App Metadata" + "Publish App Changes To Steam" (เอกสารแนะนำใช้บัญชีเฉพาะ build) · ทดสอบเองได้ด้วย Dev Comp package / release override keys / Steam Playtest
- **ต้องดูในระบบ:** การตั้ง launch options (executable ต่อ OS) — ใน Uploading บอกว่า "define launch options and depots, publish the changes" แต่หน้า Platforms/Builds ไม่อธิบายรายละเอียด

### 3.2 กฎภาพ capsule (Graphical Asset Rules + Standard)

- ✅ ใส่ได้เฉพาะ "game artwork, the game name, and any official subtitle"; ต้องมีชื่อ/โลโก้ที่ **อ่านออก** และขนาดภาพถูกต้องตามกำหนด
- ❌ ห้าม: คะแนนรีวิวทุกชนิด (รวม Steam reviews/สื่อ), ชื่อ/สัญลักษณ์รางวัล, ข้อความโปรโมชั่นลดราคา ("On Sale Now"), calls to action ("Wishlisting now available", "Prepurchase Now"), ข้อความหรือภาพที่โปรโมตสินค้าอื่น/ภาคต่อ, ข้อความอื่น ๆ
- ภาพ capsule ทั้งร้านและไลบรารีต้องเหมาะระดับ **PG-13**
- Library Hero ห้ามมีคำใด ๆ; Library Logo เฉพาะโลโก้บนพื้นโปร่งใส
- ข้อความอัปเดต/อีเวนต์ทำได้เฉพาะแบบ **Artwork Override** อายุ <= 14 วัน และต้องแปลให้ครบเท่าภาษาที่เกมรองรับ
- ผลถ้าผิดกฎ: "may have limits to visibility within the Steam store" และ "ineligible for featuring in official Steam sales and events" (กฎมีผล 1 ก.ย. 2022)
- คำอธิบาย/ภาพ: ห้ามลิงก์/โปรโมตเว็บอื่น, ห้ามภาพที่เลียนแบบ UI ของ Steam, ห้ามโฆษณาเกมอื่น (ลิงก์โซเชียลใส่ในแท็บ Basic Info แทน)

## 6. จุดที่ไม่ได้ยืนยัน / ไม่พบในเอกสารทางการ (🔴/⚠️)

**เอกสาร/บัญชี**
1. ชนิดเอกสารยืนยันตัวตนที่ Steam รับ (บัตร ปชช./พาสปอร์ต/ใบขับขี่) — หน้า Identification Documents ไม่ระบุ
2. เอกสารบริษัทที่ Steam ขอ (หนังสือรับรอง, ภพ.20 ฯลฯ) — ไม่พบ (หน้า Steam Direct บอกเพียงว่าแปรตามบุคคล/บริษัทและประเทศ)
3. Tax interview ของนิติบุคคลไทยออกฟอร์ม W-8BEN หรือ W-8BEN-E — เอกสาร Steam ไม่กล่าวถึง W-8BEN-E ต้องดูในระบบ
4. เลขที่กรอกเป็น TIN ไทย (เลข 13 หลัก) — ยืนยันจากผลค้นหา rd.go.th เท่านั้น 🟡 ไม่ได้อ่านหน้า rd.go.th ต้นทางโดยตรง
5. อัตราหักภาษีสหรัฐจริงของผู้พัฒนาไทย: Tax FAQ ระบุว่ารายได้ขายเกมถูกจัดเป็นค่าสิทธิ (royalty) และ "royalty copyright rate will apply to US sourced sales on games and related DLCs" ✅; IRS Table 1 (จาก report ก่อนหน้า) ลิขสิทธิ์ไทย 5% ✅ — **แต่ Tax FAQ ไม่ระบุว่าไทยมีสนธิสัญญา/อัตราเท่าไหร่ และผลจริงขึ้นกับ tax interview + TIN** → ปรึกษานักบัญชี
6. สนธิสัญญาไทย-สหรัฐ มีผล 1 ม.ค. 1998 — จาก report ก่อนหน้า (IRS Table 3) ไม่ได้ตรวจซ้ำรอบนี้
7. คำนิยาม "Adjusted Gross Revenue" ที่ใช้คืน $100 — เอกสารไม่นิยาม
8. อายุขั้นต่ำของผู้สมัคร Steamworks — ไม่พบ
9. ข้อกำหนด Steam Guard/2FA ตอนสมัคร Steamworks — ไม่พบ (พบเฉพาะ: ต้องมี Steam Mobile App หรือเบอร์มือถือ เพื่อ set build live บนเกมที่วางขายแล้ว; steamcmd อาจโดน Steam Guard)
10. วิธีชำระ $100 ที่ใช้ได้จริงในไทย (บัตรเครดิต/พร้อมเพย์ ฯลฯ) — ไม่พบ ต้องดูตอนจ่าย
11. ช่องกรอกธนาคารจริง (SWIFT/BIC ถูกถามหรือไม่, routing number ของธนาคารไทยกรอกอย่างไร) — ต้องดูในระบบ
12. อักษรไทยในชื่อบริษัท/ที่อยู่ใช้ได้หรือไม่ (FAQ ห้าม non-English special characters)
13. Apple Silicon / macOS ปัจจุบัน — หน้า Platforms ไม่กล่าวถึง Apple Silicon (ข้อกำหนดข้อมูลปี 2019)
14. การสร้าง app ทำได้เมื่อจ่าย fee แล้วหรือต้องรอยืนยันภาษี/ธนาคารผ่านก่อน — เอกสาร 2 หน้าไม่ตรงกัน

16. ความยาว trailer (ไม่ระบุ) และ trailer เป็นข้อบังคับหรือไม่ (เอกสารขัดกันเล็กน้อย)
