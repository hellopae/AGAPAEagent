## 1. ประเด็นที่ Claudy ขอให้ตัดสินชัด

| ประเด็น | คำตัดสิน |
|---|---|
| ชนิดจอ "LED, HD, OLED, Retina" | ⚠️ แก้ถ้อยคำ (ข้อ 1 ใน FIX LIST). LED (จอ LCD แบ็กไลต์ LED) กับ OLED เป็นเทคโนโลยีแผงจริง; **HD เป็นความละเอียด ไม่ใช่ชนิดจอ**; **Retina เป็นชื่อการค้าของ Apple** (จดเครื่องหมายการค้า ครอบคลุมทั้งแผง LCD และ OLED ไม่มีค่า ppi ตายตัว) ถ้าเรียงเป็น "ชนิดจอ" ในลิสต์เดียวกันจะผิดหมวดและซ้อนกัน |
| ระบบปฏิบัติการมีผลต่อสีจริงไหม | ✅ อ้างได้ ไม่ต้องแก้. ระบบปฏิบัติการจัดการโปรไฟล์สีจอ (macOS ColorSync / Windows ICM) และมีฟีเจอร์ระดับระบบที่เปลี่ยนสีที่เห็น เช่น True Tone, Night Shift ของ Apple; แต่ละแอปรองรับ color management ไม่เท่ากัน ผลคือภาพเดียวกันอาจต่างกันข้ามระบบ ถ้อยคำ "ขึ้นอยู่กับ ... ระบบปฏิบัติการ" ไม่ได้ฟันธงเกินจริง |
| ชื่อไทย Cyan/Magenta | ⚠️ ไม่มีศัพท์มาตรฐานที่ยืนยันได้ (ไม่พบราชบัณฑิตยสภา). แหล่งไทยที่พบ (OFM บล็อกหมึก Brother) ใช้ Cyan = "ฟ้าอมเขียว", Magenta = "ชมพูอมแดง". "ม่วงแดง" ของคุณเป้ใกล้เคียงความหมาย (Magenta คือ purplish-red) แต่ไม่ใช่คำเรียกเดียวที่ใช้กัน จึงให้เติมทับศัพท์ (ไซแอน/แมเจนตา) กำกับ (ข้อ 2 ใน FIX LIST) |
| Pantone = spot/solid color | ✅ Pantone นิยาม spot color = หมึกผสมสำเร็จทาลงกระดาษโดยตรง ใช้เมื่อต้องการสีเฉพาะไม่กี่สีให้แม่น; ชุดสีใน Adobe ชื่อ "PANTONE+ Solid Coated" จึงเรียก solid ได้ |
| นีออน/เมทัลลิกพิมพ์ CMYK ไม่ได้ | ✅ Adobe Illustrator ระบุว่าสีนีออนบางเฉดไม่มีค่า CMYK เทียบเท่า; Pantone FAQ ระบุว่า Color Bridge (ตัวแปลง spot->CMYK) ไม่รวมหมึก metallic/neon/pastel; ทางออกคือหมึกพิเศษหรือปั๊มฟอยล์ ตรงกับข้อความ |
| การเคลือบ (รวม PVC) ทำให้สีเปลี่ยน | ✅ งานวิจัยวัดผลพบว่าเคลือบเงา (gloss lamination) เปลี่ยนขอบเขตสี (แดงกว้างขึ้น เหลืองเพิ่ม กระทบเขียวมากสุด; ผลต่างเฉลี่ยราว 3.4 ΔE00 ในงานเคลือบ UV อีกชิ้น) และสี spot (PMS) ก็เปลี่ยนจากการเคลือบเงา/ด้าน. "เคลือบ PVC ใส/ด้าน" เป็นคำเรียกการเคลือบที่ใช้กันทั่วไปในโรงพิมพ์ไทย (พบในรายการบริการหลายราย) ไม่มีงานวัดเฉพาะ PVC แต่ข้อความไม่ได้อ้างตัวเลข ไม่ต้องแก้ |

## 3. ความน่าเชื่อถือของแหล่ง
- แหล่งหลักที่ใช้: Adobe Help (helpx.adobe.com), Pantone (pantone.com + FAQ PDF), Apple Support, ISO/Fogra (ผ่านรายการมาตรฐานและหน้าสรุป), Wikipedia (Retina/Prepress proofing), งานวิจัยวัดผลเรื่องเคลือบ (hrcak.srce.hr, KMUTT)
- ข้อจำกัดที่ต้องรู้: (ก) ศัพท์ไทยของ Cyan/Magenta ไม่มีแหล่งทางการ ใช้ได้แค่บล็อกผู้ขายหมึกเป็นแนวทาง (ข) เรื่อง "เคลือบ PVC" ยืนยันได้ระดับคำเรียกในอุตสาหกรรม ไม่มีงานวัดเฉพาะ PVC (ค) ไม่ได้เปิดอ่านตัวมาตรฐาน ISO 12647-7/14861 ฉบับเต็ม (ต้องซื้อ) อ้างจากหน้าสรุปมาตรฐานเท่านั้น
- ข้อความของ Rae/คุณเป้ใช้ถ้อยคำป้องกัน ("อาจ", "บางเฉด", "ควรตรวจ", "ยังไม่ควรถือเป็น") จึงไม่มี claim เสี่ยงเกินแหล่ง

## 4. หมายเหตุไม่บล็อก (ไม่ต้องแก้ ถ้า Claudy เห็นว่าเหมาะ)
- "พรูฟเพลท" อาจทำให้ผู้อ่านทั่วไปสับสนว่าคืออะไร (ผมเข้าใจว่าหมายถึงพิมพ์ทดลองจากเพลทจริง) ถ้าจะอธิบายเพิ่มต้องให้คุณเป้ยืนยันความหมายก่อน จึงไม่เสนอถ้อยคำใหม่
- "ปัญหาที่คนทำงานพิมพ์ทุกคนต้องเจอ" เป็นโวหารของคุณเป้ (💬) ถ้าต้องการให้รัดกุมขึ้นเปลี่ยนเป็น "มักเจอ" ได้ แต่ไม่บังคับ

## 5. คำตัดสิน: FIX LIST (2 ข้อ, แก้ 1 รอบ)

1. หัวข้อ 1 ย่อหน้าแรก (💬2) · ชนิดจอ
   - เดิม: "แต่จอแต่ละชนิด ทั้ง LED, HD, OLED และ Retina ก็ให้สีสันและความสดไม่เหมือนกัน"
   - แก้เป็น: "แต่จอแต่ละชนิด เช่น LED, OLED และจอ Retina ของ Apple ก็ให้สีสันและความสดไม่เหมือนกัน"
   - เหตุผล: HD เป็นความละเอียด ไม่ใช่ชนิดแผง จึงตัดออก; Retina เป็นชื่อการค้า จึงระบุว่าของ Apple. (ทางเลือกสั้นกว่า ถ้าไม่อยากเอ่ยแบรนด์: "จอแต่ละชนิดและแต่ละรุ่น เช่น LED และ OLED ก็ให้สีสัน...")
   - หมายเหตุ: ต้องแก้ตรงนี้ที่เดียว (FAQ Q1 ไม่ได้ลิสต์ชนิดจอ) และต้องลบ 💬2 ออกด้วย

2. หัวข้อ 3 บรรทัดแรก (💬4) และ FAQ Q2 · ชื่อไทยของสี CMYK
   - เดิม (หัวข้อ 3): "สีฟ้าอมเขียว สีม่วงแดง สีเหลือง และสีดำ"
   - แก้เป็น: "สีฟ้าอมเขียว (ไซแอน) สีม่วงแดง (แมเจนตา) สีเหลือง และสีดำ"
   - เดิม (FAQ Q2): "ระบบสีฟ้าอมเขียว ม่วงแดง เหลือง และดำ"
   - แก้เป็น: "ระบบสีฟ้าอมเขียว (ไซแอน) ม่วงแดง (แมเจนตา) เหลือง และดำ"
   - เหตุผล: ไม่มีศัพท์ไทยมาตรฐานของ Cyan/Magenta ที่ยืนยันได้ (แหล่งไทยเรียก Magenta ว่า "ชมพูอมแดง") การใส่ชื่อทับศัพท์กำกับทำให้ผู้อ่านจับคู่กับชื่อสีบนไฟล์/หมึกได้แน่นอน โดยไม่เปลี่ยนน้ำเสียงคุณเป้
