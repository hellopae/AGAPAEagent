## 1. ศาสนา/ตำนาน

| ประเด็น | ผล |
|---|---|
| กรรม = เจตนา | ✅ E1 บอสถูกสะกด = เจตนาถูกระบบทับ ไม่มีโทษ ไม่เข้าศาล สอดคล้องหลัก ไม่อ้างว่า "ถูกสะกดแล้วพ้นกรรม" · `campelder` ผู้ตะคอกไม่ได้ติดบาปเกินจริง · `chainhand` บาปคือเงียบโดยเลือก (เจตนา) · `feudgran` มีข้อบรรเทา w:-2 เรื่องโทษผิดคน · ยกเว้นข้อ 1 |
| พญายมไต่ถาม ไม่ใช่ผู้ลงโทษ | ✅ ไฟล์นี้ไม่มีพญายมลงโทษ ผู้ตัดสินคือยมบาทน้อย (ผู้เล่น) ตามกลไกเกม ไม่ขัดข้อที่แก้ใน W1 |
| ไม่ลบกรรมด้วยการสารภาพ/ของเซ่น | ✅ SQ-6 "ไม่ได้บอกว่าไม่เป็นไร เอ็งจำมันไว้" และ SQ-1 "ไม่ได้ขอให้เขารู้สึกผิด" ไม่ใช่พิธีล้างบาป · SQ-7 ดู FIX 3 |
| ยักษ์ทวารบาลกลับใจ (R6) | ✅ ใช้ "ย่อตัว" ไม่ใช้ "ไหว้/กราบ" ไม่ระบุวัด ตรงที่ W1 FIX 7ค แนะนำ (เค้าโครงคล้าย ไม่ใช่ต้นกำเนิดยักษ์ทวารบาล) |
| วาลดริก/แวมไพร์ | ✅ ไฟล์นี้ไม่ได้ขยายความหลักความเชื่อแวมไพร์ เอ่ยแค่ "ราตรี/ฝัน" ไม่ซ้ำข้อผิดของ W1 FIX 4 |
| ควันทอง/ของเซ่น | ✅ ติดป้ายคติจีน-ไทย ไม่ใช่เถรวาท (R13) · ดู FIX 3 |

## 2. คดีใหม่ 8 คดี: บุคคล/เหตุการณ์จริง และความเคารพ

| คดี | ชี้บุคคล/เหตุการณ์จริง | เนื้อหาหนัก/ความเคารพ |
|---|---|---|
| `swapdoc` | ไม่ชี้ · ไม่มีชื่อรพ./คน/ปี · โยนความผิดให้พยาบาลเป็นรูปแบบทั่วไป | ✅ พยาบาลไม่ถูกเอ่ยชื่อ ไม่ตำหนิวิชาชีพ |
| `feudgran` | ไม่ชี้ · หมู่บ้านสมมติ | ✅ |
| `campelder` | ไม่ชี้ · ค่ายน้ำท่วมทั่วไป ไม่ระบุปี/พื้นที่ | ✅ ผู้ประสบภัยเป็นผู้มีศักดิ์ศรี ไม่ใช่เหยื่อน่าสงสาร · ผู้ทุจริตเป็นตัวละครสมมติ (ดำ) ไม่ระบุหน่วยงาน |
| `chainhand` | ไม่ชี้ · "เมืองหลวงเก่า" สมมติ ไม่ระบุประเทศ | ✅ |
| `silentman` | ไม่ชี้ · ไม่ระบุประเทศ/ปี/เขตงาน | ✅ หนักที่สุดในชุด (หนี้ผูกมัดน้องสาว) แต่ไม่มีฉากรุนแรงละเอียด เป็นบทเศร้า · กลไก `private` (กระจก/สะกดจิตอ่านใจ → กรรม +6) เป็นการให้ความเคารพความยินยอมชัดเจน |
| `hirefire` | ไม่ชี้ · ไม่ระบุเมือง/ปี/ผู้เสียชีวิต ("ห้องแถว/โกดัง" ทั่วไป) · ข้อสังเกต: ห้ามเติมที่ตั้ง "ชุมชนแออัด/ที่ดินพิพาท" ลงไป เพราะใกล้กับกรณีไฟไหม้ชุมชนที่เป็นข่าวจริง | ✅ ผู้ก่อถูกวางเป็นมนุษย์ มี merit จ่ายค่าทำศพ · ติด FIX 1-2 |
| `hospice` | ไม่ชี้ · ไม่ระบุสถานพัก/บริษัท | ✅ ผู้ป่วยระยะท้ายไม่ถูกเอามาเป็นมุก คำฝากแม่เขียนด้วยความเคารพ ไม่มีรายละเอียดทางการแพทย์ · ผู้ดูแล (เกรซ) ถูกวางเป็นคนยอมรับความผิดพลาดเอง ไม่ลดภาพวิชาชีพดูแลผู้ป่วย |
| `smokeheir` | ไม่ชี้ · ตลาดเช้า/พ่อค้าข้าวสารทั่วไป | ✅ ดู FIX 3 |

ทุกคดียังคงกติกา "ห้ามเพิ่มชื่อ สถานที่ ปี ยอดเงิน" ที่ผมยืนยันไว้ใน W1 (§4) · ตะขอที่ใช้ซ้ำกับคดีดัดจากเรื่องจริง (`orchard` H08) ถูกเลี่ยงแล้ว (SQ-6 ใช้ปมค้าง C08 แทน) ✅

## 3. การเหมารวมเชื้อชาติ/ภูมิภาค

| ประเด็น | ผล |
|---|---|
| อากุระ "คนต่างถิ่น ห้ามผ่าน" | ✅ เป็นคำสั่งครอบงำที่ทับนิสัยรายบุคคล (เกลียดการถูกล่าม) และถูกวางว่าไม่ใช่ความต้องการของเขา ไม่ใช่ลักษณะของชนชาติ |
| โซนเอเชีย 3 เควส (`chainhand` `silentman` `smokeheir`) | ✅ ไม่มีตัวละครระบุชาติพันธุ์ ไม่มีสำเนียง/ลักษณะทางกายภาพ · ผู้คุมเรือนงานและพ่อค้าโกงเป็นบุคคลสมมติ · ข้อสังเกต (ไม่บล็อก): `smokeheir` เป็นพ่อค้าโกงตาชั่งคู่กับธรรมเนียมเซ่นไหว้แบบจีน-ไทย ระวังภาพ/บทที่ตามมา อย่าใส่ลักษณะที่ทำให้ "พ่อค้า+จีน = โกง" |
| โซนตะวันตก (วาลดริก, `hirefire`, `hospice`) | ✅ วาลดริกสุภาพ เป็นเหยื่อ ไม่ใช่ตัวร้ายเหมารวม · `hirefire` `hospice` ไม่มีเครื่องหมายเชื้อชาติ |
| โซนไซเบอร์ | ✅ ไม่มีประเด็น "ผู้ใช้เดิม" ไม่ระบุตัวตน |

ข้อสังเกตเล็กไม่บล็อก: SIG-4 ให้ผู้เล่น "สะกดจิตสวน" วาลดริกที่เป็นเหยื่อโดยไม่มีผลกรรม ขณะที่ SQ-4 ปรับกรรม +6 กับการอ่านใจผู้ไม่ยินยอม ถ้าอยากให้หลักความยินยอมสม่ำเสมอ อาจเขียนบรรทัดบอกว่าเป็นการหยุดคำสั่งชั่วคราวในศึก (คุณเป้เคาะได้)
