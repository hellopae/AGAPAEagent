`qwen-plus` intl: output **$1.20 (non-thinking)** vs **$4.00 (thinking)** — ต่างกัน **3.3 เท่า**

| สถานการณ์ | ต้นทุน / 1 simulation |
|---|---|

**MiroFish เปิด thinking mode ไหม — ผมตอบไม่ได้:**
- ✅ ยืนยันแล้ว: `backend/app/utils/llm_client.py` และ `config.py` **ไม่มีคำว่า `enable_thinking` / `thinking` / `extra_body` เลย** → ใช้ค่า default ของ API
- ⚠️ **ค่า default ของ `qwen-plus` ผ่าน OpenAI-compatible mode — ผมยืนยันไม่ได้จากเอกสารที่เข้าถึงได้** เอกสารพูดถึงวิธี**สั่ง**เปิด/ปิด (`extra_body={"enable_thinking": ...}`) แต่ไม่ระบุค่าเริ่มต้นของโมเดลเชิงพาณิชย์รุ่นนี้ชัดพอที่ผมจะยืนยัน **ผมจะไม่เดา**

→ **ไม่ใช่ข้อผิดพลาดของ Nick** (ตัวเลขของเขาถูกภายใต้ non-thinking ซึ่งเป็นสมมติฐานที่สมเหตุสมผลที่สุด) แต่ **ควรเพิ่ม 1 บรรทัดใน sensitivity** ว่า "ถ้า thinking mode เปิดโดย default → ฿396" — ระดับ **ข้อเสนอ ไม่ใช่ข้อบังคับแก้** เพราะข้อสรุป "ไม่แพง" ไม่ขยับที่ ฿396 เช่นกัน
