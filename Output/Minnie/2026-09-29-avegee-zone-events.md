# AVEGEE — Event ประจำโซน 2–4 (ข้อเสนอเพื่อทดสอบ ไม่ใช่ข้อสรุป)

**ผู้เสนอ:** Minnie · **วันที่:** 29 ก.ย. 2569 · **ส่งต่อ:** Reese (ตรวจวัฒนธรรม) → Claudy/Astra/Codex (เมื่อคุณเป้เลือก)
**อ้างอิง:** CONCEPT §9 และหมายเหตุ M1.5 (ตัด "ลงทัณฑ์เอง"), `src/data.js` ZONES/MOB, ใบงาน `Output/Claudy/briefs/2026-09-29-avegee-zone-events-arch.md`

## 0. หลักที่ยึดทุกโซน

1. ศัตรูในทุก event ผู้เล่น **ปราบ/จับกลับ/ผนึก** ไม่ใช่ทรมาน ถ้อยคำในข้อความเตือนใช้คำว่า "จับกลับ" "สกัด" "ปราบ" ไม่ใช้ "ลงทัณฑ์"
2. บุคคลในศาสนาที่ยังมีผู้นับถือ (เทพ พระโพธิสัตว์ นักบุญ ทูตสวรรค์ใหญ่) **ไม่เป็นตัวร้าย** ผู้ทดสอบเป็นตัวระดับรองหรือตัวในตำนาน และท่าทีให้เกียรติ (ทดสอบแล้วยอมรับ ไม่ใช่ถูกกำจัด)
3. ตัวละครทุกตัวเป็นตำนาน/นิทานพื้นบ้าน/วรรณกรรมที่พ้นลิขสิทธิ์ หรือตัวสมมติ ตาม §9 ไม่ใช้ชื่อคนจริงหรือคดีจริง
4. โซน 2–4 มี "บอสพี่ชาย" อยู่แล้ว ได้แก่ แม่ทัพตรวนบูรพา / อัศวินบัญชีปัจฉิม / จอมข้อมูลไซเบอร์ ผู้ทดสอบ (ข้อ 3) จึงต้อง **ทดสอบคนละเรื่อง** กับบอส: ผู้ทดสอบดู "ฝีมือตัดสิน" ส่วนบอสดู "สิทธิ์ในการปกครอง"

**ข้อสังเกตด้านโค้ดที่กระทบ event ข้อ 2 (ให้ Claudy/Astra ทราบ):** ตอนนี้ `ZONES[].mobs` ของโซนปัจฉิมคือ [0,2] (เปรตไทยกับมนุษย์หมาป่า) และของเครือข่ายคือ [3,4,5] (ผีกระหัง ปอบ ตานี ซึ่งเป็นผีไทย) ทั้งสองโซนยังไม่มีมอนสเตอร์ประจำโซนของตัวเอง ระลอกของ event ควรอ้างชุดมอนสเตอร์ของ event เอง ไม่ดึงจาก `mobs` เดิม

## 3. โซน 3 ปัจฉิม (ยุโรป อเมริกา รัสเซีย)

**สมมติฐาน:** ถ้าบอสชายแดนเป็นตัวละครที่คนไทยรู้จักโดยไม่ต้องอธิบาย (แวมไพร์) ผู้เล่นจะจำ event ได้ง่ายกว่าตัวใหม่แต่ลึกกว่า (โคสเชย์) ทดสอบด้วยการถามผู้ทดลองเล่นว่า "บอสตัวนี้คือใคร" โดยไม่ให้เห็นชื่อ

## 4. โซน 4 นรกเครือข่าย (CyberHell)

|---|---|---|---|---|---|

| 2 | **ม้าโทรจันหน้าไฟร์วอลล์** | "ไฟร์วอลล์ชายแดนส่งสัญญาณแดง! มัลแวร์ฝ่าเข้ามาเป็นระลอก พายมทูตไปปิดช่องโหว่ให้ทัน" | 3 wave: **W1** บั๊กกลิตช์ x3 **W2** หนอน (worm) x2 + บอต **W3 (บอส)** **ม้าโทรจัน** จากตำนานสงครามทรอย (ในตำนานเป็นของขวัญที่ข้าศึกยอมรับเข้าเมืองเอง ปัจจุบันเป็นชื่อมัลแวร์ด้วย) + บอต x2 | **ต้อง gen 4 ชิ้น:** บั๊กกลิตช์, หนอน, บอต, ม้าโทรจัน (ม้าไม้พิกเซลมีสัญญาณรบกวน ท้องเปิดได้) | "ข้าไม่ได้พังกำแพงหรอก พวกเจ้าเปิดประตูให้ข้าเองต่างหาก" |

### 5.1 ภาพ `img/raw/Boss-frontier1.png` (บอสทศกัณฑ์โซน 1) ให้ยืนยัน

- **ก.** ภาพเป็นยักษ์เขียว 1 หน้า 1 มงกุฎยอด 4 กร ถือจักร สังข์ และคทา กรที่สี่กำหมัด ขนบไทยของทศกัณฑ์คือสิบหน้า (มงกุฎซ้อน) ยี่สิบกร ([Wikipedia](https://en.wikipedia.org/wiki/Ten_R%C4%81k%E1%B9%A3as%C4%ABs), [ศิลปวัฒนธรรม](https://www.silpa-mag.com/culture/article_132821) — Minnie ยังไม่ได้เปิดอ่านเต็ม) ขอให้ยืนยันด้วยแหล่งที่ตรวจสอบได้
- **ข.** จักร สังข์ คทา (และดอกบัว) เป็นอาวุธ/เครื่องหมายประจำพระนารายณ์ในขนบไทยใช่หรือไม่ การให้ตัวร้ายถืออาวุธนี้ถือว่าไม่เหมาะหรือไม่ พระนารายณ์เป็นเทพที่ยังมีผู้นับถือและมีความสำคัญในพิธีหลวงไทย
- **ค.** ผิวเขียวกับสี่กรตรงกับภาพพระรามในขนบไทย (พระรามเป็นอวตารของพระนารายณ์ — [Vithita](https://vithita.com/en/character-content/ramakian-cont/)) ภาพนี้จึงอาจถูกอ่านว่าเป็นพระราม/พระนารายณ์ ไม่ใช่ทศกัณฑ์ ให้ยืนยันด้วยว่าหน้าทศกัณฑ์ในโขนเป็นสีเขียวเป็นปกติ ([World Mythos](https://worldmythos.com/thotsakan/)) ดังนั้นสีผิวเขียวเป็นสัญญาณที่ใช้แยกไม่ได้
- **ง.** ยอดสุดของหัวโขนทศกัณฑ์มีหน้าฤๅษีหรือไม่ (ต้องยืนยัน) ถ้ามีจะเป็นรายละเอียดที่ควรเก็บไว้ในภาพใหม่
- **จ.** หัวโขนทศกัณฑ์เป็นวัตถุที่นักแสดงโขนเคารพ (มีพิธีไหว้ครู/ครอบโขน) การนำตัวโขนมาเป็นบอสที่ผู้เล่นต้องสู้ ทำได้ในระดับไหน
- **ฉ.** ในตำนานทศกัณฑ์คืออดีตยักษ์นนทกที่พระนารายณ์สาป ถ้าจะให้ภาพนี้อ้างเรื่องนี้ ถือว่าอธิบายการถือของพระนารายณ์ได้หรือไม่ (Minnie คิดว่าไม่พอ)
- **ตัวเลือกที่เสนอให้เทียบ:** (1) gen ใหม่ให้เป็นสิบหน้ามงกุฎซ้อน ถืออาวุธของยักษ์ (ดาบ ธนู หอก) (2) คงภาพเดิมแต่เปลี่ยนชื่อและถอดจักร/สังข์ เป็นยักษ์ผู้คุมชายแดนทั่วไป (3) ตัดทอนเหลือสี่ถึงหกกรพร้อมสิบหน้า เพื่อลดภาระพิกเซลโดยยังอ่านออกว่าเป็นทศกัณฑ์

### 5.2 บูรพา
1. ชูเตนโดจิ: ตำนานมีศาลหรือการบูชาที่ยังมีอยู่ที่ผู้เล่นญี่ปุ่นอาจไม่พอใจหรือไม่ ตำนานเดิมโยงกับสุรา การจับผู้หญิง และการสังหารโดยนายทหารที่มีตัวตนจริง (ไม่ใช้ส่วนเหล่านี้) ยืนยันว่ากระบองคะนาโบะเป็นอาวุธประจำโอนิที่ถูกต้อง
2. เท็งงุ: ในความเชื่อญี่ปุ่นบางสาย ไดเท็งงุเป็นเทพผู้พิทักษ์ที่มีศาลบูชา ส่วนการาสุเท็งงุเป็นตัวรองลงมา เลือกการาสุเท็งงุไม่ระบุชื่อ ยืนยันว่าเหมาะสมและไม่ทำให้ผู้นับถือรู้สึกถูกหมิ่น
3. การจัด "โอนิ" ญี่ปุ่นเป็นตัวแทนชายแดนบูรพา ทำให้จีน เกาหลี อินเดีย ตกหล่นหรือไม่ ควรมีตัวสมทบจากชาติอื่นหรือไม่ (เช่น ดกเกบี เกาหลี)
4. ยืนยันว่าเลี่ยงตัวต่อไปนี้ถูกต้อง: กวนอู เหยียนหลัวอ๋อง หมาจู่ ซุนหงอคง และเทพฮินดู
5. คำถามค้างเดิมจาก `data.js`: "ดวงไฟวิญญาณ" 人魂 ควรเปลี่ยนเป็นโอนิบิ 鬼火 หรือไม่

### 5.3 ปัจฉิม
1. เคานต์แวมไพร์: ยืนยันว่านิยาย *Dracula* (1897) พ้นลิขสิทธิ์ และต้องอิงคำบรรยายในนิยาย (ชายชราหนวดขาว) ไม่ใช่ลุคภาพยนตร์ Universal ปี 1931 (ในสหรัฐฯ น่าจะพ้นลิขสิทธิ์ 1 ม.ค. 2570 ต้องยืนยัน)
2. ห้ามใช้ไม้กางเขนเป็นอาวุธหรือของใช้ในเกม ยืนยันว่าเข้าแนวเดียวกับ CONCEPT §9
3. วาลคิรี: บทบาทตามตำนานนอร์สถูกต้องหรือไม่ ศาสนานอร์สยุคใหม่ (อาซาทรู) ยังมีผู้นับถือ การเป็นผู้ทดสอบที่ให้เกียรติเพียงพอหรือไม่ และรายการสัญลักษณ์นอร์สที่ต้องหลีกเลี่ยงเพราะถูกกลุ่มสุดโต่งใช้ สำหรับ Mind
4. ยืนยันการเลี่ยงวิญญาณพื้นเมืองอเมริกัน (เช่น เวนดิโก) · คาวบอยตะวันตกเก่าในข้อ 1 เป็นตัวสมมติ ไม่ใช่ชนพื้นเมือง
5. ตัวเลือกสำรองโคสเชย์: ยืนยันรายละเอียดตำนาน (เข็ม-ไข่-เป็ด-กระต่าย-หีบ) และความเหมาะสม

### 5.4 นรกเครือข่าย
1. ม้าโทรจัน: ยืนยันว่าตำนานม้าไม้ทรอยใช้ได้ไม่มีเจ้าของ และมุก "ของขวัญที่เปิดประตูให้ข้าศึกเอง" ตรงตำนาน
2. ผู้ตรวจสอบคลาวด์: ไม่ซ้ำตัวละครเอไอที่มีลิขสิทธิ์ และไม่ชนรูปทูตสวรรค์คริสต์มากเกินไป
3. ตัวตนปลอม 3 แบบ อยู่ในกรอบ N11 และไม่ล้อเลียนกลุ่มชาติพันธุ์ใด
4. **ข้อสังเกตนอกใบสั่ง:** ภาพ `img/CyberHell/Boss Zone4-cyberhell.png` ผิวหน้าเป็นสีเกือบดำ สวมมงกุฎแนวอียิปต์ ตาเรืองแสง ขอให้ Reese ดูว่าเสี่ยงถูกอ่านเป็นภาพเหมารวมหรือไม่
5. ความรุนแรง/เรตติ้งร้านค้า: ทุก event เป็นการต่อสู้กับปีศาจ/วิญญาณ ไม่มีภาพทรมาน ตรวจว่าสอดคล้องกับ M1.5
