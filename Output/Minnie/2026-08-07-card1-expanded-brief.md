## 1. แก่นของบทความ (thesis)

> ราคางานพิมพ์ไม่ได้คิดเป็น "ต่อใบ" — มันคิดเป็น "ต่องาน" แล้วค่อยหารด้วยจำนวน
> เพราะฉะนั้นคำถาม "ใบละเท่าไร" ตอบไม่ได้ถ้ายังไม่บอกว่าเอากี่ใบ

ทั้งบทความมีหน้าที่เดียว: ทำให้ลูกค้าเข้าใจว่า **งานพิมพ์ส่วนใหญ่จ่ายไปกับการ "เริ่มพิมพ์" ไม่ใช่การ "พิมพ์"** เมื่อเข้าใจข้อนี้ คำถามที่ตามมาทั้งหมด (ทำไมพิมพ์น้อยไม่คุ้ม / ทำไมสั่งเพิ่มถูกลง / ควรสั่งทีเดียวหรือแบ่งล็อต) จะตอบตัวเองได้

**สิ่งที่บทความนี้ไม่ทำ:** ไม่เปิดราคาต่อหน่วยของ TANAPAT เป็นเรตการ์ด (ดูหัวข้อ 7 — ความเสี่ยง)

## 2. มุมที่คู่แข่งเขียนไม่ได้

บทความไทยที่มีอยู่ตอนนี้จบแค่ประโยคเดียวว่า "ยิ่งพิมพ์เยอะยิ่งถูก" ซึ่งลูกค้ารู้อยู่แล้วและไม่ช่วยตัดสินใจอะไรเลย

สิ่งที่เราเติมได้เพราะมีแท่นพิมพ์อยู่ในมือ:
1. **ตัวเลขจริงจากใบเสนอราคาจริง** ทั้งชุด ไม่ใช่ตัวอย่างสมมุติ
2. **แจกแจงว่าเงินหายไปไหน** — เพลทกี่บาท ตั้งเครื่องกี่บาท กระดาษกี่บาท ลูกค้าไม่เคยเห็นการแยกส่วนนี้จากที่ไหน
3. **เวลาตั้งเครื่องจริง** — ตัวเลขนาที ที่ทำให้ลูกค้าเข้าใจว่าทำไม 100 ใบถึงไม่ถูกกว่า 500 เท่าไร
4. **PrintCost** — คู่แข่งเขียนบทความจบแล้วให้โทรถาม เราจบแล้วให้กดคำนวณเองได้เลย

## 3. โครงเรื่อง (ประมาณ 1,200–1,400 คำ)

### เปิด — บทสนทนาจริง (~150 คำ)
เปิดด้วยเคสที่เกิดทุกสัปดาห์ ไม่ใช่การอธิบายทฤษฎี:

> ลูกค้าโทรมาถามราคาใบปลิว 500 ใบ ได้ราคาไป
> วันรุ่งขึ้นโทรกลับมาบอกว่าขอเพิ่มเป็น 1,000 คิดในใจว่าคงราคาเท่าตัว
> พอได้ใบเสนอราคาใหม่กลับงงกว่าเดิม — จำนวนเพิ่มเท่าตัว แต่ราคาเพิ่มไม่ถึงครึ่ง

ปิดย่อหน้าเปิดด้วยประโยคที่ตั้งคำถามค้างไว้: *"ไม่ใช่ว่าเราลดราคาให้ และไม่ใช่ว่าครั้งแรกคิดแพงเกิน — แต่เป็นเพราะโครงสร้างต้นทุนงานพิมพ์มันเป็นแบบนี้มาตั้งแต่ยุคเรียงตัวตะกั่ว"**

### ตอนที่ 1 — เงินก้อนแรกจ่ายไปก่อนที่เครื่องจะพิมพ์ใบแรก (~350 คำ)
หัวใจของบทความ อธิบาย **ต้นทุนคงที่** ทีละตัว โดยเล่าเป็นลำดับเวลาของงานจริง ไม่ใช่ bullet ลอย ๆ:

- **ทำเพลท** — ไฟล์ต้องแปลงเป็นแม่พิมพ์ กี่สีก็กี่แผ่น งาน 4 สี 2 หน้า = 8 แผ่น · พิมพ์ 100 ใบกับ 10,000 ใบ ใช้เพลทชุดเดียวกัน จ่ายเท่ากัน
- **ตั้งเครื่อง (makeready)** — เวลาช่างปรับตำแหน่ง ปรับความหนาหมึก ไล่สีจนตรงตัวอย่าง ระหว่างนี้เครื่องเดินอยู่และกินกระดาษไปเรื่อย ๆ
- **กระดาษที่เสียตอนไล่สี** — แผ่นที่พิมพ์ทิ้งก่อนสีจะนิ่ง เป็นจำนวนแผ่นที่ค่อนข้างคงที่ ไม่ว่างานจะใหญ่หรือเล็ก
- **ไดคัท/ตกแต่ง** — ถ้ามี ก็มีบล็อกมีดที่ต้องทำใหม่ต่องาน และมีเวลาตั้งเครื่องของมันเองอีกชุด

ปิดตอนนี้ด้วยประโยคสรุปที่ต้องจำได้: **"ทั้งหมดนี้จ่ายครั้งเดียว ไม่ว่าคุณจะเอา 100 ใบหรือ 10,000 ใบ"**

### ตอนที่ 2 — เงินก้อนที่สองถึงจะขึ้นกับจำนวน (~200 คำ)
**ต้นทุนแปรผัน** — กระดาษ หมึก และค่าเดินเครื่องตามยอดพิมพ์ ส่วนนี้ตรงไปตรงมา พิมพ์เพิ่มเท่าตัวก็จ่ายเพิ่มเท่าตัว

จุดที่ต้องเน้น: **กระดาษคิดเป็นแผ่นใหญ่ ไม่ใช่เป็นใบ** — ถ้าใบปลิวหนึ่งแผ่นใหญ่ตัดได้ 8 ใบ สั่ง 500 กับ 512 ใบใช้กระดาษเท่ากัน (เชื่อมไปบทความ "ตกกระดาษ" ที่ทำค้างไว้ ใส่ลิงก์ตรงนี้เมื่อบทความนั้นปิดได้)

### ตอนที่ 3 — เอาสองก้อนมาบวกกัน แล้วดูตัวเลขจริง (~300 คำ)
**หัวใจที่คนจะแคปไปแชร์** — ตารางเดียวจบ ดูโครงในหัวข้อ 5

หลังตารางต้องมีสองย่อหน้า:
1. อ่านตารางให้ฟัง — ชี้ว่าราคาต่อใบร่วงเร็วที่สุดในช่วงต้น แล้วค่อย ๆ แบนลง
2. **บอกให้ชัดว่าเส้นมันแบนเมื่อไร** — เลยจุดหนึ่งไปแล้วสั่งเพิ่มก็แทบไม่ประหยัดต่อใบอีก เพราะเหลือแต่ค่ากระดาษล้วน ๆ ตรงนี้คือคำแนะนำที่ลูกค้าเอาไปใช้ได้จริง และเป็นจุดที่พิสูจน์ว่าเราไม่ได้เขียนเพื่อเชียร์ให้สั่งเยอะ ๆ

### ตอนที่ 4 — แล้วดิจิทัลล่ะ (~250 คำ)
เพราะคำถาม "ทำไมพิมพ์น้อยแพง" คำตอบจริงครึ่งหนึ่งคือ *"งานน้อยอาจไม่ควรพิมพ์ออฟเซ็ตตั้งแต่แรก"*

- ดิจิทัลไม่มีเพลท ตั้งเครื่องแทบไม่มี → ต้นทุนคงที่เกือบเป็นศูนย์ แต่ต้นทุนต่อใบสูงกว่าและคงที่ตลอด
- ออฟเซ็ตคงที่สูง แต่ต่อใบถูกกว่ามาก
- **สองเส้นนี้ตัดกันที่จุดหนึ่ง** — ต่ำกว่าจุดนั้นดิจิทัลถูกกว่า สูงกว่านั้นออฟเซ็ตถูกกว่า
- ระบุช่วงจำนวนที่จุดตัดอยู่ **พร้อมบอกตรง ๆ ว่ามันขยับตามขนาดงาน จำนวนสี และกระดาษ** ไม่ใช่เลขศักดิ์สิทธิ์ตัวเดียวใช้ได้ทุกงาน
- ข้อจำกัดที่ต้องพูดให้ครบ ไม่ใช่แค่เรื่องราคา: ดิจิทัลจำกัดขนาดแผ่น เนื้อกระดาษบางชนิดไม่รับ และสีเทียบกันไม่ได้ 100% กับออฟเซ็ต

### ตอนที่ 5 — 4 คำถามที่ควรถามตัวเองก่อนเคาะจำนวน (~250 คำ)
เปลี่ยนความรู้เป็นการตัดสินใจ:
1. **ของนี้มีวันหมดอายุไหม** — โบรชัวร์ที่มีราคาหรือเบอร์โทรอยู่ พิมพ์เผื่อเยอะแล้วข้อมูลเปลี่ยน = ทิ้งทั้งกล่อง ถูกต่อใบแต่แพงต่อใบที่ได้ใช้จริง
2. **ปีนี้ใช้จริงเท่าไร** — ประเมินจากของเดิม ไม่ใช่จากความหวัง
3. **มีที่เก็บไหม** — กล่อง 5,000 ใบกินพื้นที่จริง และกระดาษเก็บนานเจอความชื้นได้
4. **จะสั่งซ้ำอีกไหม** — ถ้าใช่ ถามโรงพิมพ์ว่าเก็บเพลท/ไฟล์ให้ได้นานแค่ไหน สั่งซ้ำงานเดิมไม่ต้องจ่ายบางส่วนของก้อนแรกใหม่ *(← ต้องยืนยันกับเป้ว่า TANAPAT ทำจริงไหม ถ้าไม่ ตัดข้อนี้ทิ้ง)*

### ปิด + CTA (~100 คำ)
สรุปกลับไปที่แก่น: ราคาต่อใบไม่มีความหมายถ้าไม่มีจำนวนกำกับ

CTA แบบไม่ hard-sell ตาม SOP-02 — ชวนกดลองคำนวณใน PrintCost เองก่อน แล้วค่อยคุยกับเราถ้าอยากได้ตัวเลขของงานจริง

## 4. ช่องที่ต้องเติม — คำถามถึงเป้ ⛔ blocker

ทุกช่องนี้ถ้าเดา บทความจะไปตายที่ fact-check เหมือนบทความตกกระดาษ **ตอบเป็นช่วงได้ ไม่ต้องเป๊ะ** แต่ต้องมาจากของจริง

**ชุด A — งานตัวอย่างที่จะใช้ทั้งบทความ** (เลือกงานเดียวแล้วใช้ยาวตลอด)
1. ใช้ใบปลิว A5 4 สี 2 หน้า อาร์ตมัน 130 แกรม เป็นงานตัวอย่างได้ไหม หรือมีงานอื่นที่เป็นตัวแทนลูกค้า TANAPAT มากกว่า

**ชุด B — ต้นทุนคงที่ของงานตัวอย่างนั้น**
2. ค่าเพลท แผ่นละเท่าไร งานตัวอย่างใช้กี่แผ่น
3. ค่าตั้งเครื่อง คิดยังไง (เหมาต่องาน / คิดตามเวลา) ประมาณเท่าไร
4. ตั้งเครื่องงานแบบนี้ใช้เวลาประมาณกี่นาที
5. ไล่สีจนนิ่ง กินกระดาษประมาณกี่แผ่นใหญ่
6. มีค่าอื่นที่จ่ายครั้งเดียวต่องานอีกไหมที่ผมไม่ได้ถาม

**ชุด C — ต้นทุนแปรผัน**
7. กระดาษที่ใช้ ราคาต่อรีม/ต่อกิโล เท่าไร แผ่นใหญ่หนึ่งแผ่นตัดงานตัวอย่างได้กี่ใบ
8. ค่าหมึก + ค่าเดินเครื่องต่อ 1,000 แผ่น ประมาณเท่าไร

**ชุด D — ดิจิทัล**
9. TANAPAT รับงานดิจิทัลเองไหม หรือส่งต่อ
10. งานตัวอย่างเดียวกันพิมพ์ดิจิทัล ต่อใบประมาณเท่าไร
11. จากประสบการณ์ จำนวนประมาณเท่าไรที่เริ่มแนะนำให้ลูกค้าเปลี่ยนมาออฟเซ็ต

**ชุด E — นโยบาย**
12. เก็บเพลท/ไฟล์ให้ลูกค้านานแค่ไหน สั่งซ้ำงานเดิมได้ส่วนลดจริงไหม
13. มีจำนวนขั้นต่ำต่องานไหม
14. **โอเคไหมที่จะเปิดตัวเลขแจกแจงระดับนี้ต่อสาธารณะ** — ถ้าไม่ ผมมีทางเลือกอยู่ในหัวข้อ 7

## 5. โครงตารางหลัก (ตัวเลขรอเติมจากชุด B–C)

ตารางนี้คือของที่คนจะแคปไปแชร์ ต้องอ่านจบใน 5 วินาที

| จำนวน | ต้นทุนคงที่ | ต้นทุนแปรผัน | รวม | **ต่อใบ** |
|---|---|---|---|---|
| 100 | _(เท่ากันทุกแถว)_ | | | |
| 500 | | | | |
| 1,000 | | | | |
| 3,000 | | | | |
| 5,000 | | | | |

**กติกาของตาราง:**
- คอลัมน์ "ต้นทุนคงที่" ต้องเป็นตัวเลขเดียวกันทุกแถว — นั่นคือทั้งเรื่องของบทความ มองปราดเดียวก็เข้าใจ
- แถว 100 ใบมีไว้ให้เห็นความสุดโต่ง ไม่ใช่เพื่อขาย
- ถ้าเป้ไม่อยากเปิดตัวเลขบาท ใช้เป็น **สัดส่วน** แทน (ตั้งราคาต่อใบที่ 1,000 = 100 แล้วเทียบแถวอื่น) เสียพลังไปบ้างแต่ยังใช้ได้

**กราฟประกอบ 1 รูป:** เส้นราคาต่อใบร่วงชันแล้วแบน — ดิ่งช่วงต้นแล้วเกือบเป็นเส้นตรงช่วงท้าย ถ้าได้ตัวเลขดิจิทัลด้วย พล็อตสองเส้นซ้อนกันให้เห็นจุดตัด จะเป็นภาพที่แทนบทความทั้งบทได้

## 6. ตัวเลือกชื่อเรื่อง

| # | ชื่อ | ให้อะไร |
|---|---|---|
| 1 | ทำไมพิมพ์ 500 ใบ กับ 1,000 ใบ ราคาต่อใบต่างกันเกือบครึ่ง | ตรงกับที่คนเสิร์ฟจริง เป็นคำถามที่ลูกค้าถามด้วยคำของเขาเอง ✅ แนะนำ |
| 2 | ราคางานพิมพ์คิดยังไง — เปิดใบเสนอราคาจริงให้ดูทีละบรรทัด | ได้ความโปร่งใส แต่จั่วหัวว่าจะเปิดหมด ต้องเปิดจริง |
| 3 | ควรพิมพ์กี่ใบถึงคุ้ม | คำค้นกว้างกว่า แต่เป็นคำถามที่ตอบแทนลูกค้าไม่ได้ อาจทำให้คนคาดหวังผิด |

**หมายเหตุ:** ตัวเลข "เกือบครึ่ง" ในชื่อเรื่องต้องตรงกับตารางจริง ถ้าคำนวณออกมาแล้วเป็น 40% หรือ 60% ต้องแก้ชื่อตาม ห้ามให้ชื่อเรื่องนำตัวเลข

## 7. ความเสี่ยง + ทางกัน

**เสี่ยง 1 — กลายเป็นเรตการ์ดให้ลูกค้าเอามาต่อรอง**
เขียนให้ชัดตั้งแต่ในตารางว่าเป็น **งานตัวอย่างชิ้นเดียวเพื่ออธิบายหลักการ** ไม่ใช่ราคาที่ใช้ได้ทุกงาน ปิดท้ายตารางด้วยบรรทัดว่างานจริงเปลี่ยนตามกระดาษ จำนวนสี ขนาด และงานหลังพิมพ์
ถ้าเป้ยังไม่สบายใจ → ใช้แบบสัดส่วนในหัวข้อ 5 หลักการยังอธิบายได้ครบ

**เสี่ยง 2 — คู่แข่งเอาตัวเลขไปตัดราคา**
บทความนี้เปิด *โครงสร้าง* ไม่ใช่ *มาร์จิ้น* คู่แข่งรู้ต้นทุนพวกนี้อยู่แล้ว คนที่ไม่รู้คือลูกค้า — ความเสี่ยงจริงต่ำกว่าที่รู้สึก

**เสี่ยง 3 — ตัวเลขล้าสมัย**
ราคากระดาษขยับ ใส่บรรทัด "ตัวเลขอ้างอิง ณ [เดือน ปี]" ไว้ใต้ตาราง แก้ปีละครั้งพอ

**เสี่ยง 4 — บทความเชียร์ให้สั่งเยอะเกินจำเป็น**
กันด้วยตอนที่ 3 (บอกว่าเลยจุดไหนแล้วไม่ประหยัดอีก) และตอนที่ 5 (คำถามเรื่องของหมดอายุ) — สองส่วนนี้ห้ามตัดออก เพราะเป็นสิ่งที่ทำให้บทความน่าเชื่อถือ
