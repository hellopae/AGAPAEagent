## สิ่งที่ build

**1. สองแบบต่างกันตรงไหน** (ดู `1-style-difference-*.jpg` ซูม 2× + ภาพ diff ขยาย ×4)
- shader เดิม = เมฆของภาพพื้น v7r เอง (วาดติดพื้น) ที่ shader ไหลไปตาม flow map: ก้อนกลมนูน สีครีม-ส้มพีชรับแสงทอง เงาเป็นม่วงเทา ขอบก้อนคมแบบก้อนสำลี ไม่มีช่องฟ้ามืดลึก
- Codex = วาดแยกชั้น A/B: โทนขาว-ม่วงอ่อนเย็นกว่า เป็นหมอกม้วนลื่นมีมิติ (volumetric) มีช่องฟ้าน้ำเงินเข้มลึกระหว่างก้อน ขอบฟุ้งนุ่ม · เคลื่อนไหวโดย cross-fade A↔B ทุก 24 วินาที + ลอย ±1.5 หน่วย
- Codex ครอบคลุมแค่ 0.5% ของแผนที่ (แถบบน y 140–800: ทะเลเมฆกลางบน, หุบตะวันตกของประตูสวรรค์, ฝั่งตะวันออกของประตู, หมอกริมซ้าย) ที่เหลือเป็น shader เดิม · ที่ต่างชัดสุดคือ "สีและมิติ" ไม่ใช่รูปทรงโดยรวม (เลยดูต่างยากตอนภาพนิ่งแล้วซ้อนเงา)

**2. วิธีผสม (ค่าเริ่มต้นแล้ว)** — ไม่ใช่วางทับสองชั้นเหมือน flag เดิม
- ชิ้นเมฆของ shader (`fluid-shader.js`) ใช้ "พื้น + เมฆ Codex A" กับ "พื้น + เมฆ Codex B" เป็นภาพสีฐาน (2 texture, น้ำหนัก A/B ตามสูตร Codex เป็น uniform) แล้ว shader ไหลภาพนี้ไปตาม flow เดิม → Codex เป็นภาพ shader เป็นการเคลื่อนไหว
- ที่ Codex มีเมฆแต่ shader ไม่มีชิ้น (หมอกสันตะวันตก/ริมซ้าย ~30% ของเมฆ Codex) วาด A/B mix ตรง ๆ **ใต้** shader (shader ทึบในมาสก์ของตัวเอง จึงไม่ซ้อนกัน) พร้อมลอยแบบ sine เดิม
- puff 8 ก้อนของ Codex ลอยช้าไป-กลับ (ไม่เร็วกว่าที่ Codex กำหนด .8–1.3 หน่วย/วินาที, คาบ 160 วินาที) อยู่บนสุด ตัดด้วย mask ของ Codex
- ที่ Codex ไม่ได้วาด = shader เดิมทุกอย่าง · ความเข้ม: ไม่ลด (เมฆดูขาวชัดขึ้นเล็กน้อยในทะเลเมฆ ไม่บังทางเดิน เมฆอยู่เหนือหน้าผา/ท้องฟ้า) · ไม่ย้อมสี/ไม่ใส่ filter กับภาพ Codex (test ตรวจ)
- โหมด: ค่าเริ่มต้น = mix · `?clouds=shader` = แบบเดิมก่อนผสม · `?clouds=codex` = Codex วางทับแบบเทียบเมื่อเช้า · ใช้เฉพาะโซน 1 บนพื้น v7r
