## สิ่งที่ build
ทุกอย่างที่ขยับเล่นจาก **sprite ที่วาด** (FX-ART-Z1 ของ Codex) ไม่มีการเลื่อนภาพนิ่ง · โค้ดแค่ขยับ/ตัด/ผสมเลเยอร์ ไม่แต่งสีภาพ (ยกเว้นข้อสังเกตลาวาด้านล่าง)
1. **ลาวา/น้ำ/หมอก ตรงตำแหน่ง (ข้อ 2 ของคุณเป้)** — ไม่ใช้ `suggestedPlacement` ตรง ๆ: `scripts/build-zone1-fx.py` หาพื้นที่จากข้อมูลจริง
   ลาวา = สีลาวาใน `ok.jpg` + ชั้นลาวาฐาน ∩ ช่อง alpha ของ terrain (**ใต้ซุ้มซ้ายเป็นลาวา** ไม่ใช่น้ำม่วง) · แม่น้ำ = ชั้นน้ำ ∩ ช่อง alpha − ลาวา · ธารน้ำแข็ง = ชั้น waterfall ∩ ช่อง alpha
   หลักฐาน `docs/art-reviews/2026-11-05-zone1-fx/liquid-regions.png` (ลาวาแดง/น้ำน้ำเงิน/น้ำแข็งฟ้าทับ ok.jpg) และ `mist-zones-and-points.png`
   **หมอก/ไอ** วางเฉพาะ "ของเหลว+ขอบตลิ่ง − พื้นเดิน" → ไม่ทับลาน/บันได/สะพาน/อาคาร (หมอกอยู่ใต้คิววัตถุ ต้นไม้/ตึกบังหมอกเสมอ) · ไอร้อนเหนือลาวา, หมอกเย็นฝั่งน้ำแข็ง · เทสต์พิสูจน์: 0 cell ของลาวา/น้ำ/โซนหมอกซ้อนพื้นเดิน
2. **แม่น้ำ** คงแบบ spirit-river เดิม (tile แกน x แถวสะท้อนแนวตั้ง) + ฟองตลิ่ง + ประกายผิวน้ำ · **ลาวา** ผิวไหล + ฟองพองแตก + ลาวาตกใต้ซุ้มซ้าย + ประกายไฟ/ขี้เถ้า
3. **เมฆลอยลื่น (ข้อ 3)** — เมฆ 3 ก้อนของคุณเป้เลื่อนต่อเนื่องความเร็วคงที่ 15/9/12 หน่วยโลก/วินาที (ก้อนเล็ก/ไกลช้ากว่า) sub-pixel ไม่ snap วนกลับด้านซ้ายเมื่อพ้นขอบ · parallax ฟ้า .90 < เมฆ .78 < ภูเขา .97 < พื้น 1 · เมฆ Codex เล็กใช้ 3 ก้อนเป็นเมฆบางเสริม (morph ช้ามาก ผสมสองเฟรมที่วาดตอน runtime)
4. **เงาเมฆบนพื้น (ข้อ 4)** — เงาจากเงาเมฆจริงของคุณเป้ (ซิลูเอตเบลอ) ใช้ฟังก์ชัน `cloudX()` ตัวเดียวกับเมฆบนฟ้า → ทิศ/ความเร็วเท่ากัน · ทับพื้น ภูเขา วัตถุ ตัวละคร · **ไม่ทับฟ้า** (ตัดด้วยมาสก์ "ไม่ใช่ฟ้า") · เงาเก่าของระบบอากาศ (`drawMapWeather`) ปิดเฉพาะโซน 1 ใหม่ (`clouds:false`) กันซ้อน + ปิดควันจากตำแหน่งคบเพลิงเก่าที่ลอยทับอาคาร
5. **DOF tilt-shift** — เบลอแถบบน(ไกล)/ล่าง(ใกล้) ตามแถบโฟกัสที่ตัวละคร (บัฟเฟอร์ความละเอียดต่ำ สร้างใหม่ทุก 2 เฟรม ไม่ blur เต็มจอ) + วัตถุที่ฐานอยู่ต่ำกว่าตัวละครมาก (ต้นไม้/ประตูหน้าสุด) เบลอแรงด้วยสำเนา sprite ที่ cache ไว้
6. **ใบไม้หล่น** จากต้นไม้ตามชนิด (เมเปิลแดง/ทอง/สน-ปาล์มเขียว/หิมะฝั่งน้ำแข็ง) จำนวนจำกัดตามคุณภาพ · **คบเพลิง** 3 เสาไฟ + กระทะ + แสงอุ่นกระพริบบนพื้น (ปิดได้) · **ลำแสง 3 + ฝุ่น** · **bloom** (สูงเท่านั้น) · **color grade** ลาวาอุ่นแดง/น้ำแข็งเย็นฟ้า · vignette ใช้ของเดิมใน scene
7. **ตั้งค่า** ในหน้าตั้งค่า: คุณภาพ ต่ำ/กลาง/สูง (มือถือ/จอแคบเริ่ม "กลาง" เดสก์ท็อป "สูง") + สวิตช์แสงไฟกระพริบ (เก็บใน localStorage) · **pause/แท็บซ่อน/reduce-motion หยุดนาฬิกา fx ทั้งหมด** (ทดสอบ pause ในเบราว์เซอร์: ภาพแคนวาสไม่ขยับเลย ต่างแค่กระดิ่ง DOM)
- ไม่มีอะไรเปลี่ยนที่โซน 2–4 · minimap ไม่วาด fx · ภาพรวมทั้งแผนที่ (scale < 0.38) ใช้ preview ตามเดิม (ไม่มี fx)

## จุดที่ไม่แน่ใจ
1. **ลาวาสว่างน้อยกว่า ok.jpg** (sheet เข้มกว่า) → ผมซ้อนเฟรมเดียวกันแบบ `screen` อีกชั้น (alpha .65) ให้สว่างขึ้น เป็นการผสมไม่ใช่แก้ภาพ แต่ถ้าไม่เอา ต้องวาดชิ้นใหม่ (ดูสเปกด้านล่าง)
2. ขอบล่างลาวาใต้ซุ้มชนน้ำเป็นเส้นตรงแข็ง (มาจากชั้นลาวาฐาน) — ไม่ได้ทำขอบเรือง
3. ลำแสง/ฝุ่นวางตามตำแหน่งที่ Codex แนะนำ (ฟ้า/อากาศ ไม่มีข้อมูลจริง) · ไฟ 4 จุดวางที่หัวเสาไฟ/ขอบกระทะ ยังไม่ได้ใส่ไฟศาลาแดง
4. DOF บัฟเฟอร์เบลอสร้างใหม่ทุก 2 เฟรม → ตอนเลื่อนเร็วเบลอตามหลัง 1 เฟรม (มองไม่ออกในคลิป) · ตอนซูมออกสุดเบลอล่างกินพื้นที่มาก (คล้ายภาพจิ๋ว) — ปรับ band ได้
5. ถ้าตัวละครไม่อยู่บนจอ (กล้องซูมออก) แถบโฟกัสถูกหนีบไว้ที่ 20–80% ของจอ
6. ข้อความตั้งค่า (คุณภาพ ต่ำ/กลาง/สูง, แสงไฟกระพริบ) ผมเขียนเอง ชั่วคราว → รอ Rae · dropdown ยังไม่จัดสไตล์ รอ Vera/Mind
7. เมฆ Codex ขนาดเล็ก (296 px) ใช้เป็นก้อนบางเสริมเท่านั้น (ตามใบงาน)
