### C — หน้าต่างสอบสวนหดแคบ (desktop)
ไล่หาต้นเหตุจริงด้วย Playwright ทั้ง Chromium และ WebKit ที่ความกว้างจอ 700–1920px ทุกปุ่ม/ทุกรอบ
สอบสวน (รวมถึงรอบออกหมายเต็มรูปแบบ) — **ไม่พบจุดที่ CSS width ของ `dialog.hudwrap` เปลี่ยนแปลงเลย
ในโค้ดปัจจุบัน** ไม่มี class ที่สลับตอนกดปุ่ม ไม่มี media query ชนกัน ใส่ `min-width` ชนกับ
`max-width` ไว้เป็นเกราะกันสุดท้าย — พิสูจน์ผ่าน Playwright แล้วว่ากล่องคงที่ 1180px บน desktop
และคงสัดส่วนถูกต้องบน 360/390px ไม่กระทบเลย์เอาต์มือถือ
**หมายเหตุสำคัญ:** ไม่สามารถ reproduce บั๊กเดิมได้จริงแม้ทดสอบละเอียดมาก — ถ้าเกิดซ้ำอีกต้องขอ
สเต็ปจริง (เบราว์เซอร์/OS/ขนาดหน้าต่างตอนนั้น) จากคุณเป้เพื่อหาต้นเหตุที่แท้จริงต่อ
