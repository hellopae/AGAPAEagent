## สิ่งที่แก้และเหตุผล

`press()` เดิมไม่มี deed ID ผูกกับคำให้การ: deny เปิดกรรมที่ยังไม่ known ข้อแรก; plea เปิดทุกกรรมที่ยังไม่ known; boast เปิดโปงบุญปลอม จึงเพิ่ม `pressDeeds()` ให้ตวาดและการสอบสวนใช้ mapping เดียวกัน โดยคงผลของการสอบสวนเดิม

ตวาดเลือกข้อที่ยังไม่ใช้และเปิดกรรมซึ่ง `s` ตรง `primarySinOf(soul)` เท่านั้น ไม่เลือก boast หรือ deny ที่เปิดบาปรอง ถ้าความจริงของบาปหลักเปิดหมดแล้ว ไม่มีข้อที่เปิดบาปหลักได้ ข้อนั้นใช้แล้ว ดวงบริสุทธิ์ หรือจำนวนสอบสวนหมด จะบอกเหตุผลโดยไม่ใช้พลัง ไม่เปลี่ยนกรรม/คูลดาวน์ ตัวเลขคูลดาวน์ยัง 120000 ms และกรรมยัง 0.5

กระจกเพิ่ม 💢 ที่ข้อเดียวกันพร้อมบันทึก หรือบอกว่าไม่มีข้อให้ชี้ และคำนวณยมทูตแม้สถานีเฉลยยังไม่ได้สร้าง โดยใช้สถานีสมมุติเพื่อคำนวณคะแนนเท่านั้น ไม่สร้างสถานีจริง ไม่มอบหมายคดี ถ้าส่งไม่ได้ยังบอกเหตุผล

สะกดจิตเดิมมี station ใน `trialAnswer()` และทำเครื่องหมายสถานีที่มีอยู่แล้วบนวงถูกต้อง แต่ไม่แสดงชื่อถ้ายังไม่มีสถานีเฉลย จึงเพิ่มชื่อสถานีเฉลยในวง “ที่ไหน” ทั้งสะกดจิตและกระจก สะกดจิตยังไม่เฉลย intensity/crew

เซฟเก่าที่มี numeric `soul.roarHint` โหลดได้ การวาด 💢 คำนวณข้อที่ถูกต้องใหม่หากมี hint เดิม เพื่อไม่แสดงข้อผิดจากกลไกเก่า

Popup คำแนะนำย้ายขึ้นเหนือวงฝั่งเวที จำกัดความกว้างไม่เกินวงและความสูง 26vh พร้อมเลื่อนอ่านข้อความได้ แผงขวาไม่ถูก popup ขยายไปทับ กฎนี้ใช้เฉพาะ desktop >700px

## Popup: การคำนวณและวิธีวัดจริง

ขอบเขตคำนวณจาก body padding 2.3%, แบ่ง stage/right 58:42, wheel left 31%/bottom 24%, ความกว้าง clamp(205px,21vw,270px), aspect ratio 9/11 และ popup bottom 100%+12px/max-height 26vh ตัวเลขประมาณ ไม่รวม border ระดับ 1–2px

| viewport | popup ขอบซ้าย–ขวาสูงสุด | popup ขอบบน–ล่างเมื่อใช้ความสูงสูงสุด | ขอบซ้ายแผงขวา |
|---|---|---|---|
| 1280×800 | 249.00–517.80 | 63.55–271.55 | 737.69 |
| 1440×900 | 280.12–550.12 | 112.08–346.08 | 829.90 |

ค่าตรวจซ้ำได้ใน `29h/popup-geometry.json`; ขอบ popup อยู่ใน viewport และเหลือระยะถึงแผงขวา >200px ตามแบบจำลอง CSS

วิธีตรวจด้วยเบราว์เซอร์เมื่อเปิดได้: serve worktree ด้วย `python3 -m http.server`, ตั้ง viewport ตามสองขนาดที่ระบุ เริ่มเกม เข้าโซนใหม่ที่ยังมีเพียง sala/tarang เปิดห้องสอบสวนและวง “ที่ไหน” แล้วรันใน DevTools:

```js
const rect = selector => document.querySelector(selector).getBoundingClientRect();
const popup = rect('.trial-hud .options-1');
const panel = rect('.trial-hud .hud-right');
console.table({ popup: popup.toJSON(), panel: panel.toJSON() });
console.assert(popup.right <= panel.left);
console.assert(popup.left >= 0 && popup.top >= 0);
console.assert(popup.right <= innerWidth && popup.bottom <= innerHeight);
const hint = document.querySelector('.trial-hud .trial-empty-hint');
console.table({ textHeight: hint.scrollHeight, textWidth: hint.scrollWidth,
  popupHeight: popup.height, popupWidth: popup.width });
```
