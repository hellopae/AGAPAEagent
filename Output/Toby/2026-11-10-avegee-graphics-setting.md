## สิ่งที่ build

### 1) ตั้งค่ากราฟิก — ความละเอียดสูง / เน้นประสิทธิภาพ
หน้าตั้งค่า (เฟือง) มีหัวข้อ "กราฟิก" ปุ่ม 2 ปุ่ม + คำอธิบาย 1 บรรทัดใต้ตัวเลือก (ไทย/อังกฤษ) · ค่าเริ่มต้น = ความละเอียดสูง · มีผลเฟรมถัดไปทันที (วัดจริง: canvas แผนที่ 2880 → 2160 → 2880 px ที่หน้าต่าง 1440 กดสลับ) · จำค่าใน localStorage `avegee.graphics` (รีโหลดแล้วยังอยู่ ทดสอบด้วย storage จริง) · `?mapdpr=` ยังชนะการตั้งค่า

| | ความละเอียดสูง (ค่าเดิมทุกอย่าง) | เน้นประสิทธิภาพ |
|---|---|---|
| ความหนาแน่น canvas แผนที่ (DPR สูงสุด) | 2 | 1.5 |
| crossfade ของเหลว (ลาวา/แม่น้ำ/ทะเลเมฆ) | คำนวณใหม่ทุกเฟรม | คำนวณใหม่อย่างมากทุก 33 ms (~30 ครั้ง/วิ) เฟรมระหว่างนั้นวาดภาพชั้นเดิมซ้ำตามตำแหน่งกล้องใหม่ · ซูมเปลี่ยน = คำนวณใหม่ทันที |
| ลูปวาดแผนที่หลัก | ทุกเฟรมของจอ | ไม่เกิน 60 ครั้ง/วิ แม้จอ 120 Hz (ข้ามเฟรมโดยไม่เลื่อนเวลา เดินยังเป็นเวลาจริง) |

ค่าทั้งหมดอยู่ที่เดียว: `src/graphics-setting.js` (`GRAPHICS_PROFILES`) — ถอดออกง่าย: ลบไฟล์นี้ + import 3 จุด (scene.js, town-fluid-fx.js, ui.js — ค้นคำว่า `GFX-1110`) + บล็อกตั้งค่าใน ui.js + i18n `settings.graphics*` + CSS `.settings-gfx*` ใน index.html
สไตล์ปุ่มใช้ทอง/มืดของหน้าตั้งค่าเดิม ไม่ออกแบบใหม่ ปุ่มสูง 44 px กว้างพอที่ 390 px

### fps / p95 (หน้าต่าง 1792×958 @2x, GPU Intel UHD 630 ผ่าน harness `perf-1110/`, วัดตอนเครื่องว่าง load < 2.5 ทุกรอบ — PikPak ยังกิน CPU อยู่บ้าง)
| ฉาก | ความละเอียดสูง (2 รอบ) | เน้นประสิทธิภาพ (4 รอบ) |
|---|---|---|
| เมือง ยืนนิ่ง | 60 fps · p95 16.8 ms | 60 fps · p95 16.7-16.8 ms |
| **เมือง เดิน 10 วิ** | **52.6 / 52.2 fps · p95 33.4 / 33.3 ms** | **53.2* / 58.5 / 58.6 / 58.7 fps · p95 16.8 ms (มัธยฐาน 58.6)** |
| ต่อสู้ ยืนนิ่ง | 60 · p95 16.8 | 60 · p95 16.7-16.8 |
| ต่อสู้ ตีกัน 8 วิ | 56.1 / 52.7 · p95 33.3 | 57.9 / 53.6 / 57.1 / 57.8 · p95 16.8 |

\* รอบแรกมีหน่วงค้าง 1 วินาทีหนึ่งครั้ง (min1s 4.1) ตอนเครื่องมี load พุ่ง · อีก 3 รอบไม่เกิดซ้ำ จึงรายงานไว้ ไม่ตัดทิ้ง
ความเห็น: เกณฑ์ "เดินเมือง DPR 2 ≥ 55 fps" ผ่านด้วยมัธยฐาน 58.6 (3 ใน 4 รอบ ≥ 58.5) · รอบตรวจ `?mapdpr=2` + เน้นประสิทธิภาพ (DPR ถูกบังคับกลับเป็น 2, เหลือแค่ลดของเหลว+cap) ได้เดิน 55.7 fps → ส่วนที่ช่วยจริงส่วนใหญ่คือ DPR 1.5 แต่อีกสองอย่างก็ช่วยเล็กน้อย
**ข้อจำกัดที่ต้องบอกตรง:** cap 60 บนจอ 120 Hz วัดจริงไม่ได้ (Chromium headless บนเครื่องนี้ 60 Hz) — ตรวจด้วยเทสต์ตรรกะ (จอ 120 Hz → 60, 60 Hz ที่ timestamp สั่น → ไม่เสียเฟรม, 144 Hz → ≤ 62) · ความร้อนไม่ได้วัด (ไม่มีเซนเซอร์) — เหตุผลเดียวคือวาดน้อยลง
โหมดความละเอียดสูง "หน้าตาเท่าเดิม": ทาง code เท่าเดิมทุกจุด (DPR 2, interval 0 ไม่ reuse, frameDue คืน true เสมอ — มีเทสต์) · ไม่ได้เทียบพิกเซลต่อพิกเซลกับ commit ก่อนหน้า
ภาพหน้าตั้งค่า: `2026-11-10-avegee-graphics-setting/settings-high-1440.png`, `settings-performance-1440.png`, `settings-en-1440.png`, `settings-performance-390.png`
