## สิ่งที่เปลี่ยน
- **ระหว่างสู้** (`game.js` `downActor`): ลูกทีมที่อยู่ในสนาม (นิรา + ยมทูตในทีม + ยักษ์ทวารบาล) ที่ขวัญ/กำลังใจ 0 → ใส่ `battle.fallen` + `absentActors` เหมือนเดิม (ไม่ได้เทิร์น เป็นเป้าไม่ได้ ไม่โดนตี ไม่อยู่ในแถบลำดับเทิร์น) แต่ **ยังไม่ตั้ง `recoverUntil` / ไม่เริ่ม `startRecoveryTeaRest`** · ฟังก์ชันใหม่ `battleParticipant()`, `battleFallen()` · คนที่ไม่ได้อยู่ในสนามของการต่อสู้นั้น (เช่น ยมทูตนอกทีม) ล้มแล้วไปพักทันทีเหมือนเดิม
- **หลังจบ** (`endBattle()` เรียก `updateActorRecovery()` ทันทีหลังปิดฉาก): ตัวที่ล้มเข้า `downActor` ทางเดิมตอนไม่มี battle → `recoverUntil = เวลาจบฉาก + RECOVERY_MS` + `startRecoveryTeaRest` · ใช้ได้ทั้ง ชนะ/แพ้/หนี · ระหว่างหน้าสรุปผลยังนอนอยู่ในฉาก · **RECOVERY_MS = 120,000 ms (2 นาที) ไม่เปลี่ยน** — เปลี่ยนแค่ "จังหวะเริ่ม"
- **ฉาก** (`ui.js`): ผู้ล้มยังถูกวาดในช่อง (slot) เดิมของแถว (เก็บลำดับใน `battle.squadOrder`) ด้วย `battle-ko.js` (sprite `:ko` ถ้ามี ไม่งั้นเอนหลัง 84° รอบเท้า) · คลิกไม่ได้ (`pointer-events:none`) · **การ์ดล่าง** แสดง 0/100 และจางลง (`.is-fallen`) · ถ้าชุบ (morale > 0) ระหว่างสู้ → เอาออกจาก fallen/absent กลับร่วมรบ (`updateActorRecovery`)
- Save/load: การต่อสู้ปกติไม่ถูกเซฟ → โหลดแล้วตัว morale 0 ไม่มี clock เข้าทางเดิมครั้งเดียว (เทสต์: ไม่เริ่มซ้ำ/ไม่ซ้ำรายการ) · ศึกสุดท้ายที่เซฟ `battle.fallen` ก็ย้อนกลับมาปกติ

## ยักษ์ทวารบาล (guard) และยามา
- **guard**: ล้มนอนในฉากเหมือนกัน แต่ตามกติกาเดิม **เหลือ 1 HP บนแผนที่ และไม่ไปศาลาน้ำชา** (เทสต์ยืนยัน morale 1, ไม่มี recoverUntil/teaRest) — ถ้าอยากให้ guard ไปพักศาลาด้วย เสนอให้ตัดสิน (ผมไม่เปลี่ยน)
- **ยามา**: ไม่เปลี่ยนกติกา — เลือด 0 = `B.over='lose'` → ฉากจบแพ้ → `pendingRecovery` ตามเดิม (เห็นนอนค้างในฉากระหว่างหน้าสรุป ตามงาน FX5) · ส่วนลูกทีมที่ล้มในศึกเดียวกันไปศาลาหลังปิดฉากแพ้ตามปกติ
