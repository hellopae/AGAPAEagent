## สิ่งที่ build
เกมเล่นพื้น **v7r** เป็นค่าเริ่มต้น: v7 + native ที่ Codex ซ่อม 7 จุด (REPAIR-1 สี่จุด + REPAIR-2 สามจุด) ประกอบด้วยสคริปต์ `assemble-v7r.py`
- **core ของแต่ละจุด = native พิกเซลต่อพิกเซล** (วัดแล้วต่างจาก native 0) วางด้วย affine ลงทะเบียนของ Codex เอง (ตรงกับ `registered-2x.webp` ของเขา เฉลี่ย 0.01–0.36/255)
- **รอยต่อ**: วงแหวน 48 map px รอบ core ใช้ min-cost seam ตัวเดียวกับ assemble.py ของ Codex (ต้นทุน = ผลต่างสี², เดินได้ −1/0/+1, feather ±8 px) ต่างจากของเดิมที่ "เพิ่มโทษ" ตรงที่ v7 ยังเป็น v5 เบลอ (ฟื้น baseline v5 ตาม hash ของ Codex แล้ววัดว่าพิกเซลไหนยังเป็น fallback) → เส้นตัดไปอยู่ตรงที่ v7 เป็น native แล้ว ภาพจึงคมถึงขอบ
- **ปรับสี/ความสว่างเฉพาะแถบรอยต่อ**: ผลต่างความถี่ต่ำ (v7 − native) ใกล้เส้นตัด ไม่เกิน ±10 RGB ลดเหลือ 0 ที่ขอบ core
- นอก 7 context **ไม่เปลี่ยนแม้พิกเซลเดียว** · ติดตั้งด้วย `install-z1-ground.py <pack> --name v7r --activate` → `img/map-zone1/v7r/` 70 ไทล์ 23.6 MB (v7 เดิม 23.4 MB) · `ZONE1_GROUND_SET='v7r'` (v7 ยังอยู่ แก้บรรทัดเดียวกลับได้) · importmap `zone-skin.js?v=20261112-z1v7r`

## ตรวจแล้ว (รันจริง)

- **ความคม**: Laplacian variance ของวงแหวน = 1.21–1.81 เท่าของแถบ 60 px รอบนอก (v7 เดิม 0.52–0.80 เท่า) — `verify-v7r.json`
- **seam-check ภาพขยาย**: `compare/*-v7-vs-v7r.jpg` (ก่อน | หลัง ที่ 1 พิกเซลเอาต์พุต, กรอบฟ้า = context, ม่วง = core) ครบ 7 · และในเกมจริง 390×844 @2× ซูมสุด `game-zoom/cmp-z5-*.jpg`
- **walkmask**: ไม่แก้ไฟล์ walkmask (hash เดิม) · `walkmask-overlay/*.jpg` ขอบที่เดินไม่ได้ตามบันไดที่ซ่อมถูกต้อง 7 จุด · เทสต์เดินครบ (ราวบันไดท่าเรือ ดูล่าง)
- **ของเหลว shader ทับตรง**: เรนเดอร์ 7 มุมกล้องใน Chromium ทั้ง v7 และ v7r — ล้นนอกของเหลว ≤ 0.49% ทุกจุด (สะพานสวรรค์ล้น 4.28% ลดจาก 6.15% ของ v7; ส่วนล้นอยู่ที่ขอบเมฆนอกจุดซ่อม) · น้ำตกใต้สะพานและน้ำท่าเรือถูกคลุมตรงตัวภาพ native (ไม่พบน้ำนอกโซน) · ผลรายจุด `render-v7.json` / `render-v7r.json`
