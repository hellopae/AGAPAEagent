## สิ่งที่ build

**ข้อ A — กลไกใหม่**
- ตัดการกินฟืนต่อสถานี (`st.def.fuel`) ออกทั้งหมด — ไม่มีสถานีไหน "หยุดทำงาน" เพราะเสบียงหมดอีกต่อไป
- ผู้กินเสบียงคือ **ยมทูตจริงที่กำลังทำงานอยู่** เท่านั้น: กำลังคุมสถานีที่มีดวงอยู่จริง (`activeSlots.length`) หรือกำลังเดินออกไปรับดวงใหม่ (`c.escort`) — ท่านเอง (SELF) ไม่กิน ไม่มีค่าจ้าง เหมือนเดิม
- กินรวมกันคนละ `BAL.foodEatRate` (0.5) ต่อวาระ จากสระเสบียงกลาง (`g.food`) เท่ากันทุกคนทุกสถานี ไม่แยกตามชนิดสถานีแล้ว
- **อิ่ม** (เสบียงพอ) = ทำงานไวขึ้น ×1.18 (`foodFullMul`) · **หิว** (เสบียงหมด) = ทำงานช้าลงเหลือ ×0.7 (`foodHungryMul`) — ไม่หยุดสนิท แค่คดีคืบหน้าช้าลง พร้อมแจ้งเตือนในบันทึก (`🍙 เสบียงหมด — ยมทูตที่กำลังทำงานอยู่ช้าลง`)
- ตัดค่าจ้างยมทูตรายวาระที่เป็นเบี้ยกรรม (`c.pay` ทุก `payEvery`) ออกทั้งหมด — ให้เสบียงเป็นค่าจ้างทางเดียว ค่าจ้างแรกเข้า (`hire`) คงเดิมทุกคน ยักษ์ทวารบาลยังจ่ายเบี้ยรายงวดเหมือนเดิม (ไม่ได้คุมสถานี/ออกรับดวง จึงไม่เข้าเงื่อนไข "กำลังทำงาน")
- `g.fed` (boolean) + `g.workingCrew` (Set ของ key ยมทูตที่กำลังทำงาน) คำนวณใหม่ทุกวาระ ให้ UI ใช้แสดงสถานะได้

**ข้อ B — เปลี่ยนคำทุกจุดที่ผู้เล่นเห็น**
HUD (🔥→🍙), ปุ่ม/ร้านซื้อในแท็บก่อสร้าง, บรรทัด "ฟืน x/วาระ" บนการ์ดสถานี (ลบทิ้ง — ไม่มีความหมายแล้วเพราะไม่ผูกกับสถานีอีก), tooltip ยมบาท, การ์ดยมทูต (ลบ "ค่าแรง X" ที่เป็นเบี้ยรายงวด — เปลี่ยนเป็นสถานะอิ่ม/หิวเมื่อกำลังทำงาน), ป้ายในแผงสถานี ("ผู้คุมประจำหลังนี้" เพิ่มสถานะอิ่ม/หิว), ร้านพ่อค้า/บุญ, เหตุการณ์ "พระธุดงค์เดินผ่าน", คำอธิบายโลกันตนรก, ปุ่ม "ประหยัดฟืน" ที่เป็น dead code (ถอดออกจริง ไม่ใช่แค่ซ่อนปุ่ม), tutorial บทที่ 9, item "มัดฟืน"→"ห่อเสบียง" 🍙, item "เศษฟืนอาถรรพ์"→"เศษถ่านอาถรรพ์" (วัตถุดิบขายพ่อค้า ไม่เกี่ยวกับค่าจ้าง — เปลี่ยนแค่ชื่อกันสับสนกับเสบียง), ดำ (dam) เปลี่ยนหน้าที่ "ขนฟืน"→"ขนเสบียง" และคำพูด

## ตารางตัวเลขเก่า-ใหม่

| รายการ | เดิม (ฟืน) | ใหม่ (เสบียง) |
|---|---|---|
| ผู้บริโภค | สถานีที่ใช้ไฟ 5 หลัง: กระทะ 1.4 · งิ้ว 0.4 · ป่าดาบ 0.3 · ลาน 0.2 · ศาลา 0.2 ต่อวาระ (ไม่ว่าจะมีคนคุมหรือเปล่า — ผูกกับ "อาคาร") | ยมทูตจริงที่ **กำลังทำงานอยู่จริง** (คุมสถานี/ออกรับดวง) คนละ 0.5/วาระเท่ากันหมด ไม่ว่าจะคุมสถานีไหน (ผูกกับ "คน") |
| เริ่มต้น | 80 ดุ้น | 80 ห่อ |
| ราคาเติม (แท็บก่อสร้าง) | 3 เบี้ย/ดุ้น = 30 เบี้ย/10 | 4 เบี้ย/ห่อ = 40 เบี้ย/10 |
| ของเก็บบนแผนที่ | มัดฟืน +12 | ห่อเสบียง +12 (เท่าเดิม) |
| ของหมด | สถานีที่ใช้ไฟ **หยุดทำงานทันที** | ยมทูตที่กำลังทำงานอยู่ **ช้าลงเหลือ 70%** ไม่หยุด |
| มีพอ | ไม่มีโบนัส (แค่ทำงานปกติ) | ยมทูตที่กำลังทำงานอยู่ **เร็วขึ้น 118%** |
| ค่าจ้างรายวาระ (ยมทูตจริง) | หักเบี้ยกรรมทุก 30 วาระ รวม 84 (taan14+nira12+plerng16+kan18+boon15+dam9) | **ไม่มีแล้ว** — กินเสบียงแทนเฉพาะตอนทำงานจริงเท่านั้น (นิราไม่ทำงานสถานี เลยไม่กินอะไรเลยตอนนี้) |
| ค่าจ้างยักษ์ทวารบาล | หักทุก 30 วาระ 22 เบี้ย | เหมือนเดิม ไม่เปลี่ยน (ไม่ใช่ยมทูตที่คุมสถานี) |
| ค่าจ้างแรกเข้า (hire) | เท่าเดิมทุกคน | เท่าเดิม ไม่เปลี่ยน |

**ภาระรวมโดยประมาณ** (สมมติ 5 ยมทูตทำงานพร้อมกันครบ — เท่ากับจำนวนคนจริงที่ไม่ใช่นิรา):
- เดิม: ฟืน 2.5/วาระ × 3 เบี้ย = 7.5 เบี้ย/วาระ + ค่าจ้าง (72÷30) = 2.4 เบี้ย/วาระ ≈ **9.9 เบี้ย/วาระ**
- ใหม่: เสบียง 5×0.5=2.5/วาระ × 4 เบี้ย = **10 เบี้ย/วาระ** — ใกล้เคียงเดิมมาก (คลาดเคลื่อน ~1%)

โครงสร้างต้นทุนเปลี่ยนจาก "จ่ายคงที่ไม่ว่าจะมีงานหรือเปล่า" (ฟืนผูกกับอาคาร) เป็น "จ่ายเฉพาะตอนใช้งานจริง" (เสบียงผูกกับคน) — ยมทูตที่ว่างงาน/พักอยู่ ไม่กินเสบียงเลย ต่างจากเดิมที่สถานีเผาฟืนแม้บางจังหวะไม่มีคนคุมชัดเจน (ในทางปฏิบัติ 1 สถานีมี 1 คนคุมอยู่แล้วเสมอ ผลจึงใกล้เคียงเดิมในภาพรวม)
