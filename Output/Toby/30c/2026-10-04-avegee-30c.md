## สิ่งที่ทำ

1. Pause ซ้ำ/ค้าง: แยก native dialog ของ pause ออกจาก dialog ฉากเดิม ไม่แทนที่ DOM ของศึก/popup/cutscene จึงรักษาปุ่มและ close handler เดิมไว้ เพิ่ม guard ต่อ blur/visibility/focus ซ้ำ และเคลียร์ userPaused/autoPausePending ทันทีในปุ่มเล่นต่อ ไม่รอ native close event คืน focus ให้ฉากเดิม หลังปิด pause แผนที่เดินต่อ ส่วนศึก/กล่องยังพัก simulation แผนที่ตามปกติจนจบฉาก ปุ่มศึกเดิมยังอยู่
2. Native close event เก่าที่เข้ามาหลังเปิด dialog ใหม่: onDlgClose ไม่ให้ event ขณะกล่องปัจจุบันยังเปิดอยู่กิน callback ของกล่องใหม่
3. เปลี่ยนโซน: เคลียร์ bossWalk (ตัวที่ releaseDlgPause ใช้ล็อกการคืน simulation), huntMob และเส้นทาง/เป้าหมายเก่าของผู้เล่น ก่อนตั้งเส้นทางเข้าประตูของโซนใหม่ ตรวจ transition 1→2→3→4 ด้วย Node ได้ ไม่มีการรีเซ็ต user pause ของผู้เล่นโดยพลการ ยังไม่ได้ reproduce เซฟจริง #33 จึงถือว่าแก้ป้องกัน state ค้าง ไม่ยืนยันต้นเหตุจริง
4. Returning: ไม่พบการสุ่มใส่สถานะ back ให้สำนวนใหม่ในโค้ดปัจจุบัน สำนวนกลับมาจริงมาจาก moveFromPrison ซึ่งใช้ sentence ที่ผู้เล่นลงทัณฑ์ไปแล้ว และอีกทางคือ returning ในเซฟเก่า ข้อผิดพลาดที่พบคือ delayed return มี fallback ส่งเข้าคิวโซนปัจจุบัน แม้เป็นของสาขาอื่น แก้ให้ส่งเฉพาะคิวต้นทาง หากยังไม่มีสาขาต้นทางให้คงรายการไว้จนมีคิวรับ ไม่สร้างวิญญาณใหม่/ไม่แต่งประวัติการลงทัณฑ์ เพิ่ม zone ให้ข้อมูลกลับจาก sentence เซฟ legacy ที่ไม่มี zone ใช้ th เป็น fallback (สมมติฐานเพื่อไม่ยกประวัติที่ระบุสาขาไม่ได้เข้าสาขาใหม่) ไม่ใช้ threshold N และไม่เปลี่ยนสมดุล สถานะ back ที่มีอยู่แล้วในคิวเซฟเสียไม่ได้ถูกลบทิ้ง
5. เปลี่ยนบาปตัดต่อเสียงพ่อแม่ของคนอื่นจาก akata → kong (ฉ้อโกง id เดิม) คำให้การสุ่ม mkLines ใช้ sin ของ deed จึงได้ deny หมวด kong ทดสอบเลือกคำขัดแย้งด้วย press จริงแล้ว ไม่เปลี่ยนเนื้อหาสำนวนอื่น ไม่เพิ่มข้อความผู้เล่น สี หรือ balance
