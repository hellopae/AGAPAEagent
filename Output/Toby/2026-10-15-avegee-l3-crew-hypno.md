## สิ่งที่ build

### 1) ปุ่ม "ไปพักที่ศาลาน้ำชา" ต่อคน
- ตอนตรวจพบว่าระบบนี้มีอยู่แล้วบางส่วน: `restActor()` + ปุ่ม `data-guard-rest` ใน `guardRestWidget()` แต่ **ปุ่มโผล่เฉพาะเมื่อ HP < 50 (ยมทูต) / < 100 (ยักษ์)** คุณเป้เลยไม่เห็นปุ่ม (โกคุ 100, โฮมุระ 97, ซาโตริ 78 ฯลฯ ในภาพ) — จุดที่เห็นแค่ "กำลังเดินไปศาลาน้ำชา" คือยักษ์ทวารบาลที่ HP ต่ำกว่า 100 อยู่แล้ว
- แก้: ทุกคนที่ไม่ใช่ผู้อ่าน (นิรา) กดพักได้เมื่อ **HP < 100** (`game.js restActor`)
- ปุ่มแสดงเสมอบนการ์ด (เมื่อไม่ได้พักอยู่) · จางพร้อมเหตุผลใต้ปุ่ม: "HP เต็มแล้ว ไม่ต้องพัก" / "ต้องสร้างศาลาน้ำชาให้เสร็จก่อน" / "อยู่ในศึก พักไม่ได้" / "กำลังฟื้นตัว พักไม่ได้" (key ใหม่ `g1.full/inBattle/down/inTeam` ทั้ง th/en)
- สถานะระหว่างพัก (ของเดิม ใช้ต่อ): "กำลังเดินไปศาลาน้ำชา" → "พักฟื้นที่ศาลาน้ำชา · เหลือ N วินาที" (HP x/100 โชว์ตลอด) → ครบ 60 วิ (ยักษ์ 120 วิ) HP=100 แล้ว**เดินกลับจุดทำงานเอง** — อัตราพักเดิมไม่แก้
- **กติกาทีมสู้ (ตัดสินตามของเดิม):** ยมทูตที่อยู่ในทีมสู้กดพักได้ ระหว่างเดิน/พัก `actorStanding=false` → `crewHelpers()` ตัดเขาออกจากสนามรบชั่วคราว แต่ **ยังอยู่ในรายชื่อทีม** (party.members ไม่ถูกแตะ) กลับมาร่วมสู้เองตอนเต็ม — ใต้ปุ่มมีบรรทัดเตือน "อยู่ในทีมสู้ — ระหว่างพักไม่ร่วมต่อสู้ (ยังอยู่ในทีม กลับมาเองตอนเต็ม)" · พักระหว่างอยู่ในศึกไม่ได้ (กฎเดิม)
- ไม่ได้ทำปุ่ม "กลับไปทำงาน" (ใบงานให้เลือกอย่างใดอย่างหนึ่ง เลือกกลับเองอัตโนมัติ)

### 2) สะกดจิต
- **สาเหตุที่โผล่ในโซน 1:** `POWERS.hypno` ใน `data.js` มี `lv:4` และ `game.powerLocked()` ปลดพลังตามเลเวลอย่างเดียว (`level >= p.lv`) → พอยมบาทเลื่อนขั้น 4 (ทำได้ในโซน 1) `syncDiscoveries()` ก็คิว popup `power:hypno` "ได้พลังใหม่ · สะกดจิต" และปุ่มสะกดจิตในห้องสอบสวนใช้ได้ทันที (ยืนยันซ้ำ: สร้างเซฟ lv5 โซน 1 รันบน main `99ec562` → คิวได้ `power:roar, power:ice, power:hypno`; บน branch ได้เฉพาะ roar/ice) ข้อความ "ซื้อจากบุญ" เป็นคอมเมนต์/desc ที่ค้าง — BOON_SHOP และ MERCHANT stock ว่างตั้งแต่ชุด 10 อยู่แล้ว ไม่มีของขายจริง
- **แก้:** `powerLocked()` ของ hypno = `!abilities.hypno` (ไม่ผูกเลเวล) · `abilities.hypno` ถูกตั้งตอนชนะ event `westVampireBreach` (บอสชายแดนโซน 3 · แวมไพร์) ครั้งแรก — reward `{ability:'hypno'}` มีอยู่ในข้อมูลแล้ว ไม่ต้องเพิ่ม · ปุ่มต่อสู้เดิมเช็ค `abilities.hypno` อยู่แล้ว
- popup: ใช้ `power:hypno` ตัวเดิม ("ได้พลังใหม่ · สะกดจิต" ข้อความอธิบายสอบสวน+ต่อสู้) และ **ข้าม `ability:hypno`** เพื่อไม่ให้เด้งซ้ำสองครั้งตอนชนะบอส
- ลบคำว่า "ซื้อจากบุญ/ซื้อวงสะกดจิต/บุญยังขาย" ใน `data.js` (desc ของ POWERS.hypno, desc/use ของ sawan, คอมเมนต์ BOON_SHOP/MERCHANT/POWERS) · ข้อความล็อกในแท็บ "พลัง" และวงคำสั่งสอบสวนเปลี่ยนเป็น "ล็อก · ชนะบอสชายแดนโซน 3 ก่อน" สำหรับ hypno
- **เซฟเก่า (ริบตามคุณเป้เลือก):** ตัดกติกา "คงไว้" ออกแล้ว (ไม่มี marker/grandfather) · `restore()` ให้ `abilities.hypno` เฉพาะเซฟที่ชนะแวมไพร์โซน 3 แล้ว (flag ใน abilities ของเซฟ หรือ event `westVampireBreach` = cleared) เซฟ lv4+ ที่ยังไม่ชนะจะถูกล็อกสะกดจิต และล้างสถานะ "เคยเห็น popup สะกดจิต" ทิ้งเพื่อให้ popup เด้งตอนชนะบอสจริง
  - `g.buyBoon` + `BOON_SHOP` ยังเป็น dead code (stock ว่าง) ไม่ได้ลบเพื่อไม่ขยายขอบเขต
