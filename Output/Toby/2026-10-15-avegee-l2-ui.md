## สาเหตุที่ "ป้องกัน" และ "หนี" เป็นโจมตี
ตรรกะเกมถูกอยู่แล้ว (`battleAct`: `defend` ตั้ง `B.defending`, `flee` ตั้ง `B.over='flee'`) — ผิดที่ **ui.js `executeCommand`** ที่ทุกคำสั่งวิ่งเส้นทางเดียวกับโจมตี:
- `effect = ... || k` แล้ว `fxNow = { key: FX_OF[effect] ? effect : 'atk', side:'foe' }` — `defend`/`flee` ไม่มีใน `FX_OF` จึงถูกแปลงเป็น `'atk'` (ยิงเอฟเฟกต์ฟัน/กรงเล็บใส่ศัตรู)
- `paint()` ตั้ง `act = { lunge:'you', struck:'foe' }` ทุกครั้งที่ `phase==='you'` → ยมบาทน้อยพุ่งท่าโจมตี ศัตรูสะดุ้ง
- ยังเรียก `playActionCutscene(k)` + `powerSound(k)` (เสียง hit) และเข้าจังหวะ 2 ช่วงแบบโจมตี
- หนีไม่มีหน้าต่างถาม; ป้องกันไม่มีไอคอนโล่/ข้อความบอกผล
หลักฐานก่อนแก้: `/tmp/l2/repro-defend-mid.png` (กดป้องกัน → ยมบาทน้อยท่าโจมตี + รอยกรงเล็บ)
(ใบงานข้อ 3 "ใช้ของเดิมก่อน": ระบบ guard มีอยู่แล้วที่ `B.defending` ลด x0.5 — ใช้ต่อ ไม่แก้ค่า, แค่ย้ายเป็นค่าคงที่ `DEFEND_DAMAGE_RATIO = 0.5`)

## ฟังก์ชัน "หนี" จุดเดียวสำหรับ Toby L5 (ตามที่ขอ)
- ตรรกะ (game.js): **`g.fleeWhy(kind?)`** → `''` (หนีได้) | `'noBoss'` | `'noEvent'` · **`g.fleeBattle()`** → ทำ flee จริง (ไม่ได้รางวัล) คืน true/false · รายการชนิดที่หนีได้อยู่ที่เดียว `FLEEABLE_KINDS = ['soul','mob','frontier']`

- ในฉากต่อสู้ปุ่มหนีเรียก `performFlee()` (ใน `openBattle`) ที่ใช้ `g.fleeBattle()` แล้ว `finish()` — ถ้า L5 อยากให้ศัตรูที่เดินเข้ามาถามก่อนเข้าศึก ให้ใช้ `openFleeConfirm` + ถ้ายืนยันก็แค่ไม่เปิดศึก (ยังไม่มี battle จึงไม่ต้องเรียก `g.fleeBattle()`)
