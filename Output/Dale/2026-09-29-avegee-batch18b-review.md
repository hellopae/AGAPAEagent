## บั๊กที่เจอระหว่างรีวิว + วิธีแก้ (แก้เองแล้ว 1 จุด — เข้าเกณฑ์ "ข้อเล็ก" ตามกติกา orchestration ข้อ 10)
**คีย์ลูกศรเปลี่ยนหน้าคู่มือหยุดทำงานหลังคลิกเมาส์ครั้งแรก** (พบด้วย Playwright: คลิกปุ่ม "ถัดไป" หนึ่งครั้ง
แล้วกด ArrowRight → หน้าไม่ขยับเลย ทั้งที่เกณฑ์ข้อ 7 ระบุ "คีย์ลูกศรซ้าย/ขวาเปลี่ยนหน้า" ชัดเจน)

สาเหตุ: `show()` เขียนทับ `reader.innerHTML` ทุกครั้งที่เปลี่ยนหน้า ปุ่มที่ผู้ใช้เพิ่งคลิก (ซึ่งกำลังมีโฟกัส)
ถูกลบออกจาก DOM ไปด้วย เบราว์เซอร์จึงย้ายโฟกัสไปที่ `<body>` โดยอัตโนมัติ ต่อจากนั้นการกดคีย์ลูกศรจะ dispatch
event ที่ target = body ซึ่ง**ไม่ใช่ลูกของ** `dlg` (dialog element) — event listener `d.addEventListener('keydown', keys)`
ที่ผูกไว้ตอน bubble phase เลยไม่มีวันได้ยิน event นี้อีกเลยตลอดเซสชันนั้น (ยืนยันด้วยการ dispatch KeyboardEvent
ตรง ๆ ที่ `dlg` เทียบกับที่ `document` — dispatch ที่ `dlg` ทำงาน ที่ `document` ไม่ทำงาน ตรงกับทฤษฎี)

แก้ที่ `src/ui.js` ฟังก์ชัน `openHelp()` → `show()`: เพิ่ม `d.focus({ preventScroll: true })` ท้ายทุกครั้งที่
render หน้าใหม่ (คืนโฟกัสกลับไปที่ `dlg` เอง ซึ่งเป็น element เดียวที่ไม่เคยถูกแทนที่ = ที่คีย์ลูกศรผูกอยู่)
ทดสอบซ้ำแล้วคีย์ลูกศรใช้งานต่อเนื่องได้ไม่ว่าจะเพิ่งคลิกเมาส์มาก่อนกี่ครั้งก็ตาม ไม่กระทบปุ่ม/จุดหน้า/ปัดจอสัมผัส
(ยังทำงานปกติทั้งหมด) `node --test` ยัง 49/49 ผ่านหลังแก้
