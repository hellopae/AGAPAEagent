## 2. ส่วนที่ 1 — ใบวินิจฉัยวิญญาณ (ตะราง `tarang` + ประตูสวรรค์ `sawan`)

### 2.1 ทางเข้า
1. แผงรายชื่อเดิม (drawer): ทุกแถวเพิ่มปุ่มรอง **"วินิจฉัย"** (ไอคอน 🔍 ขนาดสัมผัส 44px) และกดที่ชื่อแถวก็เปิดได้
2. ป้ายลอยเหนือหัววิญญาณในห้อง (ใช้ `R.anchor(room.souls[i], SOUL_H)` แบบเดียวกับ `lotus`/`manage`): ปุ่มเล็ก "ใบวินิจฉัย" ปรากฏเมื่อเลื่อนเมาส์/แตะวิญญาณ · ห้องมี 3 ช่อง ถ้ามีเกิน 3 ดวงให้ใช้แผงรายชื่อ
3. ในใบมี ‹ › วนดูดวงอื่นใน **ห้องเดียวกัน** (ตะรางรวม `held` + `stage:'prison'`; ประตูสวรรค์ `stage:'gate'`) และปัดซ้ายขวาบนมือถือ
4. ปุ่มดำเนินการท้ายใบเรียกฟังก์ชันเดิมทั้งหมด (`inspectPrison` `moveFromPrison` `inspectGate` `resolveGate` `release`) พร้อมแอนิเมชันห้องเดิม (`R.prisonEscort`, `R.gateEffect`) ไม่สร้างกติกาใหม่

### 2.5 สถานะสรุป (แบนเนอร์ใต้รูป + ปุ่มหลัก)
| เงื่อนไข (เรียงลำดับตรวจ) | แบนเนอร์ | สี | ปุ่มหลัก (ฟังก์ชันเดิม) |

| `stage:'prison'` `!inspected` | รอนิราตรวจความสำนึก | กลาง | นิราตรวจ (`inspectPrison`) |
| `stage:'prison'` `inspected && repentant` | เข็ดแล้ว · พร้อมไปประตูสวรรค์ | เขียว | ส่งไปประตูสวรรค์ (`moveFromPrison`) · ถ้ายังไม่มีประตู: ปุ่มปิด + ข้อความ "ต้องสร้างประตูสวรรค์" (ตรงกับ `room.needSawan`) |

### 2.6 พฤติกรรม
- เปิดใบ = หยุดเกมเหมือน dialog อื่น (`pauseForDlg`) ปิด Esc/✕/กดฉากหลัง
- กดปุ่มหลักแล้ว: เล่นแอนิเมชันห้องเดิม ใบปิดเอง แล้วถ้ายังมีดวงถัดไปให้เปิดดวงถัดไปที่ "ต้องทำอะไรต่อ" อัตโนมัติ (ผู้เล่นปิดค้างได้ที่ ✕)
- reduced-motion: ตัดแอนิเมชันแท่งวิ่ง/เรืองแสง เหลือเปลี่ยนค่าทันที
- โฟกัสคีย์บอร์ด: กับดัก Tab ในใบ, ‹ › ด้วยลูกศร, Esc ปิด

### 4.2 วิธีกด (ไม่ชนกับคลิกเดิน)
ฐานโค้ด: `onSceneClick` ตรวจ "ตัวละคร" **ก่อน** "พื้นโล่ง" อยู่แล้ว → แตะตัวละครจึงไม่เคยกลายเป็นคำสั่งเดิน ไม่มีชนกันที่ระดับคลิก ที่ต้องจัดการคือ 3 เรื่องนี้:

1. **แตะตัวละครไกล (> `INTERACTION_REACH` 100)**: เดินเข้าหา (`g.walkTo`) แล้วเปิดบับเบิลอัตโนมัติเมื่อถึง (รูปแบบเดียวกับ `openDevaEncounter`) · ถ้าผู้เล่นเดินเอง (WASD/แตะที่อื่น) ก่อนถึง = ยกเลิก
2. **แตะตัวละครใกล้ (≤ 100)**: เปิดบับเบิลทันที + ยังเลือกขึ้นแผงข้อมูลตามเดิม (`select(a)`)
3. **ปุ่ม 💬 และปุ่ม E (โซน 1)**: เพิ่ม kind `talk` ใน `mapInteractions` โดย **กรองให้โผล่เมื่อไม่มี interaction อื่นอยู่ในระยะ** (สถานี/นิรา/พ่อค้า/ท่าเรือ/ซ่อม มีสิทธิ์เหนือกว่า) เพราะ `nearestInteraction` เลือกตามระยะล้วน ระยะเอื้อมคุยตั้ง 70 · ถ้าตัวละครยืนติดสถานี ปุ่ม E จะไปที่สถานีและผู้เล่นคุยผ่านการแตะตัวแทน — ตั้งใจให้แตะเสมอได้ผลเสมอ

กฎกัน misclick:
- ตัวละครซ้อนกัน (ระยะ < 24 หน่วยโลก) เลือกตัวที่ใกล้จุดแตะที่สุด แทนลำดับตายตัวใน `hitActor` ยกเว้นเปรต/เป้าต่อสู้ที่มีลำดับสูงกว่าเดิม
- พื้นที่แตะขั้นต่ำ 44×44px บนหน้าจอ (คิดหลังซูมกล้อง: ซูม 5× ของโซน 1 พอ, ซูมออก 1× ใช้ `CHAR_HIT_PAD_MAP` ขยาย)
- ปุ่ม 💬 ใช้ `.repairfab` pattern เดิม (หัวตัวละคร, `anchor-top`, clamp ในจอ, ชดเชยสเกลกล้องด้วย `--map-label-scale`)
- ห้ามหยุดเกม (`pauseForDlg`) ตอนคุย — เป้าหมายคือ "ให้เกมมีชีวิต"; บับเบิลหายเอง 6 วินาที หรือเมื่อเดินห่าง > 140

### 4.3 รูปแบบบับเบิล (ใช้ระบบเดิม)
- ใช้ `mark()` + `.bub` ใน `#ov` (หมุดตามพิกัดฉาก + `followMarks` ตามตัวละครที่เดินได้) คลาสใหม่ `mark talk speech-side` เปิดแบบ `show=true`; ต่อยอด `data-follow` ให้รองรับ kind `worker`/`soul` (ปัจจุบันตาม `g.crewOf` เท่านั้น)
- เนื้อหา: บรรทัดชื่อ (`who` สีทอง 11px) + ข้อความ ≤ 2 บรรทัด ความกว้างสูงสุด 250px (มือถือ 220px) ตัวอักษร ≥ 13px line-height 1.6
- แตะบับเบิลหรือกด "ถัดไป ›" = บทถัดไป (วน 1–3 บท) แล้วปิด · บทที่ผู้เล่นเห็นแล้วเลือกสุ่มแบบกันซ้ำ 30 บรรทัดล่าสุดต่อตัว (ใช้ `pickFresh` เดิม)
- ตัวแปรขึ้นสีทองอ่อนเฉพาะใน mock เพื่อสื่อสาร ในเกมจริงเป็นสีข้อความปกติ
- เสียง: ใช้ `sfx('step')`/ที่มีอยู่แล้ว ไม่เพิ่มไฟล์เสียง
- คีย์บอร์ด: Esc ปิดบับเบิล · Enter/E บทถัดไป

### 5.2 สูตร `remorse` (รักษาสมดุลเดิม)
ปัจจุบัน: เข็ดเสมอเมื่อ `short<=0`; เมื่อ `short>0` เข็ด 30% (`1 − RETURN.chance`) สุ่ม ณ ตอนกดตรวจ
เสนอย้ายการสุ่มมาตอนจบทัณฑ์ แล้วเก็บเป็นตัวเลข:
```
short <= 0           → remorse = rand(65..100)
short  > 0 (30%)     → remorse = rand(60..85)    // เข็ด
short  > 0 (70%)     → remorse = rand(25..54)    // ยังไม่เข็ด
inspectPrison: repentant = remorse >= 60
```
ความน่าจะเป็นผลลัพธ์เท่าเดิมทุกกรณี ไม่มีผลต่อ balance · ผลพลอยได้: ปิดช่องโหลดเซฟแล้วตรวจซ้ำเพื่อสุ่มใหม่ · ถ้าคุณเป้เลือกสูตรตายตัว (ข้อ D1 ตัวเลือก B) ต้องมีใบงานปรับสมดุลแยก
