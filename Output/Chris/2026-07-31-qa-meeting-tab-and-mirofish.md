## 1.5 XSS / escape — ✅ ผ่าน (ตรวจซ้ำแล้ว ไม่ได้เชื่อ Dale)

ยัด payload `<img src=x onerror="window.__PWN=1">"><script>window.__PWN=2</script>` ลง **ทุกฟิลด์**
ที่มาจากไฟล์: `topic` · `sop` · `status` · `proposal` · `keyPoints[]` · `point` · `quote` · `impact` ·
`role` · `agentName` · `agentImg` · `file` · `factcheckFile` · `conclusion` · `decisions[].question` ·
`options[]` · `owner`

| ตรวจ | ผล |
|---|---|
| `window.__PWN` | **undefined** — ไม่มีโค้ดไหนรัน |
| `<script>` ที่หลุดเข้า DOM | **0** |
| `<img>` ใน `#meetBody` | 4 = avatar ล้วน (ของ 2 คน × img+fallback) ไม่มีตัวที่ inject มา |
| ข้อความ payload | เรนเดอร์เป็น **text** ทั้งหมด |
| `href` | ถูก prefix ด้วย `MT_REPO` คงที่เสมอ + `TD_ESC` → หลุดออกจาก attribute ไม่ได้ |
| `onclick` | ใส่แค่ **index ตัวเลข** (`openMeetingAt(0)` / `mtJump(0)`) ไม่มี string จากไฟล์เข้า JS context — ตรงตามที่ Dale เขียนไว้ และผมยืนยันจากซอร์สแล้ว |

**หมายเหตุเทคนิค (NOTE ไม่ใช่ช่องโหว่):** `TD_ESC` ไม่ escape `'`
วันนี้ไม่มีจุดไหนในโค้ดใหม่ที่เอาค่าจากไฟล์ไปวางใน attribute ที่ครอบด้วย `'` หรือใน JS context
→ **ยังไม่เป็นช่องโหว่** แต่ถ้าวันหลังมีคนเขียน `style='...'` หรือ `onclick='...'` เมื่อไหร่จะกลายเป็นช่องโหว่ทันที
ควรเติม `"'":"&#39;"` ลงตาราง `TD_ESC` ไว้เลย (1 บรรทัด) — **ข้อเสนอรอบหน้า**

1. **`TD_ESC` ไม่ escape `'`** — วันนี้ไม่เป็นช่องโหว่ (ไม่มีจุดไหนวางค่าจากไฟล์ใน attribute เดี่ยว/JS context)
   แต่เติม `"'":"&#39;"` ไว้ 1 บรรทัดจะปิดความเสี่ยงในอนาคตทั้งหมด
2. **`decisions` ที่เป็น object ว่าง** เรนเดอร์เป็น `<li>` เปล่าที่ยังมีเส้นคั่นและ ◇
   — validator บังคับ `question` อยู่แล้ว เข้ามาทางปกติไม่ได้ · เพิ่ม guard ถ้าอยากกันไว้อีกชั้น
3. **`.mt-entry-role` ขึ้นต้นด้วย `· ` ตายตัว** — ถ้า `role` ว่างจะเหลือจุดลอย
   validator บังคับ `role` แล้ว จึงเป็นแค่ defensive ที่ยังขาด
4. **ที่ ≤760px ตัวคั่น `⇄ ค้าน ⇄` ถูกดันลงไปอยู่ *ใต้* ชื่อทั้งสองฝั่ง** (`order:3`)
   อ่านเป็น "Nick Minnie / ⇄ ค้าน ⇄" ซึ่งบอกไม่ชัดว่าใครค้านใครจนกว่าจะอ่านบรรทัดล่าง
   — **ตรงตามที่ Vera สั่งทุกตัวอักษร** ผมจึงไม่ติด Dale · แต่เสนอให้ Vera ทบทวนรอบหน้า
   (ทางที่ง่ายกว่า: ให้ `.mt-clash-head` เป็น `flex-direction:column;align-items:flex-start` ที่ ≤760px)
5. **ชิป `⚖ ประชุม` ยังไม่โผล่ใน Work Log วันนี้** — ผมยืนยันว่า**ไม่ใช่บั๊ก**:
   `worklog.json` ไม่มี entry ของงาน MiroFish เลย (entry ล่าสุด 29 ก.ค. · `outputFile` 30 รายการ
   ไม่มีอันไหนชี้ไฟล์ MiroFish) ผมทดสอบด้วย entry ปลอมที่ `outputFile` ตรงกันแล้ว → **ชิปขึ้นถูก**
   → เรื่องที่ต้องตามคือ **ทำไม hook `SubagentStop` ไม่บันทึกงานทั้งสปรินต์ลง worklog**
   ซึ่ง Vera กับ Dale ชี้ตรงกันแล้ว และกระทบ DoD ข้อ 4 โดยตรง — **ใหญ่กว่าแท็บ Meeting**
6. **Accessibility ตามที่ Vera สั่ง — ทำครบ:** การ์ดเป็น `<button type="button">` ที่มีแต่ `<span>` ข้างใน
   (valid HTML) · `:focus-visible` มี · `aria-label` ที่ปุ่มย้อนกลับมี · avatar มี `alt` + `onerror` fallback ·
