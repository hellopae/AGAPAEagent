# map-markup-extract — จากภาพวาดทับ → mask + ตำแหน่ง

ต้นแบบ: ชายแดน 1–2 วันที่ 23 ต.ค. 2569 (`Output/Claudy/frontier12/`, ใบงาน `briefs/2026-10-23-avegee-f12-*`)

## 1. จับคู่ screenshot กับภาพพื้นหลังจริง (ห้ามข้าม)
ภาพของคุณเป้คือ screenshot (มี minimap, ป้าย, ตัวละคร, ขนาดไม่ตรงภาพ) — **อย่าเดา scale เอง**
- ORB 5000 จุด + BFMatcher(Hamming, crossCheck) 800 คู่ที่ดีสุด → `cv2.estimateAffinePartial2D(..., ransacReprojThreshold=3)`
- ผ่านเมื่อ inliers ≥ ~150 และ scale ใกล้ ภาพจริง/screenshot (ชายแดน 1–2: 0.6704, offset y ≈ +4.5)
- inliers ≤ 10 = ไม่ใช่ภาพเดียวกัน (เช่น ภาพธีมคนละรุ่น) → ถามคุณเป้ว่าวาดบนภาพไหน

## 2. Walk mask จากการทาแดง
- แดง = `R − max(G,B) > 90` และ `R > 180` · ตัดมุม minimap ทิ้ง
- warp ด้วย affine (INTER_NEAREST) → open 5×5, close 7×7 → เก็บ component > 3000 px
- ตรวจ: ต้องได้ **ผืนเดียว** (ถ้าได้หลายผืน = ทางขาด รายงานคุณเป้) · ทำ overlay มืดนอก mask แล้ว **Read ดูเอง**

## 3. ตำแหน่งไอคอนที่วาด (ต้นไม้ ฯลฯ) — `trees_match.py <threshold>`
- stroke = (diff กับภาพจริงที่ warp กลับ > 110) & สีอิ่ม · แดง H≤6/≥175, เขียว H 30–75 (เขียวอ่อน median H≈43, เขียว ≈64)
- template = ไอคอนที่อยู่โดดๆ 1 ตัว (crop จาก stroke) → `matchTemplate` TM_CCOEFF_NORMED บนภาพ blur σ3, NMS 0.4 เท่าไอคอน
- **กับดัก:** พื้นที่ว่างได้คะแนน 1.00 (NaN/หารศูนย์) → `nan_to_num` + กรอง **coverage < 0.4** (TM_CCORR ของ stroke ดิบ / T.sum()) ไม่งั้นได้ 150 แทน 80
- ไอคอนที่วาดใหญ่กว่า template จะหลุด → ดูภาพกล่องแล้วเติมเอง (`big:true`)
- พิกัด = **โคนต้น** (กลางล่างของกล่อง) แปลงด้วย affine → 0–1 ของภาพจริง
- โคนที่ตกใน mask → ดันไปจุดนอก mask ที่ใกล้สุด + 6px, เก็บ `moved_from` แล้วแจ้งคุณเป้
