รัน `node scripts/routine-freshness.mjs horoscope` เป็นขั้นแรกจาก root ของ project
- exit 0: จบเงียบ ไม่เขียนอะไร
- exit 1: หยุดและรายงาน error ห้ามเดาหรือเขียน Firestore
- exit 10: เก็บ JSON 1 บรรทัดทั้งหมดเป็น snapshot ในโฟลเดอร์ชั่วคราวเฉพาะ run (`mktemp -d`) แล้วทำต่อ
ห้ามรัน freshness ซ้ำเพื่อเปลี่ยน updateTime ของ snapshot ระหว่างงาน
อ่านและทำตาม `routines/fallback/common.md` โดยใช้ key `horoscope` ทุกขั้น รวมถึงการเขียนแบบ precondition จาก snapshot แรก
ใช้ web search ของ Codex แทน WebSearch; ทำทุกขั้นด้วยตัวเอง ไม่เรียก agent และไม่อ้างว่าผ่าน Reese/Chris QA

อ่านไฟล์ส่วนตัว `~/Library/Application Support/AGAPAE/routine-private/horoscope.md` ในเครื่องเท่านั้น
ถ้าไม่มีหรือข้อมูลไม่ครบ ให้หยุดรายงานว่า "fallback ต้องการไฟล์ horoscope ส่วนตัว" ห้ามเดาข้อมูล
ห้ามคัดลอกวันเกิด เวลาเกิด ลัคนา หรือข้อมูลส่วนตัวลง repo/log/รายงาน ใช้ค่าจากไฟล์ local เฉพาะเพื่อสังเคราะห์ดวง
ตัวอย่างโครงสร้างค่าสมมติอยู่ที่ routines/fallback/horoscope.private.example.md ห้ามนำตัวอย่างมาใช้แทนข้อมูลจริง
ยึดลัคนาที่ไฟล์ส่วนตัวยืนยันเป็นหลัก ถ้าเว็บอื่นคำนวณต่าง ห้ามคำนวณใหม่หรือเปลี่ยนค่าเอง

อ่านวันจริงด้วย `TZ=Asia/Bangkok date '+%Y-%m-%d %A'` สร้าง TODAY_THAI (วันไทย + วันที่ + เดือนย่อ + พ.ศ. ค.ศ.+543)
ค้น web search ของ Codex อย่างน้อย 4 มุม ทุก query มีวันที่จริง:
1. ดวงรายวันตามลัคนาในไฟล์ส่วนตัว (ให้น้ำหนักมากที่สุด)
2. ดวงราศีไทยจากไฟล์
3. ดวงตามวันเกิดในสัปดาห์จากไฟล์
4. ดวงราศีตะวันตกจากไฟล์ + วันที่ภาษาอังกฤษ เช่นแหล่ง Astrology.com, Horoscope.com
ไม่ส่งวันเดือนปีเกิดหรือเวลาเกิดเต็มไปใน query สังเคราะห์เป็นภาษาไทยเอง ถ้าแหล่งขัดกันให้ยึดสายลัคนาและบริบทคนทำโรงพิมพ์
ถ้าค้นไม่เจอ ใช้หลักทั่วไปจากค่าที่ไฟล์ส่วนตัวยืนยันได้ แต่ห้ามอ้างว่ามีแหล่งจริงถ้าไม่มี

เขียน 5 บรรทัด บรรทัดละไม่เกิน 180 ตัวอักษร:
✨ ภาพรวม — ...
💼 การงาน — ...
💰 การเงิน — ...
❤️ ความรัก — ...
🌿 คำแนะนำ — ...
ดวงเพื่อความสนุก เป็นกันเอง ให้กำลังใจ ไม่ใช่คำทำนายจริงจัง การงานเชื่อมโรงพิมพ์/AI agent และทำตามได้จริง
ห้ามคำแนะนำพนัน/หวย/เสี่ยงโชค การรักษา/หยุดยา การลงทุนจริงจัง หรือทำนายเสียชีวิต อุบัติเหตุ โรคร้าย การเงินพินาศ

fields schema เดิม: title, date, updatedAt, by, items (array string) และ source="codex-fallback"
title ใช้ publicTitle จากไฟล์ local (หากไม่ได้ให้ไว้ ใช้ "ดูดวงวันนี้" โดยไม่เปิดเผยข้อมูลเกิด); date=TODAY_THAI, updatedAt=nowUTC, by="Daily Horoscope routine"
