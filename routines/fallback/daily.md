รัน `node scripts/routine-freshness.mjs daily` เป็นขั้นแรกจาก root ของ project
- exit 0: จบเงียบ ไม่เขียนอะไร
- exit 1: หยุดและรายงาน error ห้ามเดาหรือเขียน Firestore
- exit 10: เก็บ JSON 1 บรรทัดทั้งหมดเป็น snapshot ในโฟลเดอร์ชั่วคราวเฉพาะ run (`mktemp -d`) แล้วทำต่อ
ห้ามรัน freshness ซ้ำเพื่อเปลี่ยน updateTime ของ snapshot ระหว่างงาน
อ่านและทำตาม `routines/fallback/common.md` โดยใช้ key `daily` ทุกขั้น รวมถึงการเขียนแบบ precondition จาก snapshot แรก
ใช้ web search ของ Codex แทน WebSearch; ทำทุกขั้นด้วยตัวเอง ไม่เรียก agent และไม่อ้างว่าผ่าน Reese/Chris QA

ไม่ต้องใช้ Gmail ไม่ส่งอีเมล ไม่สร้าง draft ผลลัพธ์คือ agents/daily เท่านั้น
อ่านวันที่จริง `TZ=Asia/Bangkok date '+%Y-%m-%d %A %H:%M'`; TODAY_THAI = วันไทย วันที่ เดือนย่อ พ.ศ. (ค.ศ.+543)

## รวบรวม
ค้น web search ของ Codex 6 หัวข้อตามลำดับ ทุก query ต้องใส่วันที่จริงทั้งไทย/อังกฤษ ห้ามใช้แค่ "วันนี้":
1. การเมืองไทยระดับชาติ — รัฐบาล นโยบาย พรรค ครม.
2. การเมืองไทยท้องถิ่น/กฎหมาย — ผู้ว่า นายก อบจ. กฎหมายใหม่ ศาล
3. ข่าวโลก — ความขัดแย้ง สงคราม ภูมิรัฐศาสตร์ ผู้นำโลก
4. ภัยพิบัติ — แผ่นดินไหว พายุ น้ำท่วม
5. เทค/AI — ข่าวใหม่ tech startups
6. ราคาทองคำแท่งไทยบาท + Bitcoin USD spot และ % เปลี่ยนแปลง 24 ชม. เท่านั้น ไม่วิเคราะห์ทางเทคนิค
ทุกข่าวต้องมีวันที่เผยแพร่ชัดเจนและไม่เกิน 48 ชั่วโมงจากเวลารันจริง หากไม่มีวันหรือเก่ากว่านั้น ทิ้งและค้นใหม่สูงสุด 2 รอบต่อหัวข้อ
ไม่พบให้เขียน "ไม่มีข่าวใหม่ภายใน 48 ชม." ห้ามแต่งหรือเติมจากความจำ
เก็บ news_raw.md ใน RUN_DIR ครบ 6 หมวดพร้อมบรรทัดวันที่เผยแพร่ (YYYY-MM-DD หรือ X ชั่วโมงก่อน) และชื่อแหล่ง+URL จริง

## ตรวจและเรียบเรียง
ตรวจวันเผยแพร่กับ TODAY, ความน่าเชื่อถือ, เนื้อหาสอดคล้องกับพาดหัว ตัดข่าวที่ไม่ผ่านพร้อมเหตุผลลง news_verified.md และคงแหล่ง+วันที่
เขียน daily_items.txt หนึ่งบรรทัดต่อหัวข้อ ≤180 ตัวอักษร ภาษาไทยอ่านง่าย ข่าวจริงลงท้าย (ชื่อแหล่งข่าว):
🇹🇭 การเมืองไทย — ...
🏙️ ท้องถิ่น & กฎหมาย — ...
🌍 ข่าวโลก — ...
🌋 ภัยพิบัติ — ...
💻 เทค/AI — ...
💰 ทอง & Bitcoin — ทองแท่ง XX,XXX บาท · BTC $XX,XXX (▲/▼X.X% 24 ชม.)
หลายหมวดติดกันไม่มีข่าวใหม่ให้รวมบรรทัดได้ เช่น "🏛️ การเมืองไทย (ชาติ + ท้องถิ่น & กฎหมาย) — ไม่มีข่าวใหม่ภายใน 48 ชม."
ห้ามใส่ตัวเลขราคาสมมติ ถ้าแหล่งราคาไม่ยืนยันให้แจ้งว่าไม่พบข้อมูลแทน
